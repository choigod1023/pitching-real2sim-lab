# 생성 투구 장면

`pitcher_batter_overlay.mp4`는 OBP830/1615_1 투구와 별도 OBP000004/103_1 타격을 배치한 합성 대결이다. 실제 경기 촬영 영상이나 같은 실제 투구·타격 대결이 아니다. 공은 기록 구속 초기화·접촉점 정렬을 사용한 참조 포물선이며, 실제 구위 향상/힘/일/타구 결과 검증이 아니다. 조건과 수치는 상위 `FINDINGS.md`를 읽는다.

원/비교 타자는0/+12ms이며 투수 자세는 바꾸지 않았다. 실제 관절 재생과 가정 공을 화면에 구분했다. 전체 디코드 및 대표 프레임을 검사했다. 성공한 연구 결과를 보고할 때는 범위를 밝히고 이와 같은 투구 장면을 함께 표시한다.

Driveline Baseball의 [OpenBiomechanics Project](https://github.com/drivelineresearch/openbiomechanics)를 인용한다. 파생 영상·이미지는 [CC BY-NC-SA4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 및 상류 [자료 라이선스](https://github.com/drivelineresearch/openbiomechanics/blob/main/LICENSE-DATA.md)를 유지한다. 원본 C3D·CSV·촬영 영상은 재배포하지 않는다. 연구용 시각화이며 훈련·의료 조언이 아니다.
