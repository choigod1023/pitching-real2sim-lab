# 대학 실험실에 전달할 최소 동시 측정 명세

목적은 같은 투구의 전신·손·공 중심 움직임과 기록 구속을 연결해 기준 재현 및 미사용 투구 검증을 가능하게 하는 것입니다. 현재 이 조건을 모두 확인한 공개 코호트는 확보하지 못했습니다. 아래는 공학적 pilot 설계안이며 장비 구매나 선수 훈련 지시가 아닙니다. 외부 연락·선수 모집·실제 측정은 실행하지 않았습니다.

## 먼저 필요한 협력 범위

기존 장비로 전신 mocap/지면반력, 손·공이 보이는 다중시야 고속촬영, 독립 구속 기록을 공통 투구키와 시계로 묶을 수 있는 실험실이 필요합니다. 새 장비 구매를 전제로 하지 않습니다. 수집을 진행한다면 기관 연구 절차와 참가자 동의를 별도로 따라야 합니다.

시작 단위는 같은날·같은선수·같은구종의 반복 투구입니다. 예를 들어 기록된20투구 중 사전 지정10투구를 보정, 나머지10투구를 봉인 검사하는 구성을 설계 검토의 출발점으로 삼을 수 있습니다. 20은 통계적 검정력이나 적정 투구량의 기준이 아니며 실제 수집수·참여 조건은 담당 연구진이 정합니다. 다른날 반복을 추가해야 세션 일반화를 평가할 수 있습니다. 선수1명의 성공으로 처방이나 기존50선수 관문 통과를 주장하지 않습니다.

## 반드시 같이 저장할 것

1. **전신과 손:** 원본 C3D/원본 영상, 신체 치수, 정적/기능적 보정, 실제 마커/분절/관절축 정의와 모델 버전. 손목 중점·손 분절 원점·피부 표면·골 관절중심을 구분합니다. 이름이 같은 점이라고 자동 변환하지 않습니다. 손 방향을 식별할 충분한 비공선 관측이 필요합니다.
2. **공:** 릴리스 전후의 실제 공이 여러 시야에 보이는 원영상과 공 중심의3D 좌표/품질 표시. 단일 표면 반사표식만으로 중심/회전을 정하지 않습니다. 공 중심을 얻은 방법과 반지름/표면 오프셋/회전에 따른 불확실성을 별도로 저장합니다. 손가락 가림은 미관측으로 표시합니다.
3. **시계:** 원본 frame ID, 실제 캡처 timestamp, 공통 trigger/clock ID, 센서별 지연/노출/읽기 방식. 동기화 펄스 또는 같은 물리 사건을 기록해 잔차를 측정합니다. MP4의 명목 FPS, 첫 프레임 번호, 같은 C3D 파일이라는 사실만으로 물리 지연을0으로 놓지 않습니다.
4. **보정:** 내부/외부 파라미터·왜곡·단위·좌표계, 실제 측정한 길이와 보정 원영상. 손/공이 지나는3D 영역의 여러 방향·위치에서 보정에 쓰지 않은 길이/물체/시각으로 검사합니다. 픽셀 재투영만 낮고 실제 길이가 틀리면 통과하지 않습니다.
5. **독립 구속:** 장비 모델·측정 위치·관측축·기록 정의·단위·가능한 원본 로그/시각을 저장합니다. 최대 구간 속도, 특정 거리에서의 속도, 릴리스 추정 속도를 구분합니다. 두 장비의 숫자가 같아도 정확도를 입증한 것은 아닙니다. 비디오와 장비는 같은 물리 구간/양을 비교해야 합니다.
6. **이탈:** 마지막 접촉/처음 분리의 관측 시각 범위와 근거 시야, 가림 여부를 저장합니다. 손 최대속도나 손–공 거리10% 증가를 실제 마지막 접촉 정답으로 바꾸지 않습니다.
7. **힘/일:** 지면반력 원시6축·COP/모멘트·플레이트 좌표/단위/보정/접촉 구간, 전신 운동과의 시각 연결을 보존합니다. 선수 최대 힘 능력은 반복 투구의 관찰 토크 최대값과 다릅니다. 개인 근육 파라미터를 후보마다 키우지 않고, 미확인 능력은 미확인으로 둡니다.

구위/제구까지 확장하려면 실제 회전수·3D축·궤적, 의도한 목표·도착점·반복 분산이 추가로 필요합니다. 이번 구속 검증 자료로 없는 값을 채우지 않습니다.

## 정밀도는 측정해 정할 목표이며 보장값이 아님

1000fps 같은 설정만으로1km/h 분별을 보장하지 않습니다. 캡처 속도·공간 해상도·노출·가림·관측창 길이·가속을 함께 검토합니다. 아래는 Python으로 수식을 검산한 **조건부 공학 시나리오**입니다.

- 축 방향 위치잡음이 독립적으로 SD0.5mm이고,1000fps의11표본에서 일정속도 직선을 적합한다고 가정하면 속도 SD는 **0.171623km/h**입니다. 실제3D 공 중심·가속·왜곡·필터·상관잡음 오차를 포함하지 않습니다. 이 창의 평균 속도를 순간 이탈 속도라고 부르지 않습니다.
- 공간 스케일이1% 틀리면150km/h에서 **1.5km/h** 편향이 생깁니다. 스케일0.2%도 **0.3km/h**입니다. 오차 예산의 한 부분으로 삼을 목표 예시이며 교정 인증 기준이 아닙니다.
- 시간차의 속도 영향은 국소적으로 a×Δt입니다. 실제 가속도를1000m/s²라고 주장하는 것이 아니라 그 스트레스 조건을 가정할 때,0.3km/h 예산은 **0.083333ms** 시간차에 해당합니다. 실제 센서 지연 허용값은 관측한 가속과 불확실성에서 다시 산출해야 합니다.

점 위치잡음의 계산상 작은 SD만으로 전체 측정 정확도나 작은 개입 효과를 보장하지 않습니다. 새로운 미사용 투구에서 기준/변화 예측과 측정 반복성을 평가하고 기존 합격 기준을 유지합니다.

## 파일 연결 규약과 검사 순서

동봉 trials_template.csv는 헤더만 있는 양식이며 실제 측정자료가 아닙니다. 모든 파일의 각 관측에는 participant_id/session_id/pitch_id의 같은 키를 사용합니다. 원본은 보존하고 처리 이력·해시·단위를 기록합니다. 결측은 빈값/UNKNOWN과 이유를 남기며0으로 채우지 않습니다.

별도 streams.csv에는 stream_id/clock_id/실제 rate/시간 단위/좌표계/지연 근거를, ball_observations.csv에는 같은 키·시간·xyz·center 또는surface·품질을, events.csv에는 사건 정의·시간 범위·근거 시야·가림을 저장합니다. calibration_manifest.json은 학습/제외 길이/시각과 원본 해시를 구분합니다. 원시 센서 로그를 가공된 투구별 한 숫자로 대체하지 않습니다.

검사는 파일/키/단위 → 좌표·시계·관측 품질 → 같은 투구 재구성 → 보정에 쓰지 않은 투구의 구속/변화 예측 → 관절/외력/근육/힘·일 제약 → 작은 신체 수정 순서입니다. 실제 향상/안전/편안함은 별도의 인간 개입 검증이 필요합니다. 훈련 또는 의료 조언이 아닙니다.
