# 생성한 관절 재생 영상

아래 MP4는 OBP 원본 촬영 영상이 아니다. 공개 처리 관절 중심으로 새로 그린 골격이며, 원래 두 투구를 관측 비교한다. 주황색은 빠른 기록, 파란색은 느린 기록이다. 각 289프레임, 1600×1040, 30fps, 1/12배 재생이며 전체 디코드를 검사했다.

- [선수830: 1615_1 / 1615_2](player_830_observed_overlay.mp4)
- [선수774: 1097_2 / 1097_3](player_774_observed_overlay.mp4)

각 영상 앞부분은 FP10 착지 정렬의 실제 경과시간, 뒷부분은 제공 BR 이벤트 정렬의 별도 진단이다. 원점은 FP10에서 고정된 수평 병진이며, 이후 골반 이동과 높이를 보존했다. 공·머리·손가락·근육의 관측하지 않은 좌표는 만들지 않았다. 숫자는 기록 구속이며 새 예측값이 아니다. 실제 자세 변경 효과나 같은 근력/일을 입증하지 않았다. 훈련·의료 조언이 아니다.
