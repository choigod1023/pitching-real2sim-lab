# 중복 최대 입력 제약의 수치적 제거

2026-10-30. raw상한 복원 중, 입력생성기가 이미 성분/관절노름 상한으로 제한한 값의 노름을 다시 계산하면 약7.1054e−15Nm의 반올림차이가 생겼다. 기존 실제판정epsilon1e−9에서 충분히 통과하는 수치차이지만, epsilon을 뺀 최적화 식에서는 변화하지 않는 중복 peak 부등식이 음수가 돼 복원을 방해했다. 입력생성기의 제한과 실제판정은 계속 유지한다.

후속 복원에서는 최적화 부등식에서 이미 분석적으로 제한하는15개 peak 항만 제거한다. 나머지24개 일 항(성분양/음의일22,어깨순일2),자세3개,증가량0.5목표는두해상도에서실제raw상한으로유지한다. 원 gate에서는 모든peak를포함해이전과똑같이검사한다. 원래변수/시작점/탐색범위/최대400쌍평가/ftol/eps는바꾸지않는다.

입력제한함수와후보평가단계에서실제모든peak불증가를확인한다. 합성테스트에서는이미제한된peak의7e−15차이가복원의일부등식을막지않음을확인하고,실제로1e−3만큼peak를넘기는값은기존gate에서반드시탈락하는지검사한다. 입력상한을늘려구속을맞추거나peak를최종판정에서빼는수정이아니다.

앞선raw복원보고서/코드·입력해시를보존한다. 아직이수정이유효증가를만든다고확정하지않으며새실행후실제값으로검산한다.
