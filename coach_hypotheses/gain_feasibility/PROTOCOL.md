# +1.665km/h 후보의 동작 파형·실제 입력 제한 검증

2026-10-30. 결과 계산 전에 고정한다. 원래3034_1 `wrist_z_p2`를 대상으로 하며 다른 Prime 투구의 기록차이를 섞지 않는다. 기존 +1.665237km/h는 힘·일 미통과임을 유지한다. 실제 선수 개입이나 검증된 해부학 모델이 아니다.

## 질문과 사전 조건

끝 각도 +2°만으로 설명했던 증가량 중, 마지막에 추가된 각속도의 영향이 얼마나 큰가? 끝 추가 각속도가 0인 파형으로 바꿔도 상승분이 남는가? 원래 힘 최대값을 초과하지 않는 실제 입력을 적용하면 기존 일·자세 제한까지 통과하는가?

입력은 기존 `grip-identifiability/artifacts/grip-identifiability/fine-reference/reference-0.npz`이며 원 보고서의 SHA256과 대조한다. 일반 질량·관성, 그립15cm, 이탈 시각, 초기 상태를 고정한다. 레이더 구속은 적합·선택에 사용하지 않는다. 마커 Z축을 해부학적 손목 굽힘 축으로 부르지 않는다.

## 계산 A: 고정 각도, 시간 파형 분리

동작 끝점 수정각은 모두 +2°다. 창 길이는 20/30/40/60ms, 파형은 cubic-in `s³`, smoothstep `3s²−2s³`, smootherstep `10s³−15s⁴+6s⁵`로 고정한다. 12조건과 무수정 기준을 모두 보고한다. 원래30ms cubic-in을 재현 대조군으로 둔다. smoothstep/smootherstep은 연속식 끝점 추가 각속도가 0이지만 이산 미분의 작은 잔차는 수치 그대로 보고한다. 모두 같은 초기 위치·속도다.

각 처방 궤적의 역동역학 입력을 재산정하여 실제 RK4 적분한다. 이는 같은 입력 비교가 아닌 동작 수요 검사다. 기준과 조건을 모두 한 구간당1/2 substep으로 검사한다.

## 계산 B: 제한된 실제 입력 경로

A의 12조건별 역동역학 입력에서 손목 DOF8:11만 사용한다. 어깨 DOF0:6, 팔꿈치DOF6, 전완 marker_roll DOF7은 기준 입력을 매 시각 그대로 유지한다. 손목 입력은 `기준 + α(수정−기준)`, α=0.25/0.5/1.0의 36조건으로 고정한다. 적용 구간의 기준 성분별 최대 절댓값과 손목3축 최대 노름으로 제한한다. 이 클리핑이 실제 일의 불증가를 보장한다고 가정하지 않는다. 초기 상태에서 상태 재설정 없이 RK4로 실제 동작·속도·일을 계산한다. terminal 미사용 입력은 최대값·클리핑 기준 계산에서 제외한다.

A와 B는 서로 다른 질문이다. B가 요청한 수정각을 실제로 구현하지 못하면 실제 끝점 각도/각속도 및 궤적 차이를 그대로 보고하며 A와 같은 동작이라고 부르지 않는다. 양의 구속만 보고 선택하지 않는다.

## 판정

기존 `capacity_budget_gate.gate`의 epsilon1e−9를 변경하지 않는다. 모든 DOF의 양/음의 일, 성분 힘/토크 peak, 어깨 병진·회전 순일, 관절 토크 노름 peak가 각각 기준을 넘지 않아야 한다. 각 해상도에서 해당 해상도의 기준과 비교한다. 초기 상태·에너지가 같아야 하고, 기존 최대 회전차3° 검사를 유지한다. 양의 일의 좌표 의존성과 근육 능력 미검증을 표시한다.

계산상 후보는 두 해상도 모두에서 위 검사를 통과하고 증가량이 양수여야 하며, 두 증가량의 차이는0.001km/h 이하여야 한다. 또한 증가량은 기준·수정 절대구속의 해상도 차이 합보다 커야 한다. 기존 별도 동작 탐색의 보수적 자세 지표도 함께 적용하여 공 중심 최대 이동20mm·방출 방향차1°를 넘는 조건은 채택하지 않는다. 이는 수치·공학적 기준이지 실제 최소 유효 증가량·측정 오차·95% 구간이 아니다. 1km/h를 넘는지 별도로 보고하며 작은 양수만으로 실효성을 주장하지 않는다. 이 검사는 기존 연구 gate 통과나 실제 안전·편안함·훈련 효과를 뜻하지 않는다.

원래 기준/수정 재현값은 기존 세밀한 결과와0.00001km/h 안에서 일치하는지 확인한다. 구현 검증 실패 시 원인을 수정하고 결과를 보존한다. 실패한 조건을 제거하거나 alpha/창/각도를 추가 탐색하지 않는다.

## 계산 C: 증가량의 짝지은 공학적 민감도

저장된 실제 기준/수정 상태에서 같은 그립14/15/16cm와 공칭BR 대비−2/−1/0/+1/+2 source frame(360Hz)을 사용해 공 중심 속도를 계산한다. 두 상태는 같은 물리 시각에 대응시킨다. quaternion 상태를 정규화·보간하며 가장 가까운 프레임을 임의 선택하지 않는다. source 범위 밖 조건은 제외 사유로 기록하고 외삽하지 않는다. 실제 +1/+2가 없으면 대칭 민감도나 release 식별로 부르지 않는다.

이 단계는 payload 관성을 바꿔 재적분한 결과가 아니라 동일 실제 상태의 끝점 기하 진단이다. 확률분포·95% 구간·성공 확률을 만들지 않는다. 원래 후보와 새로 조건을 통과한 후보가 있으면 각각 평가한다. 관측하지 않은 손가락 접촉·이탈 변화와 실제 개입 오차는 UNKNOWN이다.
