# 같은 능력과 일 제약을 구분하는 근거

2026-10-30. 실제 선수의 근력 용량은 아직 측정·검증하지 못했다. 이번 코드의 힘·일 상한을 생리학적 능력과 동일시하지 않는다.

## 확인한 기존 결과

이 저장소의 `EMPIRICAL_BUDGET_FINDINGS.md`는 이미 2026-10-26에 같은 선수의 다섯 관찰 투구를 비교했다. 한 투구의 모든 좌표별 힘·양/음의 일을 상한으로 삼자 나머지 네 투구가 탈락했다. 이번 작업은 그 계산을 재실행하거나 새로운 발견으로 포장하지 않고, 기존 제한을 최대 능력으로 해석할 수 없다는 근거로 재사용한다. 다섯 투구가 같은 노력/피로 상태였다는 증거도 아니며 관찰 범위를 안전 역치로 바꾸지 않는다.

당시 그룹 일·공통 관찰예산·6개 각도/타이밍 변수의 탐색도 이미 수행됐고 해상도 차이를 벗어난 증가를 얻지 못했다. 이번 변경은 그 예산이나 각도를 반복 탐색하는 것이 아니라, 입력 시계열 자체를 변수로 삼는 별도 실험이다.

## 물리량의 차이

- **근력 용량:** 근육의 최대 등척성 힘, 길이·수축속도·활성에 따른 힘 발생, 힘줄과 모멘트암 등으로 정의되는 능력이다. [OpenSim 원본 Muscle 정의](https://github.com/opensim-org/opensim-core/blob/main/OpenSim/Simulation/Model/Muscle.h)는 최대 등척성 힘과 섬유 길이/속도 관련 계산을 구별한다. 한 번 수행한 일반화좌표별 최대 토크나 일만으로 이 능력을 측정할 수 없다.
- **일:** 실제 힘/토크와 해당 일반화속도의 내적을 시간 적분한 결과다. 같은 최대 힘에서도 지속시간과 속도가 달라지면 일은 달라진다. 축별 파워를 양수만 모은 합은 축 구성에 의존할 수 있다. 관절그룹 내부에서 먼저 내적을 합한 뒤 양/음을 나누는 정의는 그 그룹의 공통 직교 좌표변환에 불변이지만, 근육의 동시수축이나 대사 에너지까지 나타내지는 않는다.
- **에너지 전달:** [Naito 2021](https://pubmed.ncbi.nlm.nih.gov/34495332/)의 대학 투수16명 분석은 생성과 근육토크/원심력에 따른 전달을 구분했다. 분절 간 전달의 관찰 근거이며, 개인의 특정 자세를 바꾸면 동일 능력으로 구속이 얼마나 오르는지 검증한 연구나 허용 증가율을 정한 연구는 아니다. 이번에는 공개 초록을 확인했으며 전문에서 추가 수치를 추정하지 않았다.

## 이번 두 분석의 의미

**A는 기존 비교 기준을 그대로 보존한다.** A의 통과/실패를 B 결과로 덮어쓰지 않는다. 엄격한 모든 좌표별 일 제한 아래에서 실제 입력 시간분배의 개선 후보가 있는지를 본다.

**B는 별도의 기계적 재분배 가정이다.** 총 그룹 양/음의 일과 총순일, 외부어깨의 양/음의 일·순일, 기존 힘/토크peak를 모두 제한한다. 내부관절별 일을 재분배할 수 있게 하지만, 이는 검증된 근력곡선을 대체하지 않는다. B만 통과한 결과는 A의 성공이나 실제 동일 능력 효과가 아니다. 이런 구분 없이 뒤늦게 제한을 바꿔 통과시키는 해석을 금지한다.

두 분석의 힘 상한은 모델 일반화입력의 성분/정의된 관절노름 상한이다. 실제 팔꿈치 varus/어깨 내회전 부하와 자동 대응하지 않으며, 자유 어깨 병진힘의 벡터노름·관절각/속도별 근육 능력의 완전한 상한으로 확대 해석하지 않는다. 실제 모델/관절/근육 경로 검증은 별도다.

## 아직 필요한 근거

같은 투구의 전신운동·지면반력·외력분배, 해부학적 회전축, 검증된 근육경로와 모멘트암, 손–공 접촉과 이탈 관측이 필요하다. 근력검사/EMG를 확보해도 측정 정의와 모델 대응을 검증해야 하며 EMG만으로 실제 힘을 확정하지 않는다. 원래 논문과 공개모델의 불일치를 일반 관성/임의 근력 조정으로 메우지 않는다. 현재 연구는 이 모든 자료가 확보됐다고 주장하지 않는다.
