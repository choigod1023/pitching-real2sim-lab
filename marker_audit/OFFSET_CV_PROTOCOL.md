# 손 오프셋 교차 검증 규칙 (결과를 보기 전에 기록)

2026-10-28. 선수 2의 세션 3034, 5투구. 이미 본 개발 자료이므로 독립 검증이 아니다.

- 질문: 손목 중점에서 공 중심까지의 거리(오프셋) 하나를 일부 투구의 레이더 기록으로 보정하면, 보정에 쓰지 않은 투구의 구속을 맞히는가.
- 모델: BR 프레임의 공 중심 대리 속도. 공 중심 = 손목 중점 + 오프셋 × 손 길이축(RFIN 방향). 기본 필터 20Hz 양방향. 오프셋 탐색 범위 0~0.40m.
- 보정: 훈련 투구의 제곱 오차 합을 최소화하는 오프셋 하나. 다른 모수는 보정하지 않는다.
- 평가: 투구 1개씩 빼는 교차 검증(5회). 평가 투구는 보정에 쓰지 않는다.
- 비교 기준: (a) 훈련 투구 레이더 평균을 그대로 쓰는 예측, (b) 보정하지 않은 15cm 가정.
- 보고: 투구별 오차, 평균 절대 오차, 보정된 오프셋의 범위, 투구 사이 순위 일치(스피어만).
- 민감도: 필터 13, 30, 50Hz와 RFIN 고정(G0)도 모두 보고한다. 결과를 보고 필터나 변형을 선택하지 않는다.
- 판정: 평균 기준 (a)보다 평균 절대 오차가 작지 않으면 이 모델이 투구 사이 차이를 설명한다고 말하지 않는다.
