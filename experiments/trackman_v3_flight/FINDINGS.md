# TrackMan V3 포심의 수직 무브먼트 비교 결과

[공개 TrackMan V3 원자료](https://data.mendeley.com/datasets/xfnz6mkdzm/3)의 3,344행을 사용했다. 수동 분류 Fastball과 자동 분류 Four-Seam의 교집합 861구에서 같은 투수·경기의 구속 차이 1.0 km/h 이하인 기존 1,733쌍을 재현했다. 24명의 투구가 포함되며, 한 투구가 여러 쌍에 포함될 수 있다. 새 매개변수를 기록에 맞추지 않았다.

## 전체 쌍에서 맞힌 방향

- RPM 변화 부호만 사용 · 1,005/1,733, **57.99%**.
- 구속·RPM·릴리스 위치 및 비행거리, 수평·수직 각도 0°, 백스핀 고정 · 1,018/1,733, **58.74%**. 쌍별 IVB 변화 MAE 5.48 cm.
- 위와 같은 조건에서 측정 릴리스 각도 사용, 백스핀 고정 · 1,027/1,733, **59.26%**. 변화 MAE 5.45 cm.
- 릴리스 각도 0°, TrackMan 역산 회전축 사용 · 1,152/1,733, **66.47%**. 변화 MAE 5.00 cm.
- 측정 릴리스 각도와 TrackMan 역산 회전축 모두 사용 · 1,157/1,733, **66.76%**. 변화 MAE 4.97 cm, 투구별 IVB MAE 7.14 cm.

마지막 조건은 RPM 기준보다 152쌍 더 맞혔다. 방향 일치율 차이는 +8.77%p다. 축을 고정한 상태에서 릴리스 각도를 넣은 순수 추가분은 +0.52%p였고, 역산 축을 쓴 상태에서는 +0.29%p였다. RPM 기준에는 cm 단위 예측이 없으므로 변화 MAE를 부여하지 않았다.

TrackMan V3는 비행 중 측정한 무브먼트에서 회전축을 역산한다. 해당 회전축을 쓴 결과는 같은 비행 자료에 조건부인 재현 성능이다. 원자료의 `SpinAxis`에서 180°를 빼면 861구의 `Tilt`와 최대 3.748° 차이로 맞으며, 이는 시계 표기의 15분 반올림 범위다. 수평·수직 무브먼트로 계산한 방향과의 절대 차이 중앙값은 1.470°였다. 축을 제외한 모델도 같은 장비의 릴리스 추정치를 입력하고, 자동 구종 분류에 무브먼트가 사용된다. 독립적인 투구 전 예측 성능은 미검증이다. [회전축 정의](https://support.trackmanbaseball.com/hc/en-us/articles/48452122649499-V3-Metrics-Spin-Axis-V3) · [데이터 수집 논문](https://doi.org/10.1016/j.dib.2024.111049)

계산에는 항력계수 0.35와 [Sawicki 외](https://baseball.physics.illinois.edu/AJP-Nov03.pdf)의 양력식을 썼다. 유효 회전 비율은 공개 자료에서 직접 확인되지 않아 1.0으로 고정했다. 0.8 조건의 방향 일치율은 66.36%, 변화 MAE는 4.96 cm였다. 모든 쌍 비교는 지면 충돌 없이 판면까지 수식을 연장한 경우를 포함한다. 원기록의 판면 높이가 음수이거나 네 주 조건 중 하나에서 지면을 통과한 공이 든 쌍 4개를 공통 제외하면 RPM 기준은 1,005/1,729(58.13%), 두 정보를 모두 넣은 모델은 1,157/1,729(66.92%)였다. 거리 구간 수를 256에서 512로 두 배로 늘려도 전체 1,157쌍이라는 결과가 유지됐다.

## 연속 투구 17·18번

- **17번** · 145.36 km/h, 2,287 RPM. 기록 IVB 34.75 cm, 모델 49.48 cm. 기록 판면 높이 50.25 cm, 모델 65.09 cm.
- **18번** · 145.18 km/h, 2,335 RPM. 기록 IVB 32.16 cm, 모델 39.58 cm. 기록 판면 높이 55.07 cm, 모델 62.85 cm.

17번에서 18번으로 갈 때 IVB는 기록에서 **−2.59 cm**, 모델에서 **−9.90 cm**였다. 모델이 감소 방향을 맞혔으나 감소폭을 **7.31 cm** 과대 계산했다. 판면 높이는 기록에서 **+4.82 cm**, 모델에서 **−2.24 cm**로 순서가 반대였다. IVB는 각 공이 릴리스 방향과 중력만으로 날아갔을 때의 기준 높이와 비교한 값이고, 판면 높이는 좌표계에서 직접 읽은 값이다.

겹침 그림의 실선은 TrackMan이 제공한 2차 적합 궤적이다. 원시 카메라 영상이나 시점별 독립 실측 좌표가 공개된 것은 아니다. 장비가 추정한 궤적의 판면 통과 시간을 장비 기록과 대조했을 때 두 구의 차이는 0.046 ms 및 0.094 ms였다. [TrackMan V3 필드와 IVB 정의](https://support.trackmanbaseball.com/hc/en-us/articles/5089413493787-Radar-Glossary-Of-V3-Terms)
