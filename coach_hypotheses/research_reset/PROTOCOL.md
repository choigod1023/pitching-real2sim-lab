# 연구 재설계: 자료 적격성과 같은 선수의 두 투구 차이

2026-10-29. 사용자가 설계 확정과 검증의 병렬 진행을 승인했습니다. 두 에이전트는 기존 평가 설계와 실제 자료의 키/신호 유효성을 읽기 전용으로 감사합니다. 이 문서를 **새 예측 계산과 구현 전에 커밋**합니다. 자료 목록 확인은 먼저 진행했지만 새 성능 점수는 아직 계산하지 않았습니다. 자료와 기존 결과를 이미 본 뒤의 개발 실험이며 독립 사전등록 연구가 아닙니다.

## 보존과 범위

고정 15cm 그립 모델은 진단 전용으로 남깁니다. 이 브랜치는 최신 원격 main에서 만들고 PR118의 사용 중단 변경 e9abea8만 명시적으로 가져왔습니다. 기존 stage1/진단/교체 실험의 코드·결과·합격 기준 및 gate 상태는 바꾸지 않습니다. 새 결과를 기존 scientific_gate 통과로 승격하지 않습니다. 신체 개입, 골반/몸통 최적화, 손가락 접촉 모델 구현, 자동화 재개는 이번 범위에 없습니다.

## 1. 자료 적격성 감사

- metadata의 session_pitch와 filename_new 고유성, metadata→파일명→고유 C3D 연결을 검사합니다. full_sig/POI는 session_pitch로 연결하고, 신체와 GRF의 다른 샘플 격자를 행번호로 합치지 않습니다.
- 기존 신체 지표 코호트는 98선수/399투구, 추가 처리 10/20/30Hz 세 조건을 고정합니다. 목표 속도, 선수/세션, 키 및 필터별 투구 집합이 metadata와 일치하는지 검사합니다. 기존 제외 투구를 성능에 따라 복귀시키지 않습니다.
- GRF는 파일 존재, 전체 시간의 6축 finite, PKH~BR 구간의 6축 finite를 따로 기록합니다. 결측과 제외 ID를 남깁니다. 이번 쌍 예측에서 GRF로 투구를 추가 제외하지 않습니다. finite는 발 접촉·좌표/단위·힘/일 검증 통과가 아닙니다.
- Prime OBP_movement_BaseballThrow_001은 같은 투구 손/공 관측의 별도 개발 자료입니다. 3034의 관측 정답으로 합치지 않습니다. 실제 영상·제공 회전·트랙의 존재/길이 확인은 관측 연결의 일부일 뿐, 미확인 보정·시계·관절원점을 승인하지 않습니다.
- 기존 stage1 manifest의 원자료 해시를 모두 검증합니다. 파생 지표 입력 SHA256은 c555d826ce78fc0ca20bb6a2be017ffc6df8fa84e8911001a3250ac3ea4b04f4입니다. 해시/키/값 불일치 시 오류로 멈추고 예상값을 바꿔 통과시키지 않습니다.

## 2. 작은 고정 예측 실험

질문은 **이미 관측한 같은 선수의 두 투구에서 구속 차이를 예측하는가**입니다. 미래 단일투구의 절대구속, 새 세션, 신체 개입의 효과를 묻는 실험이 아닙니다. 기존 centered 평가에서 평가 정답의 세션 평균은 회고적 점수에만 쓰였으며 이를 학습 누출이라고 소급 단정하지 않습니다. 이번에는 정답 평균을 필요로 하지 않는 쌍 차이를 정답으로 삼습니다.

- 각 선수 안에서 session_pitch를 사전식으로 정렬해 모든 unordered 쌍 i<j를 만듭니다. 이 순서는 시간 순서가 아닙니다. 입력 dx=x_j−x_i, 정답 dy=v_j−v_i(km/h), 기준 예측은 0입니다. 쌍 수를 독립 선수 수처럼 해석하지 않습니다.
- 입력은 이미 감사한 stable7 하나로 고정합니다: lead_knee_extension_deg, stride_reported, stride_reported_sq, hip_shoulder_sep_fp10_deg, hip_shoulder_sep_peak_deg, wrist_height_br_m, arm_slot_poi_deg. 실제 공 이탈 높이로 손목 높이를 부르지 않습니다. 토크·힘·레이더·ID는 입력이 아닙니다.
- 선형 ridge, 절편 0, alpha=10 한 조건만 사용합니다. 선수별 모든 쌍의 가중치 합을 1로 둔 Σw(dy−Zβ)²/2+10||β||²/2를 풉니다. 스케일은 훈련 쌍만의 가중 RMS이며 상수 0열의 스케일은 1입니다. 평균을 빼지 않아 방향 반전 시 예측 부호도 반전합니다. 초모수/지표/필터 선택은 하지 않습니다.
- 선수 단위 LOAO: 제외 선수의 모든 투구/정답은 적합·스케일·선택에서 제외합니다. 해당 선수의 두 입력을 읽는 것은 허용하며 정답은 점수 계산에만 씁니다. 기존 선형 중심화와 정보적으로 밀접하므로 새 정보 확보나 누출 수정에 의한 성능 향상이라고 주장하지 않습니다.
- 세 필터를 모두 보고합니다. 20Hz가 주 조건이며 기존 신호는 이미 처리된 자료이므로 10/20/30Hz 추가 처리가 원시 센서 대역을 복구하지 않습니다. 소수의 좋은 선수·조건을 사후 채택하지 않습니다.

## 3. 판정과 회귀 검사

선수별 쌍 MAE를 평균해 선수균등 MAE를 구합니다. 선수별 (모델 MAE−0기준 MAE)를 seed20261029, 2000회 선수 cluster bootstrap으로 재표집해 95% percentile 구간을 보고합니다. 쌍을 독립 표본으로 bootstrap하지 않습니다. 절대오차 p95도 기술 통계로 남기되 측정 오차 또는 예측 95% 구간으로 부르지 않습니다.

`development_pairwise_criteria_pass`는 고유선수>=50/고유투구>=150, 해시/키/누출·반대칭 검사 통과, 20Hz MAE가 0기준보다 작음, 차이 bootstrap 상한<0, 10/30Hz MAE가 0기준보다 나쁘지 않음을 모두 요구합니다. 기존 문턱을 완화하지 않고 새로운 쌍 평가에 같은 엄격함을 적용하되 기존 scientific_gate의 판정은 그대로 둡니다. FAIL이면 모델 채택/최적화로 넘어가지 않습니다. PASS여도 관찰쌍의 개발 결과일 뿐 처방이나 실제 향상 근거가 아닙니다.

합성/실제 자료에서 선수 비중복, 제외 선수 전체 정답의 임의 교체 후 해당 예측 불변, 입력 방향 반전의 예측 반전, 훈련 전용 스케일, 정확한 쌍 차이/단위 및 중복·NaN 거부를 검사합니다. 모든 새 함수에 회귀 검사를 추가합니다. 기존 10환경 오류/2skip과 새 실패를 구별합니다.

1km/h 분별성은 별도 목표입니다. 보수적인 개발 점검값으로 MAE<0.5km/h와 절대오차 p95<1km/h를 둘 다 보고하되 이는 문헌 표준이나 센서 신뢰구간이 아닙니다. 이 점검을 만족해도 개입 반응의 정확도를 보장하지 않으며 추천 가능 여부는 항상 false로 둡니다.

## 4. 이후 모델 교체의 관문

병렬 관측 분석은 검사할 신체 가설을 좁힙니다. 손–공 모델 교체는 같은 투구에서 손 상대 공 위치·회전·이탈의 직접 관측으로만 제약합니다. 공 위치로 초기화한 비행, 동일 투구 앞부분 보정 뒤의 후속 재구성, 새 투구의 공 속도 예측을 구별합니다. 미분 stencil/필터 지지 구간이 학습·평가 경계를 넘으면 독립 속도 검증이 아니며, 별도 guard gap/분리 자료가 필요합니다. 비공개/미확인 값을 정답으로 채우지 않습니다.

미사용 투구의 구속·차이 검증 이후에만 전신/GRF/관절별 힘·일·외력 예산을 다룹니다. 같은 총 일과 같은 관절별 예산은 따로 검사합니다. 신체 수정의 개선이 검증될 때 원래/수정 투구를 같은 좌표와 시각에 겹친 영상을 만듭니다. 이번 자료 감사와 관찰쌍 실험을 신체 개선 영상으로 꾸미지 않습니다. 새 회전수/3D축/목표점 자료가 없는 구위·제구는 미검증으로 남깁니다.
