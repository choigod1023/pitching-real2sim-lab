# 후속 원인 분리: 같은 alpha의 ridge 표현 비교

주 분석의 원래12개는 alpha<=100이고 개선 표현들은 alpha<=1000입니다.
따라서 개선 표현의 오차가 작아진 것을 지표 개선 효과라고 단독 해석할 수 없습니다.
주 분석 완료 뒤, 이 계산 전에 추가 확인을 기록합니다. 원래 결과/판정/선택기를
바꾸지 않고 비교 출력을 별도 저장합니다. 좋은 outer 결과를 골라 주 모델로 쓰지 않습니다.

같은399구/98명,10/20/30Hz에서 original12/stable7/extended14/waveform20 ridge를
각각 alpha100과1000으로 고정해 선수LOAO를 수행합니다. 훈련 전용 표준화,
선수균등 가중, 검사 예측 중심화는 동일합니다. 모든 결과를 보존하고 변수 표현과
축소 정도를 나눠 봅니다. mae14는 손실 단위가 달라 같은alpha가 같은 정규화 세기를
의미하지 않으므로 이 원인 분리 표에서 제외합니다. 합격 기준을 바꾸거나 추가
통과를 선언하지 않습니다. 기존 주 분석의 파일 해시는 그대로 유지합니다.
