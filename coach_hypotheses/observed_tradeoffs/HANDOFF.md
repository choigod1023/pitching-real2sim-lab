# 단계1 인계

완료: 기록 구속과 세 팔 부하 지표의 선수 내 관측 비교. 원래 부호 정의 44쌍, 견인 성분 크기 정의 59쌍이 추가 세 필터 모두 유지됐고, 정정 정의 중 기록 차이 1km/h 이상은 21쌍이다. 이들은 개입/같은 힘 능력/같은 일 예산을 검증한 후보가 아니다. 구속 예측 gate 미변경. 과거 자동화는 재개하지 않았다.

현재 패키지 PROTOCOL.md, AMENDMENT_01_SIGNED_TENSION.md, FINDINGS.md와 results/summary.json, manifest.json, verification.json을 읽는다. 이미 수행한 1,998행의 계산과 검산을 반복하지 않는다. full-suite.txt의 10개 오류는 기존 환경/로컬 산출물 부재로 새 오류가 아니다. 자기 worktree의 model.xml 테스트 부작용은 복원했다.

다음 범위는 별도 사전 프로토콜이 필요한 단계2다.

1. 원래/정정 정의를 유지한 채 59쌍에서 부하와 기록 차이를 뒤집는 데 필요한 오차 크기를 보고한다. 측정 SD를 임의로 정하거나 59개를 모두 실측 견고 후보라고 승격하지 않는다.
2. 소스 PKH/BR 구간과 앞무릎 신전량 지표의 원시 각도/부호를 확인한다. 이벤트 이동은 사전 지정하고 원자료 지지 구간을 검사한다. 관측 구속에 맞춰 이벤트를 고르지 않는다.
3. 독립 카메라/레이더/역동역학 오차 근거가 없으면 공학적 스트레스 조건과 실제 측정 검증을 구분하고 미확인을 남긴다.
4. 그다음 단계3에서 실제 두 투구의 겹친 신체 영상을 만든다. 먼저 실제 C3D/processed-landmark 대응과 이벤트 정렬을 검사하고, 공 관측 없는 이 투구의 손목을 공 중심으로 쓰지 않는다. 기록 구속·동작 차이·부하 지표를 관측 비교로 표시하며 가상의 증가 장면으로 만들지 않는다.

새 코드 변경은 최신 origin/main의 별도 codex 브랜치/worktree에서 격리하고 이 작업의 미병합 선행 커밋을 명시한다. 다른 작업/데이터를 수정하지 않고, 단계별 산출물을 사용자에게 보고한다. 유료 구매·외부 연락·선수모집·배포·PR병합은 하지 않는다.
