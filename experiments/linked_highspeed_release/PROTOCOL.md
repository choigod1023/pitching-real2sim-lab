# 고속 릴리스 영상과 투구 기록 연결

- 공개 예시 통합문서의 투구 번호와 같은 행의 영상 하이퍼링크를 연결 키로 쓴다. 선수 이름이 비어 있으면 영상과 공개 파일의 근거만 적는다. `FB`를 포심으로 분류하고, 같은 세션의 투구 중 구속 차이 1.0 km/h 이하를 주 분석에 쓴다. 영상이 있는 포심이 그 기준에 들지 않으면 탐색 비교로 남긴다.
- 원본 영상 프레임에서 보이는 공의 외곽과 손끝을 표시한다. 두 물체가 영상 평면에서 마지막으로 겹치거나 경계를 구분할 수 없는 프레임과 처음으로 틈이 보이는 프레임을 기록한다. 손가락 정체, 깊이, 실제 접촉점과 이탈 순서는 증거가 있을 때만 채운다. 재생 FPS는 촬영 FPS로 쓰지 않는다. 3D 접촉 위치나 힘의 작용선을 식별할 수 없으면 기존 4 mm 가정을 관측값으로 바꿀 수 없다.
- 영상 접촉 검증과 분리하여 조건부 공 비행을 계산한다. 장비의 구속, 유효 RPM, 스핀 방향, 릴리스 높이·각도를 입력하고 수직·수평 무브먼트는 비교에만 쓴다. Rapsodo 투수 시점의 12시를 백스핀으로 두고 오른쪽을 수평 양의 방향으로 한다. 3D 속도에 수직인 스핀축을 시계 방향에서 구성한다. 실밥 방향별 힘과 바람은 모델에 포함되지 않는다.
- [Sawicki 외의 양력식](https://baseball.physics.illinois.edu/AJP-Nov03.pdf)을 초기 유효 RPM에 적용한다. 기존 `pitch_outcomes.flight`로 양력 유무에 따른 판면 위치 차이를 계산한다. 릴리스에서 판면까지 16.8 m, Cd 0.35, 시간 간격 1 ms를 쓴다. 시간 간격 절반으로 수치 차이를 확인하고, 비행거리 16.2·17.4 m와 Cd 0.30·0.40을 조합해 공학적 민감도를 보고한다. 이 설정은 기록된 무브먼트로 보정하지 않는다.
- 양력 유무의 차이가 장비의 IVB·HB 정의와 비교 가능한지 구분하고, 동일한 기준을 사용한다는 증거가 없으면 독립 검증으로 해석하지 않는다. 공개 자료에서 전체 포심과 영상 연결 포심을 따로 집계한다. RPM은 입력값이며, 손가락에서 예측한 값은 관측·검증이 가능해질 때 별도로 비교한다.

## 영상 회전 관측을 더한 탐색 비교

동일한 투구에서 볼 반경으로 정규화한 실밥 무늬의 반복 주기를 관측할 수 있으면, 두 영상의 동일한 마스크·구간 집합에서 얻은 중앙값과 500 fps라는 저자 장비 설명을 사용한다. 개별 파일의 촬영 시계는 확인된 값으로 쓰지 않는다. 비행 비교는 장비의 유효/전체 RPM 비율을 고정하고 전체 RPM 입력만 영상값으로 바꾼다. 나머지 입력과 무브먼트 비교 기준은 위와 같다. 이 비교는 3D 손 접촉 위치·힘 추정과 구분한다.
