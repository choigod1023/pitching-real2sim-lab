# 기존 모델 교체 대안과 실제 대조 실험

2026-10-29. 세 에이전트가 물리·근골격, 실측 학습, 물리–학습 결합을 나눠 조사했고,
별도로 같은 동작 입력의 비선형 예측 대조를 구현·실행했습니다. 기준 코호트와
기존 합격 기준은 유지했습니다. **즉시 채택할 검증된 교체품은 찾지 못했고,
새 비선형 대조도 기존 과학적 합격 기준은FAIL입니다.**

## 교체 판단

현재 고정그립·이탈 대리 기반 모델은 오차 원인 진단용으로만 남기는 것이 타당합니다.
현재 구현의 관절 최적화 출력으로 투수에게 동작을 권할 근거는 없습니다. 이는
기존 실행기를 삭제·비활성화했다는 뜻은 아닙니다. 이번 변경은 문헌·코드 감사와
새 비교 프로그램이며 기존 앱의 예측 코어를 바꾸거나 배포하지 않았습니다.

엔진을 OpenSim에서 MuJoCo 또는 미분 가능한 엔진으로 옮기는 것과, 실제 공
구속 예측을 검증하는 것은 별개입니다. 필요한 교체 대상은 손속도/강체그립의
대리 출력을 실제 공 중심의 이탈 속도로 연결하는 예측부입니다. 그 부분의
입력·정답이 식별되지 않은 상태를 더 빠른 최적화나 신경망으로 해소할 수는 없습니다.

[Attias 저자 원문](https://uwaterloo.ca/motion-research-group/sites/default/files/2026-01/mbsd_pub_baseball_fd_cattias_final.pdf)은
NDA로 데이터와 모델 비공개를 명시합니다. 손에 붙인 공과 손 최고속도 대리를
실제 공 이탈로 취급하지 않았습니다. 힘 한계를 늘린 최적화를 같은 능력 비교라고
해석하지 않았습니다. 상세 절·수치·공식코드 해시는 물리 검토 문서에 있습니다.

Moco의 control effort 적분과 MyoSuite의activation penalty는 기계적 양의 일
하드 상한과 다릅니다. Fmax가 같아도 근육이 일하는 거리/시간/탄성 에너지와
외부 입력이 바뀌면 일이 늘 수 있습니다. 일·순간파워·외력·reserve 에너지를
따로 제한·검증하지 않은 최적화 결과를 동일 능력의 향상으로 읽지 않습니다.

[PMGF 원문](https://arxiv.org/abs/2510.10496)의8개 특징 기반 fitness는 실제
수정 투구의 구속 결과가 아닙니다. 생성 동작이 문헌상 특징에 가까워지는 것과
구속 변화 예측은 다릅니다. 저자 notebook의 전체자료 재구성 시연 역시 독립
검증과 구분했습니다.

## 새로 확인한 실제 구속·동작 자료

[Takamido2026 원문](https://arxiv.org/abs/2605.05487)과
[고정 코드·자료 버전](https://github.com/takamido/Ball_speed_pred_cross_ind/tree/29aa44eee86eff5c1fc6f5e221cb9b16a0381f16)을
확인했습니다. 익명50명×5구의250개MAT를 실제로 내려받아 scipy.io.loadmat으로
파싱했습니다. 각X는101시간×15관절×3좌표,Y는TrackMan 초기 구속입니다.
선수별 파일 수·유한값·해시를 검산했고 코드/원자료는ignored artifacts에만 뒀습니다.

새 자료의 평균 기준 MAE0.400010914mph는0.643755165km/h입니다. 기존 OBP의
0.629742km/h와 단위를 맞췄습니다. 초기에 단위를 혼동한 비교는 철회됐으며
학습 검토 문서와 근거JSON에는 정정값을 남겼습니다.

이 원문의0.38 R²는 선수 평균 평가이고,0.91 R²는 같은 사람의 다른 투구를
학습에 넣은 미중심화 평가입니다.12설정 중outer test 선수 평균 점수로 최적
모델을 골랐으므로 독립 최종 검증으로 부르지 않습니다. 우리의 개인 내 중심화
문제와 직접 비교하지 않았습니다. PMGF의51명 자료와 같은 계열이므로 둘을
독립 자료로 합치지 않았고,OBP와 참가자 중복이 절대 없다고도 단정하지 않았습니다.

재사용 라이선스,좌표 단위,실시간 표본율,정확한 전처리·event 대응의 미확인을
남겼습니다. 시간 정규화101점에 실제10/20/30Hz를 임의 적용할 수 없습니다.
새 자료를 원래 필터 검증을 우회하는 수단으로 쓰지 않았고 외부 연락도 하지 않았습니다.

## 실제로 시험한 작은 모델 교체

새 대조는 무거운 GNN 학습 전에 비선형 관계 자체의 가능성을 보는 비용 제한
실험입니다. 예전과 같은399구98명,waveform20 입력,추가10/20/30Hz를 그대로
사용했습니다. 입력 변화와 모형 변화가 섞이지 않게 했습니다.

[Rahimi–Recht NeurIPS2007 원문](https://papers.nips.cc/paper/3182-random-features-for-large-scale-kernel-machines.pdf)의
random Fourier feature를 이용해64개 비선형 특징을 만들었습니다. 이는 야구에
검증된 논문 모델을 그대로 재현한 것이 아니라 명시적 커널 근사 방식의 작은
비선형 대조입니다. 전체 RBF·모든 신경망·근육모델의 성능을 대표하지 않습니다.

새 계획은 계산 전에 `93c95a8`로 커밋했습니다. 선수LOAO 바깥 검사와 훈련
선수만의inner5그룹 선택을 사용했습니다. 스케일,임의특징 매핑,회귀를 훈련
자료에서 정하며 검증 정답을 바꿔도 해당 선수 예측/선택이 같음을 테스트했습니다.
family/gamma/alpha는 안쪽 검증에서 고르고 바깥 점수로 다시 고르지 않았습니다.
null도 선택지였지만 비선형 모형이 모든 outer fold에서 선택됐습니다.

선형 대조는 이전waveform20의 예측을 세 조건에서1e-8 이내로 재현했습니다.
점수는 선수균등 평균이며,정답 평균은 회고적 평가에만 사용하는 oracle 비교입니다.
이는 실전에서 모르는 새 선수의 절대 구속을 미리 맞춘 모델이 아닙니다.

단위km/h입니다.20Hz에서 같은 입력의 선형 대조 대비0.013965km/h,
평균 기준 대비0.011087km/h 작았습니다. 그러나 선수별 오차차이 bootstrap95%
상한은 양수이고10Hz는 더 나쁩니다. **원래 합격 기준은FAIL**입니다. 좋아진
20Hz만 골라 채택하지 않습니다. 평균보다 나은 선수가48/98명이라 모든 개인에
유리한 결과도 아닙니다.

고정seed1개·64특징·제한된gamma/alpha만 시험했습니다. 같은 개발 자료에 대한
반복 분석이고 간접적인 동작 표현을 씁니다. 이 실패가 모든 비선형 모형의
불가능성을 뜻하지 않지만,이 결과로 신체 추천 모델을 교체할 근거도 없습니다.
기존3034_1의16.781km/h 차이는 여기서 다시 계산하거나 줄이지 않았습니다.

## 앞으로 채택할 구조와 보류할 것

권장 방향은 **관찰 예측,동작 생성,부하 검증,공 이탈 예측을 분리하는 구조**입니다.
한 모델의 좋은 숫자로 나머지 검증을 대신하지 않습니다.

1. 관찰 예측 후보는 실제 구속 자료와 고정 선수 분리/개인 내 지표로 평가합니다.
   RFF는 연구 후보로 보존하되 아직 추천 엔진으로 채택하지 않습니다.
2. 생성 모델은 가능한 동작을 제안하는 역할에 한정합니다. PMGF의 특징 fitness를
   실제 구속 gain으로 출력하지 않습니다. 현재는 생성·관절 개입을 구현하지 않았습니다.
3. 검증된 근육 경로와 외력/에너지 회계를 갖춘 제약 최적제어를 부하 검증기로
   검토합니다. OpenSim/Moco 엔진을 쓸 수 있어도 현재 부착·그립 모델을 정답으로
   유지한다는 뜻은 아닙니다. 보정과 같은 능력·일 조건 검증부터 필요합니다.
4. 실제 공 중심·접촉·이탈 관측을 연결해야 공속도 모듈을 채택할 수 있습니다.
   현재의 표면표식/손 최고속도/가상 공 초기화로 이 관문을 통과시키지 않습니다.

즉시 할 후속 검증의 우선순위는 새 실측자료의 사용조건·시간·좌표 정의를 확정해
동결된 평가기에 연결하는 것입니다. 공개 근거로 해소되지 않는 항목은 미확인으로
남겨야 합니다. 모델 복잡도를 늘려 작은 표본의 소수점 우위를 찾거나 실제 구속에
맞춰 힘·그립·release를 조정하는 경로는 채택하지 않습니다.

새 테스트6개 모두 통과했습니다. 전체316개:304통과,기존10오류,기존2skip,
assertion실패0입니다. OpenSim import9개와 기존근거파일 부재1개 오류 이름이
선행 단계와 정확히 같습니다. 새로 깨진 기존 테스트는 없습니다.

기존 추적700파일의 해시를 보존했습니다. 기존 테스트가 쓴coupled-body/model.xml은
생성본 보관 후 자기 변경만 복원했습니다. protocol/code/두 동결 입력의 해시와
선형 대조 재현을 확인했습니다. 원문·공식 코드의 접근/설치/라이선스 확인은 실행
성공과 구분했고,물리 모델 설치/학습/실제 개입을 수행했다고 주장하지 않습니다.

새 파일은 이 폴더의BENCHMARK_PROTOCOL/README/통합 보고서,benchmark.py/
test_benchmark.py/패키지초기화,physics/learning/hybrid의 검토와 근거,results/의
전체 예측/inner점수/판정/해시/로그입니다. 기존 문서·결과·코드·과학gate와
자동화 상태는 바꾸지 않았습니다. 문헌 에이전트의 격리 작업 커밋만 명시적으로
cherry-pick해 통합했고 원본 C3D/영상/MAT/논문 전문/제3자 코드는 올리지 않았습니다.
