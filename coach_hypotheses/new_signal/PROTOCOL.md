## A. 고정 모델과 선택

평가 대상은 이미 관측한 같은 선수 두 투구의 기록 구속 차이입니다. 절대 구속/미래 투구/개입 반응이 아닙니다. 사전식 투구 순서의 unordered 모든 쌍, 선수별 쌍 가중 합1, LOAO 외부 검사, 선수 단위 inner5그룹(modulo순서)을 씁니다. 후보는 null(0차이), stable7 선형, new48 선형, new48 RFF64 비선형 네 개만입니다. alpha10 고정, 절편0, inner 점수 동률은 이 순서의 단순한 후보를 우선합니다. 주 결과는 inner 선택기이고 외부 점수로 다른 family를 주 모델로 승격하지 않습니다.

선형은 훈련쌍 차이의 RMS로 스케일하고 기존 research_reset 목적을 그대로 풉니다. RFF는 훈련 투구만 선수균등 mean/SD로 표준화하고 고정 seed20261029, W~N(0,1)/sqrt(48), b~U[0,2pi], sqrt(2/64)cos(zW+b)를 씁니다. 변환은 각 투구에 적용한 뒤 쌍 차이를 구합니다. RFF의 쌍 차이도 훈련쌍 RMS로 스케일합니다. 평가 선수 정답과 다른 평가 선수의 입력은 적합/선택에 쓰지 않습니다. 단순 선형 쌍 차이를 비선형이라고 부르지 않습니다.

세 필터·모든 family·선택 결과를 보고합니다. 최소50선수/150고유투구, 누출/키/반대칭 검사,20Hz 선수균등 MAE<0기준,2000회 seed20261029 선수 bootstrap의95% 오차차이 상한<0,10/30Hz 비열등을 모두 만족해야 development_new_signal_pass입니다. 기존 scientific_gate는 변하지 않습니다. MAE<0.5와 절대오차p95<1은 별도1km/h 개발 점검으로만 보고합니다. 통과해도 같은 힘/일의 개입 효과, 안전성, 추천을 승인하지 않습니다. 실패하면 이 입력군의 추가 초모수 탐색을 하지 않습니다.

## B. 손–공 미분 지지 구간 검사

기존 Ozkaya pilot의 같은3파일/정적 보정을 재사용합니다. pilot.py SHA256=7c7c6b1183c5c9a38ddd16f6dac598e15fec50030d7232a08a7ffe5917747acc를 확인하고 명시한 로컬 파일에서만 함수를 불러옵니다. 기존 원본5개 해시는 pilot summary와 대조합니다. 전문 접근은 현재 웹 도구에서 막혀 기존 원문 감사와 저자 검색 초록의10% 거리 증가 대리 정의를 구별해 인용합니다. [자료 논문](https://doi.org/10.1038/sdata.2018.272).

학습−90~−45ms(10표본)를 유지합니다. 기존 평가−40~−5ms(8표본)는 첫 중앙차분의 이웃이 학습 마지막 표본과 겹칩니다. 새 평가−35~−5ms(7표본)의 로컬 차분 지지구간−40~0ms를 고정해 학습 표본과 교집합0인지 실제 검사합니다. 두 이벤트 규약 후보0/−1프레임을 모두 보고합니다. 원본 저자 필터/보간의 지지 구간은 미확인이므로 완전 독립 원시 관측이라고 하지 않습니다.

기존 강체 offset과 시간 선형 상대 offset 두 모델만 쓰며 평가 표식으로 fitting하지 않습니다. 새 평가 구간의 위치 RMSE/속력 MAE/속도벡터 RMSE를 모두 보고합니다. 기존8표본 점수와 새7표본 점수의 차이는 평가 구간 변경이지 개선량이 아닙니다. 새 공통7표본에서 두 모델의 차이만 비교합니다. 명목 규약의3파일 모두 위치/속력 비악화이고 평균이 엄격히 줄어야 pilot_joint_improvement이며 하나라도 악화하면 미채택입니다. 이 값도 공 표면 Ball 표식 재구성이고 공 중심 구속/새 투구 일반화/손가락 접촉/근육 능력이 아닙니다. 레이더와 비교하지 않습니다.
