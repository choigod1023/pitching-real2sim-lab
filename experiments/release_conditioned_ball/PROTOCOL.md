# 릴리스 조건과 여러 2D 공 후보를 검증하는 비교

- 이전 앱 추적기, 기존 출력에서 불확실한 릴리스 시점까지 가린 대조군, 릴리스 이후에만 여러 후보를 새로 연결하는 추적기를 같은 영상 구간·검출 영역·크기로 비교한다. 정확한 릴리스 시각 대신 원영상에서 먼저 표시한 분리 가능 구간의 끝을 쓴다. 그 프레임까지 출력하지 않는다. 가린 양성 프레임도 누락에 포함한다.
- 새 추적기는 밝기 변화와 원형 대비 후보를 한 프레임에서 함께 고려한다. 릴리스 가능 구간 직후의 3개 프레임에 여러 경로를 시작하고, 짧은 누락을 허용한다. 실제 검출점 4개 이상과 투구 방향 변위가 필요하다. 근접 점수의 경로들이 같은 프레임에서 다른 위치를 지지하면 보류한다. 점이 없는 프레임을 채우지 않는다. 경로 선택에 구속, RPM, 2D 기준 좌표를 쓰지 않는다.
- 같은 방식으로 릴리스 표식이 한 프레임 이르거나 늦을 때도 평가한다. 이 조건을 보고 영상마다 시간을 다시 고르지 않는다. 모든 좌표·구간을 결과 전에 고정한다. 개발 자료와 새로운 경기·카메라를 따로 집계한다. 같은 투구의 다른 카메라는 독립 투구로 세지 않는다.
- 가로 960px 환산 8px 이내를 일치로 센다. 일치, 기준 프레임에 반환한 다른 점, 누락, 공이 자유 비행하지 않는 것으로 판독한 프레임의 오검출을 별도 보고한다. 가림·미판독 프레임은 오검출 분모에 넣지 않는다. 중심 위치·카메라 전이를 보는 시험이며 구속 또는 3D 위치로 환산하지 않는다.
- 앱 기본값 채택 후보는 독립 투구 출처 최소 두 곳에서 기존보다 일치 수가 늘고, 어떤 독립 출처에서도 일치 수가 줄거나 확인된 오검출이 늘지 않아야 한다. 기존 검토 영상을 다시 쓴 결과, 표식만 가린 효과, ±1프레임 민감도는 별도로 해석한다. 새 경기·카메라 결과가 좋더라도 충분한 표본 전에는 배포하지 않는다.
