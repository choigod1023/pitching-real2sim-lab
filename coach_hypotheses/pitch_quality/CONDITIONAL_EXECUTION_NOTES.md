# 결과 계산 전 실행 명세 보충

원 프로토콜의 기준을 유지한다. 수집 코드와 모델 코드를 분리해 작성하는 중이며 아직 새 반복 표본의 연관성/모델 결과는 계산하지 않았다.

- 위치 제곱·교차항과 손잡이 상호작용은 **원필드에서 먼저 만든 뒤**, 각 연속 설계열을 학습 투수×구종 안에서 중심화하고 학습 내 편차로 표준화한다. 원위치를 먼저 중심화한 뒤 제곱하는 다른 모형은 시험하지 않는다.
- OOF 예측을 전부 모아 투수별 손실을 먼저 구한 뒤 투수 평균을 낸다. bootstrap도 같은 투수의 control/both 차이를 쌍으로 재표집한다. fold 단순 평균이 아니다.
- T/Q는 엄격 S/W 주분석의 분모에 남는 0이며, 공식 미스 플래그 민감도에서는 1이다. 입력 카운트는 pre_count다.
- gamePk 분할은 다른 경기 검증이고 시간 순 미래 검증은 아니다. 모델이 스윙 유도율 또는 관절 변화의 총효과를 추정한다고 주장하지 않는다.
- 연관성 계수는 전체 자료의 both 모델 재적합과 5개 fold 계수의 부호를 보고한다. 1 훈련 내 표준편차의 조건부 log odds이며 불확실한 API 물리 단위를 보정했다고 주장하지 않는다.

검사값 변조 시 학습 전처리와 기준 예측 불변, 타깃별 T/Q 차이, 수치 gradient, 게임 중복 부재, 투수 동일 가중 검산을 테스트한다.
