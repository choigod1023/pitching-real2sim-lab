# 시간순·비선형·타자 효과 구위 관측 실험 사전등록

2026-10-30. PR128의 미통과 결과와 기존 기준을 보존한다. 새 자료/모델 결과를 보기 전에 이 문서를 커밋한다. 아래는 후속 실험이며 기존 Real2Sim gate를 변경하지 않는다. 훈련·의료 조언 또는 실제 선수 효과 검증이 아니다.

## 자료와 시간순 분리

- 공개 MLB StatsAPI의 2025-06-01~08-31 모든 officialDate/R/Final 경기. 실제 schedule link와 원문 URL/bytes/UTC/hash/실패 보존. 최대3 worker·네트워크 실패 최대2추가시도, 우회/유료접근 없음. 기존 6/1~14 캐시는 검증 뒤 재사용한다. 모든 원문/행별자료는 ignored artifacts에만 둔다.
- 개발 적합 6/1~7/15, 선택용 검사 7/16~31. 최종 적합 6/1~7/31, 최종 검사 8/1~31. 날짜는 schedule officialDate다. 각 검사에서 그 이전 적합 자료의 20스윙·2경기 이상인 투수×FF만 포함한다. 검사 결과로 적격을 선택하지 않는다. 새 투수 일반화와 구분한다.
- 주분석은 포심 FF 비번트 스윙이며 엄격 S/W 타깃이다. 공식 비번트 swingMissStatus는 같은 행의 민감도다. T/Q를 분모에 남기며 이전 코드·ID·카운트·complete-case 기준을 유지한다. 단위 미확인 원필드는 무차원 통계 분석에만 사용한다. x0를 실제 release, spinDirection을3D축으로 바꾸지 않는다.
- 기존 collector의 날짜 인자를 일반화할 수 있지만 기본 6/1~14 실행/결과는 그대로 유지한다. 새 산출물은 이 폴더 또는 전용 artifacts에만 둔다. 전체 기간 수집은 가능하나 모델 선택 명령은 8월 행·타깃을 읽지 않는다. 수집/가용성 감사는 결과 연관성 계산이 아니다.

## 모형 고정

1. 여섯 모형: L0/L1=기존 선형 control/both 그대로(페널티1); G0/G1=아래 비선형 control/both, GB0/GB1=같은 비선형에 정규화 타자 절편 추가. 공통 투수 절편은 유지한다. 관측 연관성과 예측 비교이며 인과 fixed-effect 추정이라고 부르지 않는다.
2. 비선형 control: 원 speed의 cubic B-spline, 원 pX/pZ의 tensor cubic B-spline 및 이 열들과 타자 좌우의 상호작용, 타자 좌우 및 투구전 11개 카운트 더미. 각 spline의 내부 knot는 적합 자료의 1/3,2/3 분위수(중복제거), 양끝은 min/max다. 검사 범위를 벗어나면 학습 범위로 clip하고 개수를 보고한다. basis 첫 열을 제거한다. 위치 tensor는 full basis 외적의 첫 열을 제거한다.
3. both 추가열: spinRate/IVB/HB의 같은 spline, IVB basis×원 pZ, HB basis×원 pX; IVB/HB 및 해당 위치 상호작용 열과 투수 좌우·타자 좌우 상호작용. 원필드명 IVB=breakVerticalInduced/HB=breakHorizontal이며 물리 단위 확인을 뜻하지 않는다. 같은 basis로 control과 both를 만들고 모든 연속 설계열은 적합 투수 안에서 중심화·적합 편차로 표준화한다. 검사·타깃을 knot/표준화에 쓰지 않는다.
4. L2 페널티: 전체 절편0, 투수/타자 절편1, 연속/카운트 계수는 λ. 후보 λ={1,10}만 허용한다. 6/1~7/15 적합한 **GB0 엄격 타깃**의 7/16~31 투수동일가중 Brier가 작은 λ를 선택한다(동률1). 선택한 λ를 모든 G/GB 및 두 타깃에 공통 사용한다. 검사선택 기록/해시를 저장한 뒤에만 8월 모델 명령을 실행한다. 최종 결과로 knot수·λ·모형·기간을 바꾸지 않는다.
5. 합계 로지스틱 음의 로그우도+L2. 적합 단일 클래스는 실패로 처리하고 optimizer success 및 gradient를 보고한다. 테스트와 수치 검산은 실제 연구 판정과 분리한다. 학습 기준 예측은 학습 전체 미스율, 투수×FF의 Laplace(1,1) 비율이다. 처음 본 타자는 추가 절편0이며 그 검사 수를 기록한다.

## 두 질문과 사전 판정

- A: 비선형+타자 control(GB0)이 기존 L0보다 최종 검사 예측을 개선하는가.
- B: 같은 비선형+타자 모델에 spin/movement를 더한 GB1이 GB0보다 개선되는가. B가 미통과면 구위 추가모델을 채택하지 않는다. A만 통과하면 GB0를 연구용 기준 후보로 둘 수 있지만 선수 성능 향상이 아니다.
- 각각 최종 적격 검사 ≥2,000스윙·≥50투수, 관련 모형 및 여섯 최종 주모형 수렴, 비교모형(control)의 Brier−후보 Brier의 투수 cluster bootstrap2,000회(seed20261030) 95% 백분위 하한>0, 후보logloss<비교logloss, 후보Brier<투수평균을 모두 요구한다. 테스트·픽셀·통계적 상관으로 대체하지 않는다. 수집불완전·정합성 실패는 별도 technical 판정으로 보존하고 정상 통과로 보고하지 않는다.
- 모든 검사 예측을 모아 투수별 평균 손실 후 투수에 동일 가중한다. 데이터/게임/미스 수와 제외·clip·미지 타자·학습 분산·계수 안정성도 보고한다. bootstrap은 게임/시간 의존까지 해결한 보장이 아니다. 공식 타깃 민감도에서 유리한 결과로 주판정을 바꾸지 않는다.
- 개발 내 학습곡선: 7/16~31의 **동일 검사 투수/행**을 고정하고 학습을 7/1~15,6/16~7/15,6/1~7/15로 늘린 GB0/GB1을 비교한다. 가장짧은 학습에서도20스윙·2경기인 투수의 교집합만 사용하고 선택된 λ를 고정한다. 이것은 진단이며 모형 선택/최종8월검사 대체가 아니다. 표본이 증가하면 반드시 좋아진다고 가정하지 않는다.

## 스윙 선택과 신체 연결

별도 보조 분석은 모든 비번트 FF의 swingStatus를 타깃으로 같은 최종 split의 GB0/GB1을 비교한다(학습 적격20투구·2경기). 전자가 P(swing), 주분석은 P(miss|swing)이며 서로 다른 분모의 Brier를 직접 비교하지 않는다. 인과 보정이라고 부르지 않는다. 신체→회전/릴리스 필드의 정의·접근성과 Shibata2023/Kato2026/Yamaguchi2025의 직접 근거는 읽기전용으로 별도 감사한다. 회전축·접촉·힘·일의 관측 근거 없이 관절 추천이나 향상 영상을 만들지 않는다.
