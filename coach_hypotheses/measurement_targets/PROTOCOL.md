# 측정 우선순위: 입력 가정 폭 축소의 사전 프로토콜

2026-10-29. 구현과 계산 전에 이 파일을 커밋합니다. 선행 단계2 b5db6a9의
코드·프로토콜·결과·판정은 보존합니다. 단계3 개입 설계는 하지 않습니다.

같은 3034_1~5에서 prepare_case/speeds 벡터 API를 재사용합니다. 명목은
d0=.15m, 기존 BR, 손 마커20Hz, d_dot=0, 상대 로컬 offset=0입니다.
레이더 구속으로 조건을 선택하거나 중심·범위를 맞추지 않습니다.

기본 독립 가정은 d0~U[.10,.20]m, d_dot~U[-.5,.5]m/s,
BR 이동{-1,0,1}의 균등360Hz 프레임, 손 마커 필터{10,20,30}Hz입니다.
관절중심은 제공된20Hz 처리값을 유지하므로 필터 변화는 손 회전만 바꾸는 hybrid입니다.
원시 관절중심의 필터를 재구성하거나 필터의 실제 오차확률을 추정하지 않습니다.

거리/이탈/필터/상대운동을 각 명목값으로 정확히 고정하는 2^4=16조건을
계산합니다. 이탈고정은 현재 이벤트 명목에서 가정 불확실성을 제거하는 반사실적
완전관측 가정이며 진짜 이탈을 안다는 뜻이 아닙니다. 명목의 bias는 남습니다.
각 요인 단독 및 조합의 폭 감소를 전체16조건과 Shapley 평균 한계감소로 보고합니다.
Shapley는16조건의 시나리오 폭으로 계산하며 실제 측정의 정보가치가 아닙니다.

추가로 거리만 같은15cm 중심의 ±50/10/5/2/1mm 균등범위로 좁힙니다.
각 범위에 대해 나머지3요인을 기본대로 둔 조건과 모두 명목에 고정한 조건을
계산합니다. 중복조건은 공유합니다. 모든 고정 조건의 폭0은 자명한 가정 제거이며
정확도 증거가 아닙니다. 한 거리를 좁혀도 다른 처리 선택의 차이가 남는지 확인합니다.

각 투구·조건은 N=131072, seed20261029/20261030로 생성한 공통 난수
A/B 각각 N개를 결합한2N개에서 평균·2.5/50/97.5%분위수와 폭을 계산합니다.
같은 seed의 앞32768개씩을 별도 요약해 표본수 차이도 보고합니다.
MC 평균/양끝분위수/폭의 seed차이와 표본수차이를 숨기지 않습니다.
이 새 분석의 시나리오 목표는 모든5구의2.5~97.5%폭<=2km/h입니다.
이는 ±1km/h 시나리오 목표이며 실제 정확도1km/h 또는95%실증구간이 아닙니다.
기존 단계1/2의 합격 기준과FAIL은 바꾸지 않습니다.

명목점에서 dv/dd를 epsilon=1/.5/.25mm의 중앙차분으로 계산합니다.
속력(norm)의 미분과 속도벡터 미분을 구분하고 방향기여 상쇄를 허용합니다.
3개 epsilon의 기울기와 해석적 norm 미분을 검산하며 5구 최대 절대기울기의
역수로 국소1km/h 변화에 해당하는 보수적인 거리분해능을 제시합니다.
실제95%허용오차나 전역 정확도 요구라고 부르지 않습니다.
시점 API는3개 이산상태뿐이므로 fractional-frame을 임의 보간하지 않습니다.

모든 결과를 고정한 후에만 별도 recorded_comparison 함수를 호출합니다.
명목과 레이더의 차이는 조건 선택·추정 입력에 사용하지 않습니다.
새 함수는 원prior폭 재현, 요인별 고정, allfixed폭0, CRN·seed 재현,
거리mm단위, zerooffset, source/기존기준 해시보존, no-radar 입력을 테스트합니다.
관련 테스트와 전체 기존311개 테스트를 실행하고 알려진10오류·2skip과 구분합니다.
coupled-body/model.xml은 자기 실행의 쓰기만 해시로 확인해 복원합니다.
