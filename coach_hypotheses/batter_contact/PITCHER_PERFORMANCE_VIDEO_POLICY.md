# 사용자 정정: 투수 구위 향상과 연결된 영상

2026-10-30. 사용자가 원한 것은 타자를 세운 데모가 아니라, **투수의 신체 조정과 그에 따른 구위 변화가 연결된 투구 영상**이다. 이 정정이 이전 문서의 engineering/prediction 성공 시 데모 자동 표시보다 우선한다.

현재 PR129의1.49%는 미스 예측 Brier 감소다. PR130 영상은 투수 수정0이며 별도 타격을 배치한 조건부 데모다. 둘 모두 투수의 구위 향상 영상으로 제시할 수 없다. 기존 결과·영상은 이력으로 보존하지만 기본 실행에서 다시 생성하거나 표시하지 않는다.

기본 `python -m coach_hypotheses.batter_contact.run`은 검증된 투수 개입 영상이 없음을 보고하고 영상 태그를 출력하지 않는다. 별도 진단을 사용자가 명시적으로 요청하면 `--show-demo`로 기존 데모를 실행할 수 있다. 통계 분석을 다시 돌리거나 데모를 투수 향상 결과의 대체물로 쓰지 않는다.

앞으로 원하는 영상은 다음 연결을 보여줘야 한다.

- 같은 투수·기준 투구의 원래 동작과 수정 동작을 같은 시간·좌표에 겹친다.
- 어떤 관절 각도·위치·타이밍을 바꿨는지 표시한다.
- 검증된 신체→공 모델에서 나온 구속·회전축·움직임·방출 방향 중 실제 예측 가능한 출력을 표시한다. 입력 기록값을 개선 예측으로 바꾸지 않는다.
- 같은 힘 능력·일 예산 제약과 불확실성, 기준 투구 오차를 함께 평가한다. 미관측 항목은 미검증으로 남긴다.
- 타자 반응을 연결할 때 어떤 타자·스윙/상황에 대한 예측인지 밝힌다. 별도 선수의 기록이나 임의 배트를 동일한 실제 대결로 사용하지 않는다.
- 시뮬레이션의 조건부 향상 후보와 실제 선수에게 측정한 효과를 구분한다. 인간 개입 실험이 없다는 이유만으로 모든 예측 후보 영상을 금지하지는 않지만, 신체와 공 출력의 연결이 없는 데모는 후보가 아니다.

현재 이 연결을 만족하는 투수 구위 향상 후보는 확인하지 못했다. `athlete_candidate` 성공도 계속 차단한다. 새로운 구위 향상이 검증됐다고 주장하지 않으며 원래 연구 목표를 완료했다고 처리하지 않는다.
