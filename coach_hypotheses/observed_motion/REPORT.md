# 단계3 통합 결과: 전신 동작·관절 재생 영상·후속 가설

2026-10-29~30. 동작 비교와 원자료/정렬 감사를 두 에이전트에 나누고 부모가 영상·통합 검증을 수행했다. 사전 프로토콜 4664982를 먼저 커밋했다. 선수별 분리와 필터/불확실성 기준을 바꾸지 않았고 자동화를 재개하지 않았다.

## 무엇을 얻었는가

분석·영상·후속 질문 작성을 완료했다. 그러나 **모든 선수에게 공통으로 권할 자세 방향은 확인하지 못했다**. 단계2의 조건을 유지한 35쌍·23명을 분석했으며 기록 차이>=1km/h의 14쌍·11명도 별도로 보고했다. 이들은 구속·팔 부하로 이미 선택한 개발 자료이므로 결과가 전체 투수의 관계나 개인별 개입 효과를 뜻하지 않는다.

주 지표 네 개 모두에서 사전 탐색 조건(세 필터의 평균/구간 방향 일치와 각 필터 선수75% 방향 일치)을 만족하지 못했다. 이 조건은 탐색적 선별 규칙이며 가설 확증/동등성 검정/예측 gate가 아니다.

- 몸통−골반 피크 시차: 추가10/20/30Hz 평균 **-0.720 / +3.206 / +2.831ms**. 필터에 따라 평균 방향이 바뀌었다.
- FP10−BR 앞무릎 신전량 지표: 추가20Hz 평균 **-3.252°**. 16/23명(69.6%)이 음수여서 75% 조건을 충족하지 못했다. 세 필터의 평균 재표집 구간이 음수라는 점과 방향 일치 부족을 함께 보존했다. 반대로 '덜 펴라'는 처방을 만들지 않았다.
- 착지 골반–몸통 분리각: 추가20Hz 평균 **+0.624°**, 재표집 구간 **[-0.192,+1.481]°**로 0을 포함했다.
- 제공 팔 슬롯: 평균 **-0.450°**, 구간 **[-1.360,+0.423]°**로 0을 포함했다. >=1km/h 부분집합에서는 음수8/11명(72.7%)으로 역시 사전 기준 미달이다.

여러 쌍이 있는 선수의 차이를 먼저 평균한 뒤 선수를 동일 가중했다. 구간은 2,000회 선수 재표집이며 실제 측정 오차나 개입 효과의 신뢰구간이 아니다. 추가 필터 세 조건은 이미20Hz 처리된 자료에 대한 선택 민감도다. 보폭과 팔 슬롯 POI 값은 필터마다 같은 값이며 독립 세 번의 검증이 아니다. 모든 주/부가 지표와 선수별 수치는 [상세 결과](COMPARISON_FINDINGS.md), [comparison.json](results/comparison.json)에 남겼다.

## 실제 투구의 겹친 관절 영상

[선수830 영상](media/player_830_observed_overlay.mp4), [선수774 영상](media/player_774_observed_overlay.mp4)을 새로 만들었다. 원본 촬영 영상이나 새 힘 입력으로 전방 적분한 동작 수정 시뮬레이션이 아니다. 원래 두 투구의 처리 관절 중심을 재생한 파생 영상이며 주황색=빠른 기록, 파란색=느린 기록이다.

- 선수830: 1615_1 **137.438km/h**, 1615_2 **135.829km/h**, 기록 차이 **1.609km/h**. 사전의 가장 작은 동시 공학 오차(각 기록±0.25km/h·토크±0.5Nm·힘±5N)와 이벤트 이동에서는 비교가 유지됐다. 실제 오차가 이 범위임을 확인한 것은 아니다.
- 선수774: 1097_2 **123.919km/h**, 1097_3 **122.471km/h**, 기록 차이 **1.448km/h**. 같은 오차 조합에서는 비교가 유지되지 않았다. 이 사례도 숨기지 않았다.

각 영상은 XZ/YZ 두 시야에 같은 물리 축척으로 전신을 겹쳤다. 앞부분은 FP10 착지 기준의 실제 경과시간, 뒷부분은 제공 BR 이벤트 기준의 별도 진단이다. FP10 시점의 수평 엉덩관절 중점만 한 번 빼고 높이/이후 병진을 유지했다. 매 프레임 골반 중심화, 회전/스케일 적합, 시간 늘이기·압축을 하지 않았다. 제공하지 않는 머리·손가락·공·근육 좌표를 만들지 않았다.

빠른 기록 쪽의 FP10→BR 구간은 선수830에서 **158.4ms 대138.9ms(+19.5ms)**, 선수774에서 **208.3ms 대194.5ms(+13.8ms)**였다. 두 구간을 강제로 같게 정규화하면 이 차이를 지우므로 주 영상은 실제 시간을 유지했다. 이 두 사례만으로 더 긴 구간이 유리하다고 일반화하지 않는다.

화면의 각도는 현재 프레임의 제공 관절각(원 처리20Hz), 하단 부하는 기존 추가20Hz 피크다. 화면의 현재 무릎 각도 차이와 통계의 FP10−BR 신전량 차이는 서로 다른 값이다. 흰 연결선/거리 숫자는 고정 XY 정렬 후의 손목·앞무릎 위치 차이로, 직접 교정량/모델 오차가 아니다. FP10 기준으로 같은 시각이라도 BR까지 남은 시간이 달라 일부 차이가 투구 진행 단계에서 발생한다. 이를 구분하기 위해 BR 정렬 진단도 제공했다.

## 원자료와 정렬 감사

4개 원본 C3D 모두 m/360Hz/first_frame0이며 처리 landmarks와 프레임 수가 일치했다. source POINT label 순서가 선수 사이에 달라서 이름→index로 매핑했다. 선택 네 투구의 landmarks/joint_angles/joint_velos의 session_pitch+time 키는 일치한다. 좌표/각도는 유한하며 속도 테이블의 양끝 NaN은 영상에 사용하지 않았다.

CSV 시각은 소수 넷째 자리 반올림으로 frame/360과 최대44.45µs 차이가 있다. 영상 샘플링에는 확인한 정규360Hz 시계를 사용했고 이벤트 원값은 유지했다. 이것은 같은 원본/처리 파일의 시간 대응 확인이며 카메라 물리 동기 검증이 아니다.

raw 손목 마커 중점과 처리 wrist_jc의 중앙거리 차이는 약0.15~0.63mm였지만 BR 부근에는 수mm~10mm 수준의 차이가 있었다. 이는 처리/정의의 대응 진단이며 관절 중심의 실제 정확도가 0.63mm라는 뜻이 아니다. hand_jc와 RFIN도 동일점이 아니고, C3D의 0 잔차를 정확도 증거로 쓰지 않았다. 입력 해시는 [overlay_manifest.json](results/overlay_manifest.json)에 보존했다.

## 검산과 테스트

- 에이전트의 동작 차이/선수 평균/집계 독립 검산: **1,296개**, 최대 차이 **7.11e-15**.
- 부모의 원 좌표를 직접 보간한 전 프레임 검산: **16,184개 관절 위치 3D 벡터**, 최대 차이 **2.22e-16m**. 이는 코드 산술 검산이며 관측 정확도 검증이 아니다.
- 두 영상 각289프레임, 총 **578프레임 전체 디코드**. 두 시야와 한글/범례/각도·거리 표시를 대표 프레임에서 시각 확인했다.
- 새 테스트 **19개 통과**(분석11/영상8). 전체 **319실행 / 307통과 / 기존 오류10 / 건너뜀2**. 단계0 오류 ID와 동일하며 OpenSim 부재9개, 기존 로컬 산출물 부재1개다. 새 오류는 없다.
- 전체 기존 테스트가 자기 worktree의 model.xml을 바꾸어 최초 HEAD로 자기 파일만 복원했다. 기존 사용자/다른 작업의 파일은 변경하지 않았다.
- 에이전트 실행의 프로토콜 SHA는 CRLF, 부모/원 Git의 프로토콜은 LF여서 바이트 해시가 달랐다. 원래 실행 manifest를 보존하고 줄바꿈만 정규화했을 때 사전 텍스트가 같음을 통합 검증에 기록했다. 기준을 바꾸지 않았다.
- 피크 시차에 약1e-13ms인 비영값이 총4셀 있었다. 원래 엄격한0 집계는 보존하고 별도 수치0 진단을 기록했다. 전체10Hz의 양/음/0은 원래12/9/2, 수치0 진단은9/9/5다. 실제 타이밍 차이가 아니며 최종 플래그는 여전히 모두 미충족이다.

[통합 검증 기록](results/integration_verification.json)에 코드/해시/동작 및 영상 검산을 구분했다. 원본 C3D/촬영 영상/대량 CSV는 올리지 않았다. 저장한 MP4/PNG는 새로 그린 파생 관절 영상/대표 프레임이다.

## 좁힌 후속 질문과 현재 가능한 판단

후속 질문은 [HYPOTHESES.md](HYPOTHESES.md)에 설계했다.

1. 앞무릎 신전량과 구속·팔 부하의 관계가 개인별 새 세션에도 유지되는가? 신전량을 늘리거나 줄이라는 보편 처방을 전제로 하지 않는다.
2. 피크 시차의 필터 불안정성이 검출/평탄부/경계 문제인지, 재현되는 개인별 협응 차이인지 구분할 수 있는가?

새 날짜의 반복 자료와 독립 구속/동작/부하 오차 근거가 필요하다. 공개 자료로 정의·수치 감사는 더 할 수 있으나, 기존 자료를 재사용해 새 외부 검증이라고 하지는 않는다. 이번에 실제 선수에게 개입하거나 모집/외부 연락/자동화 재개를 하지 않았다.

기술 단계는 완료했지만 관측 관계의 미충족 기준을 낮춰 신체 개입 최적화로 넘기지 않았다. 실제 구속 예측 오차 감소나 훈련 성능 향상은 이번에 입증하지 못했다. 기존 scientific gate, 같은 능력/일, 실제 개입 효과와 추천 준비는 계속 미검증이다. 자료/파생 영상 이용은 README의 OBP 출처·CC BY-NC-SA 4.0 조건을 따른다.
