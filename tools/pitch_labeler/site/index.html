판독 기준

  1. 대상 투구를 확인합니다. 작업에 지정된 마운드에서 포수 방향 투구 한 번만 봅니다. 포수가 되던지는 공은 대상에서 제외합니다.
  2. 손에서 떨어지는 구간을 표시합니다. 마지막 확실한 접촉과 첫 확실한 분리를 지정합니다. 손에 가려 범위를 정할 수 없으면 판독 불가로 기록합니다.
  3. 모든 지정 프레임을 판독합니다. 자유 비행 중인 공이 보이면 중심을 클릭합니다. 아직 손에 있거나 이미 잡혀 자유 비행이 없으면 해당 버튼을 누릅니다. 가림·화면 밖·심한 흐림으로 공의 위치를 알 수 없으면 판독 불가로 남깁니다.
  4. 판독을 마치면 서버에 제출합니다. 파일로 작업하는 경우 결과 JSON을 의뢰자에게 보냅니다. 서로의 결과나 모델 출력을 보기 전에 각자 작업합니다. 키보드 ←·→로 이동하고 0은 자유 비행 없음, ?는 판독 불가를 표시합니다.
