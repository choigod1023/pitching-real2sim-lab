# 무릎 속도 부호 정정 사전 기록

최초 프로토콜053c222는 변경하지 않습니다. 이 정정은 첫 계산 뒤, 정정된 계산 전에
별도 커밋합니다. 예측 입력 수, 필터, 분할, alpha, 합격 기준은 바꾸지 않습니다.

최초 구현은 README의 각도·각속도 공통 표에서 knee flexion(+)/extension(-)를
읽고 제공 lead_knee_velo_x를 반전했습니다. 그러나 공개 자료에서 그 속도 열은
이미 신전 방향이 양수였습니다. 첫 테스트의 합성 자료에도 잘못된 부호 가정을
넣었으므로 테스트 통과만으로 이 문제를 발견하지 못했습니다.

원자료 joint_angles와 joint_velos를 session_pitch/time으로 일대일 연결하고
FP10~BR에서 **구속 없이** raw velocity와 음의 무릎 굴곡각 시간 미분을 비교했습니다.
유효402구에서 상관의 최소값은0.9998, 평균은0.9999였습니다. 같은 방향의 평균
MAE는1.6496deg/s, 반전하면352.1401deg/s였습니다. 시간 반올림과 미분/필터 차이가
있으므로 완전한 등식을 주장하지 않습니다. POI의 BR 신전 속도도 최초 반전한
속도와r=-0.9996으로 반대였습니다. 해당 감사는 레이더 구속을 사용하지 않습니다.

원본 CMO.v3s의 RT/LT_KNEE_ANGULAR_VELOCITY는 JOINT_VELOCITY를 계산하며,
최종 CSV까지의 모든 부호 변환은 공개 코드에서 확정하지 못했습니다. README 표와
실제 열의 부호가 일치한다고 단정하지 않습니다. 각도 미분은 감사용이며 제공 속도를
교체하거나 구속에 맞춰 선택하지 않습니다.

정정: 신전 속도=제공 lead_knee_velo_x, 최대 검색=FP10~BR로 고정합니다.
단위·명칭 회귀 테스트와 원자료 감사 함수를 추가한 후 세 필터를 모두 재실행합니다.
관측 구속/예측 성능으로 부호를 선택하지 않습니다. 결과가 나빠도 보존합니다.

첫 결과:98명399구, 추가20Hz 선수 내 MAE0.639438 대 평균 기준0.629742km/h,
사전 합격 기준FAIL. results_initial_protocol/에 원래 집계·상관·민감도·제외·해시와
부호 감사표를 보존합니다. 해당 결과를 정정된 신전 지표로 해석하지 마십시오.

이 정정은 자료 정의에 대한 후속 수정입니다. 최종 결과는 최초 사전등록과 동일한
분석이라고 숨기지 않고, 사후 정의 정정을 거친 분석으로 표시합니다.
