# 모델 교체의 작은 대조 실험

기존98명399구의 실패 결과를 알고 수행하는 후속 개발 실험입니다. 새로운 독립
확인 연구라고 주장하지 않습니다. 구현/계산 전에 이 문서를 커밋합니다.
기존stage1의 코호트·결과·합격 기준은 변경하지 않습니다.

질문: 같은20개 동작 입력에서, 비선형 관계를 허용하면 개인 내 구속 차이를 더
예측하는가? 이것은 물리 시뮬레이터·힘/일·신체 개입의 검증이 아니며 새로운
표현이나 정답 정의를 섞지 않습니다. 예측 입력은 이전에 동결한waveform20뿐입니다.
제공20Hz 신호에 추가10/20/30Hz를 적용한 세 조건을 모두 사용합니다.

후보: linear ridge와64개 random Fourier feature(RFF) ridge입니다.
[Rahimi–Recht NeurIPS2007](https://papers.nips.cc/paper_files/paper/2007/hash/013a006f03dbc5392effeb8f18fda755-Abstract.html)의
명시적 커널 근사를 작은 비용의 비선형 대조로 사용합니다. 이 방법이 야구에서
검증됐다는 뜻은 아니며 전체 RBF/모든 신경망을 대표한다고 주장하지 않습니다.

원래처럼 선수별 입력/정답 평균을 제거합니다. 입력 스케일은 매 훈련 fold에서만
선수균등 가중으로 구합니다. RFF는sqrt(2/64)*cos(z*W+b)이며 고정seed20261029,
W 원소는N(0,1)*gamma/sqrt(20), b는U[0,2pi]입니다. gamma는0.5/1/2만 사용합니다.
매핑 후에도 선수별 특징 평균을 빼고, 추가 분산 표준화는 하지 않습니다. 같은
변환/매핑을 검사 입력에 적용하며 검증 정답은 적합/표준화/선택에 쓰지 않습니다.

ridge 목적은선수균등Σw*(y−Zβ)^2/2+alpha*||β||²/2이며,
alpha=.01/.1/1/10/100/1000입니다. 매핑 특징과 선형 특징의 스케일이 다르므로
최적alpha를 같은 정규화 크기라고 해석하지 않습니다. 선형 대조는 이전waveform20
모형과 같은 목적/스케일이며 수치 재현도 확인합니다.

outer 선수LOAO, 훈련 선수만의inner5그룹 CV로family/gamma/alpha를 함께 고릅니다.
null(예측0)도 포함하며 동률은null,그다음linear,그다음작은gamma/큰alpha입니다.
RFF와linear의 자체 inner 선택 결과도 전부 보고합니다. outer 점수로 좋은family를
골라 주 결과를 바꾸지 않습니다. 주 결과는inner에서 고른selector입니다.

합격은 원래scientific_gate를 그대로 호출합니다. 선수>=50/투구>=150,누출없는
전처리·선수 비중복,20Hz 선수균등MAE가 같은 평균 기준보다 낮음,오차차이2000회
선수bootstrap95%상한<0,10/30Hz에서도 평균보다 나쁘지 않음을 모두 요구합니다.
이 기준을 못 넘으면 새로운 예측 코어로 채택하지 않습니다. 넘더라도 이 개발
자료만으로 인과·훈련 효과·개인 자세 추천이 검증됐다고 하지 않습니다.

새 공개50명 자료는 별도 문헌/파일 감사로 다룹니다. 라이선스,좌표 단위,실시간
표본율과 후보 선택 검증이 끝나지 않은 데이터를 새 기준을 통과시키는 데 쓰지 않습니다.
기존근육/관절모델·그립·이탈·힘을 실제 구속에 맞추지 않습니다.

누출 검사,훈련 전용 스케일,학습신호가 있는 합성 비선형 대조,전처리 해시,
선형 대조의 재현과 기존 전체 테스트를 확인합니다. 새 코드는 이 폴더에만 만들고
