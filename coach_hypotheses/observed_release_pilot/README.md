# 관측 손–공 표식 연결 pilot

기존3034와 다른 공개 자료에서 손과Ball 표식이 같은 C3D에 있는 것을 확인하고,
3개 던지기의 학습에 쓰지 않은 시간 구간을 평가했습니다. 상대운동을 더한 식은
위치와 속력을 동시에 일관되게 개선하지 못했습니다. **공 중심 구속 정확도나
실제 투수 성능 향상은 검증하지 않았습니다.**

사용 자료: Ozkaya 등, [Scientific Data2018](https://doi.org/10.1038/sdata.2018.272),
[Figshare collection4017808](https://doi.org/10.6084/m9.figshare.c.4017808).
초보 여성의 야구공 오버암 던지기로, 숙련 투수의 마운드 피칭 검증과 구분합니다.
다운로드 원본에 표시된 데이터 라이선스는CC0입니다. 새results/는 그 자료의 표식
강체적합·예측·요약 결과이며 원본C3D/CSV/영상/논문전문은 포함하지 않습니다.
저장소의 기존OBP 파생 결과의 CC BY-NC-SA 조건과 다른 출처임을 구분합니다.
코드는 저장소 MIT 조건을 따릅니다. 훈련 또는 의료 조언이 아닙니다.

Ball은 반사테이프 표면점으로 취급합니다. 중심/회전과 독립적인 실제 이탈 시각은
미확인이고, 구속표 단위도 미확정이어서 레이더 비교를 하지 않았습니다. 첫 표본
시각0초라는 C3D 표준과 실제producer 규약은 별개이므로 두 시각 후보를 모두
보존했습니다. 어떤 후보도 예측 오차가 좋다는 이유로 정답으로 고르지 않았습니다.
