- Pause all gain searches. Fit subject geometry/mass using only user2/session3034 pitch3034_1 and metadata; do not read speed into fitting functions.
- Apply one frozen geometry to pitches3034_2..5. These previously explored development pitches are reuse checks, not a new blind external test.
- Baseline: previous per-trial geometry and nominal masses. Mass-only: same geometry scaled to participant mass (ball unchanged). Calibrated: train-pitch fixed segment geometry + least-squares constant shoulder attachment coordinates in the torso frame + scaled subject mass.
- No dynamic translation joints added to hide fit errors. Keep grip15cm,20Hz marker filter and supplied BR fixed. No outcome-tuned timing or inertia changes.
- Padded observations support endpoint differentiation. Inverse controls from those derivatives; actual FOH RK4 integration with no state resets. Compare both input resolutions2880/5760Hz on test3034_4, independently of speed ranking.

No measured speed, ground force or candidate ranking enters the optimization. Require optimizer convergence. Use the identical reconstructed table for body and arm inputs. Keep original segment_axes geometry policy and all original tests; separate outputs. This is a bounded reconstruction assumption, not recovery of unique hidden full-precision data. Validate synthetic rounded signals and report speed/change errors even if worse.
