# 릴리스 직후 공 관측 역추적 사전 계획

- 기존 앱의 녹화 분석을 기준으로 삼는다. 기존 좌표와 적합 플래그를 그대로 유지한다. 대상은 원영상 판독으로 먼저 표시한 릴리스 상한 다음 두 프레임에서, 기존 앱이 점을 반환하지 않았고 이후 적합점보다 앞선 빈 프레임이다. 접촉이 남을 수 있는 구간과 궤적 중간에는 새 점을 넣지 않는다.
- 대상 뒤 1~2프레임 안에서 시작하는 연속된 적합점 4개가 필요하다. 첫 두 점과 실제 영상 PTS로 일정 영상 속도를 추정한다. 다음 두 점은 추정에 사용하지 않으며 각각 가로 960px 환산 5px 이내에서 예측을 지지해야 한다. 네 점의 검출축 진행 방향은 양수여야 하고 첫 두 점은 960px 환산 2px 이상 떨어져야 한다. 대상부터 네 번째 적합점까지 프레임 간격 최댓값이 최솟값의 1.5배를 넘으면 건너뛴다.
- 역방향 예측은 후보 탐색에만 쓴다. 기존 앱의 해당 프레임 RGB·시간차 검출 후보가 예측에서 5px 이내에 있을 때 실제 후보 중심을 추가한다. 거리 차가 1px 이내이면서 후보 중심이 서로 3px 넘게 떨어지면 추가하지 않는다. 기존 앱이 고른 적합점은 전체 경로 선택에 이미 사용되었으므로, 다음 두 점을 속도 추정에서 제외해도 독립된 센서 검증은 아니다. 추가 좌표는 기존 속력 맞춤에 포함하지 않는다.
- 사용한 영상은 회귀로만 보고한다. 이전에 누락이 알려진 아카데미 #2는 원인 비교용이다. 미사용 MLB 경기와 별도 야외 투구는 검출 결과를 보기 전에 손 겹침, 흐림, 배경 혼잡, 탐색 영역을 영상으로 확인해 선택한다. 릴리스 범위, 평가 중심점, 공이 없다고 확실히 판독된 프레임, 모호한 프레임, 고정 탐색 영역, 파일 해시를 독립 판독으로 고정한다. 기준점이나 레이더 기록은 후보 생성에 넘기지 않는다.
- 앱 적용에는 Prime 카메라 22의 기존 일치 24개를 동일 좌표로 유지하고, 미사용 MLB와 야외 두 출처 각각에서 기존 대비 릴리스 직후 일치가 최소 1프레임 늘어야 한다. 두 출처의 전체 프레임에서 잘못 찍은 점과 공이 없는 프레임의 오검출은 각각 증가하면 미통과다. 960px 환산 8px 이내를 일치로 센다. 누락, 잘못 찍은 점, 공이 없는 프레임의 오검출을 별도로 집계하고 영역 밖 기준점도 분모에 포함한다. 기존 경로를 변경한 경우 출처별 성능과 무관하게 미통과다.
- 카메라 영상 좌표 복구 실험이다. 구속, 3D 릴리스 위치, RPM, 무브먼트, 신체 개입 효과는 별도 검증이 필요하다. 미통과 시 결과와 실패 이유를 기록하고 앱 변경은 보류한다.
