# 동기화 손–공 원자료 확보 기준

공개 야구 자료에서 같은 투구의 후면·측면 고속 원영상과 구속·RPM·무브먼트 기록을 찾는다. 논문에서 촬영했다는 설명과 실제 내려받을 수 있는 자료를 구분한다. 기존 자료와 이미 수행한 계산은 재사용한다. 요청·구매·로그인 우회·저자 연락은 하지 않는다.

원자료 목록, 공개 논문·보충자료·공식 소스에서 투구 식별자, 두 시야의 동기화 근거, 촬영 시계, 손끝 가시성, 길이/카메라 보정, 공 결과의 정의와 접근 권한을 각각 확인한다. 미확인을 사실로 채우지 않는다. 손–공 부분모델의 검증 가능성과 전신·근육 개입의 검증 가능성을 분리한다. 초기 탐색에 임의의 구속 차이 제한을 추가하지 않는다.

적격 자료를 확보하면 원본 해시와 판독 시각을 먼저 고정한다. 손/공 위치·이탈은 구속·RPM·무브먼트 목표값으로 조정하지 않는다. 모델 입력과 제외 평가 구간을 분리하고 같은 투구의 관측과 예측을 비교한다. 손 모델이 만든 상대3D를 보정된 전역3D 관측으로 쓰지 않는다. 출력 기록을 입력한 비행 재생을 성능 예측으로 보고하지 않는다.

자료가 일부만 공개됐다면 실파일의 무엇이 있고 없는지 확인해 기록한다. 독립 원본·같은 투구 연결이 없는 영상이나 시연은 모델 검증용으로 승격하지 않는다. 적격 자료가 없으면 새 구속/RPM/무브먼트 예측 오차와 개선 영상을 만들지 않는다. 공개 원자료·얼굴 영상·모델 가중치·개인 경로는 ignored artifacts에만 둔다. 코드가 필요할 때만 구현하고 검사한다. 문서·집계·파일구성 검증 결과는 한국어 보고서로 남긴다.
