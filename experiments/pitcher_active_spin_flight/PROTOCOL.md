# 투수별 포심 유효 회전율과 같은 구속 쌍의 비행 비교

1. 직전 Hawk-Eye 비교의 2025-04-01과 2025-09-28 Statcast 파일과 포심 쌍을 그대로 쓴다. 같은 경기·투수의 구속 차이 1.0 km/h 이하만 평가하고, 기록상 IVB 동률은 방향 점수에서만 제외한다.
2. [Baseball Savant의 직접 측정 방식](https://baseballsavant.mlb.com/leaderboard/active-spin?year=2024_spin-based)의 시즌·투수·포심 `active_spin`을 `player_id`로 연결한다. `alan_active_spin_pct`는 비행 유래 값이므로 제외한다. 주 입력은 두 평가 날짜에 앞선 2024 시즌의 포심 30구 이상 선수 평균이다. 30구는 소표본 평균을 거르기 위해 정한 조건이다. 같은 선수가 던진 모든 포심에 그 비율을 공통 적용한다.
3. 전체 쌍은 시즌 평균이 없으면 이전의 100% 모델을 그대로 적용한다. 2024년 평균이 있는 선수의 쌍만으로도 RPM 기준·100%·평균 모델을 같은 분모에서 비교한다. 후향적 확인으로만 2025 시즌 전체 평균을 사용한다. 후향 표본에는 평가 대상 투구가 포함될 수 있으며 2024년 결과와 구분한다.
4. RPM 부호, 직전 광학 2D 축·100%, 광학 2D 축·2024 평균, 백스핀 고정·2024 평균을 비교한다. 모든 모델은 직전 100% 조건과 같은 릴리스 위치·구속·추정 속도 방향, 항력, 공기 밀도, 시간 적분을 사용한다. 새 평균은 양력계수 계산의 유효 RPM만 바꾼다. IVB 변화 방향과 변화량 MAE, 쌍에 포함된 고유 투구의 IVB·홈플레이트 앞면 높이 MAE를 보고한다.
5. 이전에 고른 제이슨 애덤의 두 포심을 그대로 사용한다. Statcast의 적합 궤적, 2D 회전 방향·100% 모델, 2D 회전 방향·2024년 평균 모델을 같은 좌표에서 겹친다. 투구별 3D 회전 벡터나 자이로 성분의 관측으로 해석하지 않는다.
