## 화면 및 저장 변경

기존의 ‘공 위치가 맞나요?’는 손에 있는 공도 클릭하게 만들 수 있었고, ‘아직 손에 있음 / 이미 잡힘’은 서로 다른 상태를 합쳤다. 공의 상태 네 가지를 먼저 고르고, 날아가는 중에서만 위치 입력을 연다. 손/잡힘/판독 불가에는 좌표를 기록하지 않는다. 입력 시점이나 모델 후보로 상태를 자동 확정하지 않는다.

또한 사용자가 F177→178을 지정해도 비교 사진은 자동 후보 F176→177을 보여주던 불일치를 수정했다. 직접 지정한 유효한 두 프레임을 우선 표시하고 사진 이동과 지정값이 같은 구간을 가리키도록 했다. ‘지정한 범위(미검증)’와 자동 후보를 구분한다.

디자인은 기존 작업대의 색·서체·원본 영상 배치를 유지한다. 공 상태 버튼에 설명을 붙이고 선택 상태를 테두리와 텍스트로 표시한다. 영상 내용을 주 시각 자료로 사용하며 별도 장식은 추가하지 않는다. 기존 unslop 저작자 표기를 유지한다.
