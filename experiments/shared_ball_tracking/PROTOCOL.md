# 여러 출처의 동일 2D 공 추적 비교

- 앱의 녹화 후 BallTracker/OfflineBallReview를 기존 기준으로 사용한다. 새 후보는 현재 영상의 원형 대비를 4개 크기에서 보고, 앞뒤 1·2·4프레임의 밝기 변화와 결합한다. 같은 앱의 시간 연결기와 같은 검출 구간에서 기존 후보 추출과 비교한다. 모델별로 해상도, 영상 구간, 이미지상의 검출 범위를 다르게 주지 않는다. 검출 범위는 영상을 본 사람이 투구 진행 방향과 카메라 시야로 정한다.
- 영상당 같은 파라미터를 사용한다. 960px 또는 원본이 더 작으면 원본 가로 길이로 디코딩하며, 투구별 속도·RPM·공 중심을 입력하지 않는다. 영상에 기록된 PTS 순서와 시간은 2D 경로 연결에만 쓴다. 슬로모션의 기록 시간을 실제 공 비행 시간으로 사용하지 않는다.
- Prime은 기존 영상 좌표, Rapsodo는 원본 실루엣 원호 적합, MLB는 기존의 독립 영상 판독, Delft와 새 영상은 원영상 판독을 사용한다. 어느 참조도 완전한 실제 좌표는 아니다. 공이 보이는 프레임, 명확히 자유 비행 공이 없는 프레임, 가림·미확인을 분리한다. 입력 영상, 좌표 및 판정은 결과를 보기 전에 고정한다.
- 기준 좌표의 허용 거리는 가로 960px 환산 8px다. 각 출처별 일치/보이는 프레임, 표시 점의 거리 및 명확한 공 부재 프레임의 오검출을 보고한다. 그 밖의 프레임에는 정오를 추정하지 않는다. 채택하려면 평가 가능한 모든 출처에서 일치율이 낮아지지 않고, 최소 두 출처에서 늘고, 명확한 부재에서 오검출이 늘지 않아야 한다. 출처 단위의 작은 탐색 표본으로 모델 일반화나 구속 정확도를 확정하지 않는다.
