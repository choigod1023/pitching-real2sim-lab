# 같은5구에서 입력 가정을 좁혔을 때 구속 폭이 얼마나 줄었는가

2026-10-29. 거리를 먼저 측정할 가치는 크지만 거리 하나만 좁혀서는 현재의
시점·손 회전 처리 차이를 없애지 못합니다. 거리 ±1mm만 가정하면 여전히
11.32~17.19km/h의 시나리오 폭이 남았습니다. 나머지3요인을 명목에 고정하고
거리 ±2mm를 가정했을 때는5구 모두 폭2km/h 이하라는 새 시나리오 목표를 충족했습니다.
실제 관측을 추가하거나 실제 구속 오차를 줄인 결과는 아닙니다.

## 방법과 보존한 경계

사전 프로토콜 커밋 ba5c9c816971d3d83f8597777860ed6ba53b7a6d 뒤에 구현·계산했습니다.
같은3034_1~5에 단계2의 prepare_case/speeds를 그대로 재사용했습니다.
모든 조건에서15cm/기존BR/20Hz/상대운동0의 명목값은 그대로입니다.
거리/이탈/필터/상대운동 정확고정의16조합과, 거리±10/5/2/1mm를 단독으로
또는 다른3요인고정과 함께 적용한8조건을 합쳐24조건입니다. ±50mm는 기본 조건입니다.

N131072의A/B 두 행렬을 합친262144개에서 분위수를 구했습니다.
seed20261029/20261030의 공통 난수를 모든 조건에 공유했습니다.
입력의 중심·범위·조건을 레이더에 맞추지 않았습니다. 구속을 읽지 않는 기존 loader로
계산하고 scenario_results.json과 CSV를 먼저 고정한 뒤 최종 별도 함수로만 기록을 읽었습니다.

기본 가정은 d0~U[.10,.20]m, d_dot~U[-.5,.5]m/s, 이벤트±1이산프레임,
손 마커10/20/30Hz입니다. 상대 로컬 offset은 모든 조건에서0입니다.
360Hz의±1프레임은±2.778ms입니다. API가3개 시점만 제공하므로 소수 프레임을
임의 보간하지 않았습니다. 처리된 관절중심은 제공20Hz 그대로이고 손 회전만 원시 마커의
필터를 바꾸므로 hybrid 처리입니다. 필터20Hz 고정은 처리 선택을 하나로 제한한 것이며
최적 필터나 실제 측정 정답을 찾아냈다는 뜻이 아닙니다.

아래 폭은 모두2.5~97.5% 시나리오 분위수의 차이입니다. 실증95%신뢰구간이나
실제 오차 허용범위가 아닙니다. 요인 독립 가정과 입력 범위에 조건부입니다.

다른 처리 선택 차이가 사라지지 않습니다. 이 범위 역시 실제 처리 bias의 실측값은 아닙니다.

거리의 조건부 가치가 가장 컸고 필터·시점의 조합 제한도 필요했습니다.
이는 실제 측정 비용이나 실측 정보량을 포함하지 않은 시나리오 폭 감소 배분입니다.
상대운동 범위±0.5m/s에서 가치가 작다는 결과를 실제 손가락·공 상대운동의 무관함으로
일반화할 수 없습니다.

## 국소 거리 분해능과 새 시나리오 목표

명목에서 dv/dd는3034_1~5 순서로0.32320/0.30519/0.30133/0.30883/0.28283km/h/mm입니다.
epsilon1/.5/.25mm 중앙차분과 해석적 norm 미분의 최대 차이는
2.10e-8km/h/mm입니다. 속도벡터 미분의 norm을 속력 미분으로 대신하지 않았습니다.
방향 기여가 상쇄될 수 있으며 합성 예에서 벡터 미분norm이 양수여도 속력 기울기가0인
조건을 테스트했습니다.

5구 최대 절대 국소기울기의 역수는3.094mm입니다. 이는 다른 입력이 고정된 명목 근처에서
1km/h 변화를 구분하려는 모델 거리의 국소 분해능 지표입니다. 실제95%허용오차나
전역 정확도1km/h의 보장으로 해석하지 않습니다. d는 모델의 손 프레임축 오프셋이므로
실제 공 중심의 관측을 같은 좌표·시점·손목 정의에 연결하는 과정도 필요합니다.

다른3요인을 정확히 고정한 거리±5mm의 최대폭은3.071km/h로 새 목표 미충족,
±2mm는1.228, ±1mm는0.614km/h로 충족입니다. 정확 거리/시점/필터고정에서
상대운동만 남기면 최대0.265km/h입니다. 이것들은 **±1km/h 시나리오 목표**의
가치 판정이며 실제 측정 정확도 검증이 아닙니다. 유한한 이탈 시점 측정정밀도나
소수프레임 요구는 이번 이산모델만으로 제시하지 않습니다.

## 명목 bias와 수치 정밀도는 별도다

명목은113.415/113.860/112.537/113.647/108.731km/h로 유지됐습니다.
3034_1의 기록130.196km/h와 명목의16.781km/h 차이도 그대로입니다.
새로운 실측 입력을 넣지 않았기 때문에 폭을 줄였다고 이 차이가 줄지 않습니다.
기본 시나리오 평균의 명목 대비 변화는+2.204/+0.562/−1.418/+0.137/−0.612km/h이며
평균을 보정된 명목으로 대체하지 않았습니다. 모든 조건의 평균 변화와 분위수는 CSV에 있습니다.

두seed 차이의 전체최대는 평균0.0497, 양끝분위수0.0826, 폭0.0938km/h입니다.
같은A/B행렬의 앞32768개씩과131072개씩 비교한 최대차이는 평균0.0305,
양끝분위수0.1518, 폭0.1513km/h입니다. 작은 처리·요인 차이를 실측 효과라고
부르지 않았습니다. 원래 단계2의 초기수렴FAIL·후속결과·기준을 바꾸지 않았습니다.
