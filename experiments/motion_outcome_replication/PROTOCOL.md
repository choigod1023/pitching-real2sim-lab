# 기존 영상의 동작 경로와 공 기록: 사전 고정 절차

이번 작업은 검수 기능을 개발하지 않는다. 기존 원영상·관절 추론·투구별 기록을 읽고 같은 선수·같은 구종의 두 투구 차이를 비교한다. 기존 결과를 이미 본 개발 자료의 재분석이며, 경기 제외 평가도 전향적 독립 검증으로 부르지 않는다. 선수에게 특정 자세를 처방하거나 인과·훈련 효과를 주장하지 않는다.

## 자료와 제외

1. 주 자료는 `skenes-ff-motion-cohort-20261110`의 기존 7쌍·14영상, `cohort.json`, `motion-review.json`, `pose.npz`, `pose-provenance.json`이다. 원본 해시와 동일 투구 ID를 대조한다. 이 자료는 구속 차이 1 km/h 이내에서 RPM과 수직 무브먼트 차이가 큰 쌍을 미리 고른 표본이다. 차이의 존재 자체를 새 발견으로 세지 않는다.
2. 기존 스킨스 속도 비교 및 다른 투수 자료는 영상·관절 시계열·시각 대응·구속/RPM/pfx 기록이 같은 투구로 연결되는 경우 별도 집단으로만 계산한다. 구속 선별군과 RPM 선별군을 섞지 않고, 중복 영상은 새로운 표본으로 세지 않는다. 원본 프레임 대응을 확인하지 못한 캐시는 수치 근거로 쓰지 않는다.
3. 첫 자유 공이 보인다는 기존 판독이 없는 영상은 이탈 기준 동작 계산에서 제외한다. 첫 자유 공은 손가락 접촉 종료의 실측값이 아니다. 누락을 보간하거나 보이지 않는 손·골반 회전을 생성하지 않는다.
4. 결과는 기록 구속(km/h), 총 RPM, `pfx_z` 및 `pfx_x`(ft×30.48, cm)다. 좌우 부호를 유지하고 수직 무브먼트를 총 낙차나 구위의 단일 점수로 바꾸지 않는다.

## 고정할 동작 특징

같은 탐지기 캐시와 신뢰도 0.5 이상, 화면 범위 및 기존 분절 길이 검사(최소 8 px, 영상별 중앙값의 0.35~2배)를 그대로 사용한다. 각도는 화면상의 2D 투영이다. 골반·몸통의 축회전이나 근육 힘으로 해석하지 않는다.

- 앞무릎 포함각, 투구 팔꿈치 포함각, 골반 중점→어깨 중점 기울기, 투구 어깨→손목 방향을 계산한다.
- 첫 자유 공 이전 −150~−33 ms에서 유효 각도의 중앙값을 사용한다. 한 시점의 최고값을 골라내지 않는다.
- 같은 구간의 초반 −150~−100 ms와 후반 −83~−33 ms 중앙값 차이도 계산한다. 각도 차이는 ±180°로 감싼다. 총 8개 특징이다.
- 구간의 관측 프레임 중 80% 이상 유효해야 한다. 전체 구간은 최소 4개, 초반·후반은 각각 최소 2개를 요구한다. 시간 축은 원본 PTS를 사용한다.
- 두 영상의 첫 자유 공을 각각 −1/0/+1프레임 이동한 9개 조합을 모두 보고한다. 8개 이상 조합이 계산되고 범위가 0을 넘나들지 않을 때만 해당 쌍의 방향이 안정적이라고 표시한다. 이 범위는 공학적 민감도이며 95% 신뢰구간이 아니다.

## 경기별 반복과 변화 예측

같은 선수의 동일 선별 집단 안에서만 비교한다. 특징별 쌍 차이를 경기별 중앙값으로 요약한다. 최소 3경기에서 계산할 수 있고, 각 경기의 쌍 중앙값 범위가 모두 0의 같은 쪽일 때만 관찰 방향의 반복 후보로 표시한다. 이 조건은 표본 통계적 유의성이나 자세 수정 효과를 뜻하지 않는다.

예측은 경기 하나를 완전히 제외하고 나머지 경기로 학습한다. 최소 2개 학습 경기와 2쌍이 필요하다. 각 특징과 결과를 따로 사용하며, 합격한 조합만 보고하지 않는다. 단일 특징의 원점 통과 ridge(고정 λ=1)를 쓴다. 학습 특징 절댓값 중앙값을 척도로 사용하되 1° 미만이면 1°로 둔다. 각 학습 경기의 총 가중치를 동일하게 한다. 기울기 부호나 크기를 결과에 맞춰 제한하지 않는다. 학습/평가 관측이 부족하면 0 변화로 fallback하고 따로 센다.

동일 평가 쌍에서 무변화 0과 학습 경기의 평균 결과 차이(선별 편향 대조)를 모두 비교한다. 모든 경기에서 두 대조보다 MAE가 낮고, 경기 평균 MAE도 두 대조보다 낮고, 모든 경기의 학습 기울기 부호가 같고, 관측 부족 fallback이 없을 때만 예측 후보로 표시한다. 최소 3평가 경기를 요구한다. 릴리스 민감도에서 관찰 방향의 반복까지 통과한 경우만 후속 연구 후보로 제시한다. 다중 탐색과 작은 표본 때문에 통과하더라도 검증된 처방이나 일반 공식으로 승격하지 않는다.

## 산출물과 검산

전체 결과/제외/해시 장부는 로컬 ignored artifacts에 보존한다. 함수 단위 합성 테스트, 직접 scalar 식에 의한 각도·ridge 검산, 원영상 해시 및 전체 영상 디코드를 검사한다. 같은 시간의 원본에 실제 유효 관절을 겹쳐 보여주며, 미관측 선을 연결하지 않는다. 원영상·실제 투구 행·얼굴이 보이는 영상은 커밋하지 않는다. 반복 후보가 없으면 실패를 숨기지 않고 대표 비교 영상에 ‘반복 미확인’을 명시한다. 원래 3034 자료 재실행은 0회다.
