# 단계3: 전신 관측 차이·겹침 영상·후속 가설 사전 기준

2026-10-29. 새 동작 분석과 렌더링 전에 커밋한다. 기존 구속 예측 gate, 단계1/2 결과와 기준은 바꾸지 않는다. 사용자 승인으로 에이전트의 동작 비교와 원자료/정렬 감사를 병렬 수행하고 부모가 영상·통합 검증을 맡는다. 자동화는 재개하지 않는다.

## 고정 코호트와 관측 지표

단계2 summary.json SHA256 32ca2146b29a31ddf212988711705832e05366a0300300999f4535ed5fa0e490에서 independent_event_stable인 35쌍·23명을 사용한다. 원래 기록 차이>=1km/h 14쌍은 사전 부분집합이다. 기존 metrics.csv SHA256 c555d826ce78fc0ca20bb6a2be017ffc6df8fa84e8911001a3250ac3ea4b04f4를 재사용하고 새 신체–구속 회귀모델을 학습하지 않는다. 구속/팔 부하로 이미 선택된 개발 자료이므로 동작 연관성도 조건부·탐색적이다.

주 지표 네 개는 sequence_lag_ms(몸통 피크−골반 피크), lead_knee_extension_deg(FP10 각도−BR 각도), hip_shoulder_sep_fp10_deg, arm_slot_poi_deg다. 부가 지표는 pelvis_peak_dps, torso_peak_dps, lead_knee_peak_extension_dps, stride_reported, wrist_height_br_m다. 보폭은 원문 단위를 보존하며 임의 %/m 변환하지 않는다. 손목 높이는 공 중심 높이가 아니다. 추가10/20/30Hz 전체를 보고하고 최고 성능/가장 큰 차이 조건을 고르지 않는다. 제공 full_sig는 이미20Hz 처리됐다는 점도 유지한다.

모든 차이는 기록 구속이 빠른 투구−느린 투구다. 같은 선수의 여러 쌍을 독립 표본으로 세지 않는다. 각 선수의 쌍 차이를 먼저 평균한 뒤 선수균등 평균·중앙값·범위·양/음/0 방향 인원과 2,000회 선수 재표집 구간(seed20261029)을 보고한다. 이는 개입 효과 또는 측정 오차의 신뢰구간이 아니다. 선수별 부호가 세 필터에서 바뀌는 수를 별도 보고한다. 14쌍 부분집합도 똑같이 보고하되 주 집합의 결과를 대체하지 않는다.

주 지표에서 세 필터의 선수균등 평균 방향과 재표집 구간의 방향이 같고, 모든 필터에서 같은 방향의 선수 비율>=75%이면 탐색적 후속 검증 대상으로 표시할 수 있다. 0은 일치로 세지 않고 모든 유효 선수를 분모로 쓴다. 이 표시는 통계적 가설 확증/다중 비교 보정/예측 합격이 아니다. 해당 지표가 없으면 없다고 보고한다. 공통 방향이 부족한 경우 개인별 조건부 관계와 보상 동작을 분리하는 가설을 설계하며 유리한 자세 규칙을 만들지 않는다. 1~2개의 후속 질문을 제안하되 효과가 반드시 존재한다고 가정하지 않는다.

## 영상 고정 사례와 정렬

사례는 원래 선정된 선수830의1615_1(빠름)/1615_2(느림), 선수774의1097_2(빠름)/1097_3(느림) 두 쌍으로 고정한다. 전자는 작은 공학 오차 조건에서도 유지됐고 후자는 유지되지 않았다는 사실을 둘 다 표시한다. 새로 더 유리한 사례로 교체하지 않는다.

실제 processed landmarks의 양팔·양다리·골반·흉곽 관절 중심을 골격으로 그린다. 없는 머리/손가락·공 중심·근육을 만들어 표시하지 않는다. 이것은 관측 기반 재구성 재생이며 같은 입력 힘으로 전방 적분한 새 시뮬레이션이나 원 카메라 촬영 영상이 아니다. 기록 구속을 새 예측값으로 표시하지 않는다.

주 영상은 FP10 정렬의 실제 경과시간이다. 두 투구의 FP10을0으로 두고 각자의 실제 BR 시각과 이후 표본을 그대로 사용한다. 속도를 맞추기 위한 시간 늘이기/압축은 하지 않는다. 비교 시간의 공통 유한 지지 구간만 사용한다. 별도 BR 정렬 영상을 진단용으로 제공하며 시간축 이동을 명시한다. 두 정렬의 역할이 다르므로 하나를 실제 시계 동기 검증으로 부르지 않는다.

좌표는 실험실 축을 보존한다. 자세 겹침에는 각 투구 FP10의 양 엉덩관절 중점의 수평 위치를 한 번만 빼는 고정 병진을 사용하고 그 벡터(mm)를 화면/메타데이터에 표시한다. 수직 위치와 이후 골반 병진은 보존한다. 매 프레임 골반 중심화, 회전/스케일 최적화, 동작을 맞추는 등록은 하지 않는다. 화면의 관절 간 거리는 이 정렬 조건 아래 관측 차이이며 직접 선수 교정량/모델 오차가 아니다.

영상은 전신을 같은 좌표/시각에 겹쳐 두 개 이상의 시야에서 보여주고, 각 투구/기록 km/h·BR·정렬 방법·각도/위치 차이·팔 부하 비교·동일 근력/일 미검증을 표시한다. 상대 속도를 느리게 재생하더라도 실제 경과시간과 배율을 명시한다. 제공 관절각과 별도의 관절 중심 기하각은 이름/정의를 분리한다. 각도/위치 차이는 실제 두 투구의 관측 비교다.

원본 C3D/metadata와 처리 신호의 ID·단위·360Hz·프레임 수·이벤트 지지·유한값을 검사한다. raw 손목 마커 중점과 처리 관절중심 차이는 대응 진단이며 골 중심의 정확도 검증이 아니다. 파일 해시와 고정 병진/샘플링/시야를 메타데이터에 기록한다.

## 완료 검증과 한계
