# 첫 계산 후 고정한 추가 진단

주 PROTOCOL의 기준·집단·판정은 바꾸지 않는다. 첫 계산에서 쌍 내부 시야는 14/14 통과했지만 기준 영상과의 경기 간 정합은 5월11일 2쌍만 확인됐다. 특징점 지지가 부족하므로 다른 경기의 실제 카메라가 다르다고 단정하지 않는다. 같은 타자/아웃의 속도 집단 7쌍(무릎 변화 평가6쌍) 진단은 MAE 9.416→8.207cm였지만 시점에 따라5.505~15.195cm로 달랐고, 작은 학습 집합에서 4공변량이 무릎 변화를 보간해 독립 성분을 구분하지 못했다.

이 결과를 숨기거나 주 분석을 통과시키지 않고 두 원인을 추가 점검한다. 이 문서는 추가 계산 전 커밋한다.

1. **통제 변수 수 진단:** 이미 지정한 pair_camera_only 집단에서 구속·RPM 두 변수만 사용하는 M0와 +무릎 M1을 계산한다. 원래 네 변수 모델과 같은 쌍·fold·시점·단위·벌점·누락 규칙이다. 카운트를 뺀 결과는 카운트 차이가 통제됐다고 말하지 않는다. 전체 조건부 결과의 대체가 아니며 채택은 원래 주 기준만 따른다. 모든 시점과 두 특징의 결과를 남긴다.
2. **기준 시야 선택 진단:** 새로운 카메라 임계값을 만들지 않고 기존 28영상의 배경 특징을 모두 서로 비교한다. 날짜/쌍ID/좌우 순으로 첫 적합 cluster에 넣되, 양방향으로 모든 기존 cluster 구성원과 원래 기준을 통과해야 넣는 complete-link 규칙을 쓴다. 어느 cluster도 안 맞으면 singleton을 만든다. 결과를 보고 가장 성능 좋은 cluster를 고르지 않고 전체 cluster의 영상·경기·엄격 상황 쌍 수를 보고한다. 같은 cluster에 속한 엄격 상황 쌍이 같은 선별 집단에서 3경기 이상이면 원래 조건부 계산을 별도 진단으로 실행한다. 미만이면 반복 평가 불가로 남긴다.

모든 원래 주 결과와 실패는 그대로 보존한다. 배경 정합과 군집은 3D 보정이 아니며, 광고/관중/조명 변화와 한 프레임만 본 한계가 남는다. 양쪽 영상 시점의 독립 전체 조합이나 실제 관절 측정 오차 구간으로 해석하지 않는다.
