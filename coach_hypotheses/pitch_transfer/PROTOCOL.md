# 다른 투구 적용 검증: 계산 전 고정 계획

2026-10-30. PR135의 3034_1 조건부 후보를 다른 투구에 적용한다. 새 결과 계산 전에 이 문서를 커밋한다. 기존 결과와 기준은 수정하지 않는다.

## 대상과 입력

- 기준 후보: PR135 clean_restore.json.gz의 selected.parameters 33개. 보관 원문 SHA256을 검증하고 읽는다. 3034_1의 재계산은 기준 재현 검사이며 새 발견으로 세지 않는다.
- 같은 선수: 3034_2, 3034_3, 3034_4, 3034_5 모두 포함한다.
- 다른 선수: 메타데이터의 우투수 숫자 ID 순서에서 user2 다음 user72와 user90. 각각 사전식 첫 두 투구 2996_1/2, 3044_1/2를 포함한다. 과거 개발 자료이며 독립 외부 검증이라고 부르지 않는다.
- 20Hz 손/전완 처리, 제공 관절 중심, FP10~BR, 기존 11520Hz 요청 격자를 유지한다. 같은 선수 4구의 기존 reference NPZ는 해시와 출처를 기록하고 재사용한다. 다른 선수는 ObservedPitch.sample을 사용한다. 결측/실패는 기록하고 조용히 대체하거나 제외하지 않는다.
- 같은 선수의 분절 길이는 첫 투구에서 정하고 고정한다. user2는 원래 기준 NPZ lengths를 쓴다. 다른 두 선수도 첫 투구의 마커 길이를 고정한다. 매 투구의 원래 길이와 차이를 보고한다. 각 기준 입력은 이 고정 기하에서 inverse_controls로 재계산한다. 일반 질량/관성, 15cm 그립, 주석상 BR을 유지하고 기록 구속으로 선택하지 않는다.

## 서로 다른 적용 방법

1. **정규화된 규칙의 고정 전이(주 분석)**: 33계수, BR 기준 마지막 60ms의 세 Hann 구간, 수신 투구의 성분 최대값 2% 척도와 최대값 투영을 그대로 적용한다. 동일한 절대 힘 또는 동일한 해부학적 자세 수정은 아니다.
2. **절대 입력 차이의 고정 전이(보조)**: 원래 후보의 실제 입력 차이를 BR 상대 시각으로 선형 보간한다. -60~0ms 밖에서는 0이다. 수신 기준 입력에 더하고 수신 입력 최대값으로 투영한다. clipping 크기를 보고한다. 좌표계와 마커 회전축의 선수 간 해부학적 동등성은 미확인이다.
3. **투구별 재탐색(별도 분석)**: 같은 선수의 4구에서만 실행한다. 고정 수정안의 전이 성공과 혼동하지 않는다. 기존 33변수/2% 범위, 입력 최대값 투영, A 제약, 자세 제약을 유지한다. 시작점은 0과 원래 계수이며 시작점마다 최대 120개 고유 coarse/fine 쌍 계산, 총 최대 240쌍이다. SLSQP maxiter=12, eps=1e-5, ftol=1e-12. 목적은 fine 구속 차이 최대화다. 일 제약은 허용 epsilon 없는 원래 cap-cost로 최적화하고, 입력 생성이 강제하는 중복 peak 제약만 최적화 부등식에서 제외한다. 최종 검사는 원래 A 전체 gate를 그대로 사용한다. +0.5km/h 같은 성공 하한을 강제하지 않는다. 시간/평가 예산 종료는 수렴이나 불가능 증명이 아니다.

## 사전 판정

- 실제 같은 초기 상태에서 힘 입력을 전방 RK4 적분한다. source dt와 dt/2 두 해상도를 모두 평가한다. 중간 상태를 관측 자세로 되돌리지 않는다.
- 각 전이의 합격은 두 해상도 모두 A 전체 힘/일 gate와 자세(최대 회전 3도, 공 중심 변위 20mm, 이탈 방향 1도), 동일 초기 상태를 통과하고 구속 차이가 양수여야 한다. 차이가 두 해상도의 기준/수정 절대 속력 차이 합보다 커야 하며 두 해상도 gain 차이는 0.001km/h 이하여야 한다. 양의 구속 차이만으로 합격시키지 않는다.
- 같은 선수 전이 성공은 4/4 합격, 다른 선수 전이 성공은 4/4 합격일 때만 선언한다. 일부 통과는 개별 조건부 통과로 보고한다. 재탐색 결과로 고정 전이 판정을 바꾸지 않는다.
- A는 총 순 일과 root 힘 벡터 최대값을 제한하지 않는다. B 별도 판정, 총 순 일 변화, root 힘 벡터 최대값 변화, 그룹별 일도 보고한다. 어느 결과도 생리학적 능력 또는 모든 힘/일 비증가를 뜻하지 않는다.
- 선택된 결과는 저장한 힘과 초기 상태로 독립 재적분하고 accounting을 재계산한다. baseline은 항상 유효 fallback이다. 모든 실패와 최적화 기록을 보존한다.

## 해석과 영상

기록 구속은 원래 투구의 참고값이다. 가상 수정 투구의 정답이 아니므로 수정 구속이 기록값에 가까워진 것을 예측 오차 감소라고 부르지 않는다. 실제 선수 효과, 95% 효과 구간, 근육 능력, 관절 안전, 편안함, 구위/제구 개선은 미검증이다. 손/공 직접 관측과 실제 개입 자료가 필요하다. 원본 C3D/CSV/영상은 커밋하지 않는다. CC BY-NC-SA 4.0 및 OBP 인용을 유지한다.

조건부 통과 후보가 새로 발견되면 같은 투구 원래/수정 신체를 같은 시각과 좌표에 겹친 영상을 만든다. 전신 회색 부분은 관측 재생이며 팔·손·공만 실제 가상 적분이다. 단순 그래프나 타자 시연으로 대체하지 않는다. 전체 디코드와 대표 프레임을 검사한다. 원래 후보만 통과하고 다른 투구는 실패하면 새 향상 영상이라고 만들지 않는다.
