# 신체→공 연결 근거와 관측 가능성 감사

2026-10-30. 시간순 실험 사전등록 `59ae41da8c5f605689a87f4e81a017240539ba38`를 읽고 작성했다. 최신 origin/main `63fc06c2c37b9af55c48d341a5c5e39d8a6deb2e`에서 만든 별도 worktree에 명시 선행을 fast-forward했다. 이 문서는 문헌·필드 정의·기존 기록의 대조이며 새로운 선수 분석, 모델 적합, 신체 개입 또는 물리 시뮬레이션 결과가 아니다. PR128의 미통과와 기존 Real2Sim gate를 유지한다.

**현재 바로 가능한 것은 공 원필드의 무차원 관측 예측 평가와 기존 관측/재구성의 오차 감사다. 같은 투구의 검증된 접촉·3D 회전·근육 힘·기계적 일이 연결된 자료는 확인하지 못했다. 시간순 구위 모델이 통과해도 관절 수정량이나 동일 힘/일에서의 구속 향상으로 번역할 수 없다.**

## 확인·가정·미확인의 구분

- **확인**: 실제 읽은 공식 정의, 초록/본문의 명시적 기술, 고정 선행 커밋의 로컬 기록과 코드 경로다. 공개 페이지 접근과 원자료 획득은 구분한다.
- **가정**: 아래 추가 관측 설계와 수학적 평가 후보다. 아직 구현하거나 실측 검증하지 않았다.
- **미확인**: 유료/403 전문, 미확보 원자료, 문서화되지 않은 StatsAPI 경로의 물리 단위·좌표·시간 기준이다. 그럴듯한 값 범위나 비슷한 변수명으로 채우지 않는다.

`SOURCES.json`에는 확인 범위·재사용 여부·실제 직접 GET의 UTC/상태/bytes/SHA256과 읽은 로컬 기록의 해시를 담았다. HTTP 200도 전문임을 보장하지 않으므로 content 검토 범위를 따로 적었다. 원문 응답 본문·행별 선수 자료는 이 산출물에 저장하지 않았다.

## 1. 토크와 공 회전을 실제로 연결한 근거

### Shibata 등 2023

[논문 DOI](https://doi.org/10.1016/j.jbiomech.2023.111603), [PubMed 초록](https://pubmed.ncbi.nlm.nih.gov/37126885/), [출판사 preview](https://www.sciencedirect.com/science/article/pii/S0021929023001720), [저자 게시 PDF](https://researchmap.jp/nifsbaseball-kanoya/published_papers/42164792/attachment_file.pdf).

**접근 범위:** PubMed 초록은 확인했다. 출판사 검색 색인의 preview/부분 발췌도 확인했지만 페이지 직접 열기와 저자 PDF는 403이었다. 따라서 이번에 전문을 확보했다고 쓰지 않는다. 검색 색인의 방법 발췌에는 공 가속도로 공에 작용한 힘을 계산한 역동역학 수식이 보이지만, 전체 처리·동기·회전 산출 절차를 검증하거나 재현하지 못했다.

**직접 근거:** 7명의 손가락·손목·팔꿈치·어깨 운동학/역동역학 토크에 SVD를 적용했다. 높은 구속당 회전수(SPV)와 어깨 내회전 중심의 토크 패턴, 낮은 SPV와 수평내전 중심 패턴이 관련됐다. 개별 손가락만으로 회전을 설명하기 어렵다는 관측 근거다.

**제한:** 토크는 역산값이며 개별 근육 힘이나 신경 제어의 직접 측정이 아니다. SVD 분해가 인과적 토크 기여나 근육 synergy의 생리적 증명을 뜻하지 않는다. SPV 정규화는 동일 구속·동일 힘 능력·동일 기계적 일을 실험적으로 통제한 것이 아니다. 교정 개입·새 선수 예측의 검증으로 사용하지 않는다.

**공개 모델/자료:** 확인한 링크에서 투구별 원시 좌표·동기화 파일·회전 정답 및 실행 가능한 재현 코드/모델을 확보하지 못했다. 수식이 공개 색인에 보인다는 사실과 실행 가능한 공개 모델/데이터가 있다는 주장은 다르다. 데이터가 비공개라고 확정하는 것도 아니다. 외부 요청·연락·유료 접근·403 우회는 하지 않았다.

### 기존 확인 문헌의 재사용

- **Shibata 온라인 2022/권호 2025**, [DOI 10.1080/14763141.2022.2125823](https://doi.org/10.1080/14763141.2022.2125823): 기존 초록 확인 범위를 재사용한다. 13명의 센서 공에서 추정한 접선 힘 성분과 SPV가 관련됐다. 이는 직접 손가락 힘 훈련이나 같은 일의 개입 검증이 아니다. 상세 원자료/코드는 미확인이다.
- **Yamaguchi 2025**, [공개 본문](https://pmc.ncbi.nlm.nih.gov/articles/PMC11950353/), [DOI 10.1038/s41598-025-93632-y](https://doi.org/10.1038/s41598-025-93632-y): 기존 전문·보충파일 감사 기록을 재사용한다. 6명의 마찰 조건 개입은 손가락–공 미끄러짐·회전·구속·릴리스/도착 지표가 함께 달라질 수 있음을 보여준다. 원자료는 합리적 요청 방식이며 기존 보충파일에서 우리 모델을 검증할 투구별 보정 좌표를 확보하지 못했다. 송진 조건을 처방하지 않는다.
- **관련 상지 분석 2025**, [DOI 10.1038/s41598-025-12298-8](https://doi.org/10.1038/s41598-025-12298-8): 기존 전문 확인을 재사용한다. 8명에서 마찰과 팔 경로/구속의 보상이 함께 나타났다. 손속도²/곡률반경은 부하 대리지표이고 관절토크·근육 힘·일의 측정이 아니다. 앞 실험과 연결된 자료를 독립 대규모 재현으로 세지 않는다.
- **Kato·Yanai 2026**, [원문·부록](https://journals.sagepub.com/doi/pdf/10.1177/17479541251378897), [DOI 10.1177/17479541251378897](https://doi.org/10.1177/17479541251378897): 기존 전문 확인을 재사용한다. 투수 간과 투수 내 관계가 달라질 수 있다는 MLB 관측 근거다. 공 지표–헛스윙 관계와 신체→공 전달 검증은 별개이며 이번 모델의 개선을 보장하지 않는다.

## 2. 실제 release·extension·접근각·회전축의 정의와 현재 입력

근거는 [Savant CSV 공식 사전](https://baseballsavant.mlb.com/csv-docs), [Active Spin 공식 설명](https://baseballsavant.mlb.com/leaderboard/active-spin), [Spin Direction 공식 설명](https://baseballsavant.mlb.com/leaderboard/spin-direction-pitches), [Arm Angle 공식 설명](https://baseballsavant.mlb.com/leaderboard/pitcher-arm-angles)이다. 같은 이름의 다른 API 경로가 동등하다는 문서는 확보하지 못했다.

1. **릴리스 좌표:** Savant `release_pos_x/z/y`는 feet의 릴리스 위치다. 현재 파서에는 이 세 필드가 없다. 보유한 StatsAPI `coordinates.x0/y0/z0`를 실제 손–공 이탈 위치로 바꾸지 않는다. 릴리스 이벤트·좌표 원점·축·참조평면을 직접 확인한 같은 투구 자료가 먼저다.
2. **Extension:** 공식 CSV의 `release_extension`은 feet다. 보유 경로는 `pitchData.extension`이며, 문서가 보증한 동일 경로/정의는 아니다. 기존 53,950투구 감사에서 1개 결측이 있었다는 기록은 가용성 근거일 뿐 단위 검증이 아니다. 이번 사전 모델에 임의 추가하지 않는다.
3. **속도·가속도 기준:** CSV의 `vx0/vy0/vz0`는 y=50 feet의 ft/s, 가속도도 해당 기준의 ft/s²로 설명한다. 현재 보유 `vX0/vY0/vZ0/aX/aY/aZ`의 단위·기준을 그대로 확정할 수 없다. `startSpeed`는 기존 공개 화면 코드로 mph 표시만 확인했으며 참조 위치/시점은 미확인이다.
4. **VAA/HAA:** [2025년 1차연구](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2025.1557145/full), DOI [10.3389/fspor.2025.1557145](https://doi.org/10.3389/fspor.2025.1557145)의 방법·표에서 공 속도 벡터의 수직/수평 투영 접근각 정의를 확인했다. 현재 파서에는 직접 접근각 필드가 없다. 9개 궤적 모수에서 각도를 유도할 구조적 재료는 있지만, 공통 길이/시간 단위·축·기준평면·plate 도달 시각을 검증하기 전 물리 각도를 산출할 수 있다고 승인하지 않는다. y=50의 초기 속도 각도를 plate 접근각으로 쓰거나 release→plate 직선 기울기로 대체하면 다른 양이 된다.
5. **3D 회전·active spin:** 공식 Active Spin 설명은 릴리스 3D 회전벡터를 쓰는 직접 측정과 궤적 역산을 구분한다. 직접 측정 방식은 2020년 이후 가능하다고 설명한다. 일반 CSV `spin_axis`는 2D X–Z 각이며, 현재 보유 `breaks.spinDirection`의 정의도 미확인이다. RPM과 단일 각도만으로 3D벡터·gyro·active spin을 유일하게 복원하지 않는다. 리더보드 집계를 우리 투구 키별 직접 관측으로 붙이지 않는다.
6. **SSW·심 방향:** 공식 Spin Direction은 초기 속도/plate 위치에 기반한 실제 움직임과 spin 기반 움직임을 구분해 표시한다. 그 차이는 직접 심 방향·그립·손가락 힘의 측정이 아니다. 현재 입력에는 직접 3D 회전·심 방향이 없어 SSW 크기나 원인을 식별하지 못한다.
7. **Arm angle:** 공식 단일 릴리스 팔각도는 몸의 정보이지만, 현재 파서에는 없고 전신·전완·손목·손가락 시계열이나 관절 힘의 대체값도 아니다.

StatsAPI의 기존 경로별 단위 미확인 상태는 [기존 감사](../pitch_quality/FIELD_DEFINITIONS.md)와 같다. 공식 사전의 확인은 새 CSV 다운로드/샘플 매칭이나 StatsAPI 물리 단위 통과를 뜻하지 않는다. 이번 temporal 모델은 사전등록한 원필드의 무차원 관계만 평가한다.

## 3. 기존 저장소에 실제로 연결된 자료

아래는 선행 커밋의 문서·코드를 읽어 대조한 것이다. 기존 수치를 새로 계산하거나 새 원자료를 받은 것으로 보고하지 않는다.

- **MLB feed:** `pitch_quality/mlb_feed.py`의 `NUMERIC_PATHS`는 속도·extension·회전/움직임·궤적 모수를 보존한다. `FIELD_DEFINITIONS.md`는 팔·손·그립·전신 운동학이 같은 투구에 연결되지 않았다고 명시한다. OBP와 동일 선수/투구가 아니므로 임의 결합하지 않는다.
- **OBP 반복 투구:** [PAIRED_DATA_SOURCES.md](../../PAIRED_DATA_SOURCES.md)는 100명·411투구의 신체 운동학과 기록 구속 연결을 감사했다. 별도 직접 공 3D/회전 정답 연결은 미확인이다. 제공 역동역학 부하 지표는 개별 근육·인대 힘, 힘 능력 또는 일정한 전신 일을 뜻하지 않는다. [관측 비교](../observed_motion/COMPARISON_FINDINGS.md)의 고정 35쌍·23명에서 주 자세 네 지표의 사전 탐색 플래그는 모두 미충족이다.
- **같은 투구의 영상 손–공 후보는 존재:** [HAND_BALL_OBSERVATION.md](../../HAND_BALL_OBSERVATION.md)와 [HAND_BALL_LINK_FINDINGS.md](../../HAND_BALL_LINK_FINDINGS.md)는 별도 computer-vision 투구에서 손과 공 후보를 연결했다. 가림·시간 정렬·공 중심 편향이 남고 접촉 정확도 gate를 통과하지 못했다. '손–공 자료가 전혀 없다'고 표현해서는 안 된다. 다만 이 자료에 직접 spin/심 방향/힘/일이 검증되어 연결됐다는 기록은 없다.
- **세션 3034 모델:** [WHOLE_CHAIN_FINDINGS.md](../../WHOLE_CHAIN_FINDINGS.md)는 익명 선수 2의 3034_1~5에서 검증된 직접 공 궤적이 없다고 명시한다. 별도 Prime/영상 투구의 손–공 보정 결과를 이식하지 않았다. 지면 외력 수지와 팔 위치에도 불일치가 남는다.
- **근육·손목 진단:** [WRIST_MUSCLE_FINDINGS.md](../../WRIST_MUSCLE_FINDINGS.md)와 [WRIST_RESIDUAL_FINDINGS.md](../../WRIST_RESIDUAL_FINDINGS.md)는 출처 모델의 근육 파라미터와 정적/샘플별 힘 배분 진단을 다룬다. 선수 실측 근력·연속 활성화/건 동역학·동일 양/음의 일·회전 정답 검증이 아니다. 잔차가 남아 구속 향상 탐색 진입 실패를 유지한다.
- **접촉 모델과 문헌 자료:** [CONTACT_EVIDENCE_FINDINGS.md](../../CONTACT_EVIDENCE_FINDINGS.md)는 공개 전문/보충파일을 확보했지만 별도 투구에서 모델을 검증할 원시 연결 묶음은 확보하지 못했다고 기록한다. 공 중심 선형 스프링의 변위는 손가락–공 표면 미끄러짐과 다른 양이며 그 중심력으로 자전 토크를 만들지 않는다. [COMPLIANT_PROTOCOL.md](../../COMPLIANT_PROTOCOL.md)는 spin이 초기값만 유지됨을 명시한다.
- **추가 공개 EMG 후보:** PAIRED_DATA_SOURCES의 van Trigt 자료(11명×15회)는 별도 영상/EMG/MVC 후보로만 확인됐고, 투구별 정답 연결 검증이 남는다. 대용량 ZIP을 받거나 현재 데이터와 합치지 않았다.

## 4. 지금 평가할 수 있는 것과 다음 연결의 통과 조건

**현재 입력으로 가능한 평가:** 사전 시간순 분리의 Brier/log loss, 선수 동일 가중 손실 차이, strict S/W와 공식 미스 민감도, 미관측/결측·clip·새 타자 수, 계수/기저 안정성, 별도 P(swing)와 P(miss|swing) 평가다. 이는 부모 프로토콜의 모델 작업이며 이 감사에서 실행하지 않았다. 기존 손–공 재투영/시간 정렬 민감도·역동역학 잔차도 관측/수지 진단으로 유지할 수 있다. 이를 실제 spin/구속 예측 정확도라고 이름 바꾸지 않는다.

**다음 자료의 가정된 최소 연결 요건:**

1. 선수·세션·투구 키와 공통 시간축으로 전신/팔/손가락, 공 중심·표면/심, 릴리스 이벤트를 연결한다. 해상도·fps·노출 동기·좌표 보정·가림과 이탈 시간 오차를 기록한다. 문헌의 fps를 우리 장비의 충분조건으로 복사하지 않는다.
2. 독립 장비/관측으로 릴리스 3D 선속도·회전벡터와 실제 비행궤적을 확인한다. 평가 후보는 벡터 오차, 회전축 각도 오차, RPM 오차, 궤적/plate 위치 오차, 릴리스 시각 오차다. 같은 데이터로 보정하고 검증하지 않는다. 참조값의 오차도 함께 고려한다.
3. 접촉 예측을 검증하려면 접촉점·법선·손가락별 힘 또는 독립적으로 검증된 추정, 미끄러짐·rolling·순차 이탈을 연결한다. 순수 중심력 스프링을 회전 전달 검증으로 세지 않는다. 공 선운동량·각운동량과 예측 접촉 충격량의 수지 잔차는 후보 진단이지만 현재 실측 정답이 없다.
4. 동일 힘 능력/일 비교에는 검증된 관절 토크·각속도와 근육/건 모델, 외부 보조입력·그립·공 질량/관성을 함께 고정·측정해야 한다. 순일 하나만 같으면 양·음의 일이 상쇄될 수 있으므로 양/음의 일, 최대 힘·토크·파워·활성화 등 제약을 구분한다. 현재 최대 등척성 힘의 출처값이나 주관적 동일 노력은 선수별 능력·일의 실측이 아니다.
5. 별도 세션/투구에서 기준 동작·공 회전/궤적·힘 수지를 통과한 뒤에만 작은 동작 차이에 대한 예측을 시험한다. 효과 크기·오차 허용치·샘플 수는 독립 측정오차와 목표에 맞춰 사전등록해야 하며, 여기서 임의 숫자를 설정하지 않는다.

**자세 추천 보류:** 위 같은 투구 연결·오차/식별 가능성·근골격/접촉 수지·독립 검증과 동일 예산 조건이 충족되지 않는 동안 관절 몇 도/몇 ms 조정, 무조건 높은 RPM/active spin, 안전·편안함 또는 향상 영상을 권고하지 않는다. 문헌의 평균 관계나 새 MLB 모델의 예측 이득은 이 조건을 대신하지 않는다.

## 범위와 남은 미확인

신규 원자료 대량 다운로드·외부 연락·유료 접근·우회·모델/코드 변경은 하지 않았다. Shibata2023 전문·전체 동기 방법·실행 모델/코드·원자료 제공조건은 미확인이다. VAA/HAA 1차자료는 각도 정의를 확인한 것이며 MLB 신규 예측 개선 근거로 사용하지 않는다. 공식 CSV/리더보드는 필드/측정 개념의 근거이며 현재 StatsAPI와 동일 투구별 값이 검증된 것은 아니다. 로컬 대조는 기록의 존재·내용·해시 감사이고 raw C3D·새 회전 데이터의 재분석이 아니다.
