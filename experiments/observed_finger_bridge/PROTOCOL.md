# 기존 영상의 손가락 관측과 같은 투구 연결

## 실행 전 고정 기준

기존 로컬 야구 영상과 공식 MediaPipe Hand Landmarker float16 v1을 사용한다. 원래 출력이 없는 손가락을 몸 관절 캐시에서 복원했다고 부르지 않는다. 원본과 모델 해시, 실제 원본 프레임, 배포 fps와 촬영 시계의 근거를 보존한다. 구속·RPM·무브먼트는 손 영역·시각·모델·기하 선택에 사용하지 않는다.

1. 기존 Prime 001의 잠정 보정과 3시야, 손이 큰 기존 고속 시연, 기록 연결 고속 영상을 각각 검사한다. 다른 영상의 신체·기록을 합치지 않는다. 원영상에서 가시성을 확인하고 영상·구간·ROI를 로컬 manifest에 먼저 고정한다. 이미 완료한 Prime 두 크롭/세 점 결과는 기준으로 재사용하며 새 성과로 세지 않는다.
2. 새 손 모델은 21점을 출력한다. 고정 ROI 원방향과 손/팔의 영상 방향을 기준으로 회전한 입력을 비교한다. 첫 실행 전 적용할 방향과 ROI를 동결한다. 모델 출력/기록에 맞춰 ROI를 수정하지 않는다. 손목이 ROI의 대상 손에서 벗어나거나 반대 손/관객/포수 손에 붙는 후보는 보존 후 제외한다. 확대는 원본의 해상도를 높인 측정이 아니다.
3. 누락은 유지한다. 검출 프레임 비율, 연속 검출 길이, 두 입력의 손목/손끝 차이와 프레임별 뼈 길이 변동을 함께 보고한다. 모델 confidence나 입력 합의는 실제 정확도의 대체가 아니다. 검출 결과를 보기 전에 정한 원본 평가 프레임에서 보이는 손목·검지·중지 끝만 영역으로 판독한다. 가려진 손끝은 정답을 만들지 않는다. 모델 간 합의를 수동 판독 정확도라고 부르지 않는다.
4. Prime에서 같은 프레임의 2시야 삼각측량 후 남은 시야를 평가한다. 양의 깊이, 손목의 원자료 위치와 차이, 손 크기 및 21점 재투영을 보고한다. 적어도 3연속 프레임과 남은 시야 재투영 중앙값 5px 이하, 최대 10px 이하가 있어야 관측 손 자세를 몸의 손목 좌표에 연결하는 후보로 분류한다. 이 수치는 공학적 검사이며 생리학적 정확도·힘 용량의 검증이 아니다. 잠정 카메라와 동기화 한계는 그대로 남긴다.
5. 단안 손 world 좌표는 모델 추정의 손 중심 상대 좌표다. 별도 계측 없이 전체 신체의 절대 3D, 공 접촉, 손가락 힘이나 이탈 순서의 관측값으로 채택하지 않는다. 같은 투구의 보정·3D신체·시간·공 접촉 관측이 없으면 동역학 연결과 출력 예측을 미실행으로 기록한다. 가능한 부분의 실제 추론/검산은 끝까지 수행한다.
6. 실측 비교에는 동일 투구 키와 출력 정의가 필요하다. 기록을 입력한 비행 재현은 구속/RPM의 독립 예측이 아니다. 누락된 RPM·무브먼트·힘/일 예산은 null로 보존한다. 손 관측 통과와 기준 신체/공 모델 검증 전에 신체 조정이나 구속 향상치를 만들지 않는다.

결과는 실패와 제외를 포함해 보존한다. 원영상 위에 실제 후보 21점, 구간의 가시성/누락, 추정과 측정 구분을 표시한다. 코드·집계·한국어 보고서만 커밋하고 원영상·원자료행·개인 경로는 ignored artifacts에 둔다. 관련 단위/회귀 테스트, 독립 워커 검산, 영상 전체 디코드 및 대표 프레임 검사를 수행한다. 훈련·의료 조언이나 실제 선수 향상 보장이 아니다.
