# 논문 기반 공통 수정 규칙: 계산 전 고정 계획

2026-10-30. 새 결과를 계산하기 전에 커밋한다. 선행 PR136의 원본 입력과 실패는 변경하지 않는다. 이는 훈련·의료 조언이나 실제 성능 효과 검증이 아니다.

## 근거와 연구자가 정한 부분

- Slowik et al., 2019, https://pmc.ncbi.nlm.nih.gov/articles/PMC6485842/ : 선수 간 관계와 선수 내 관계를 구분한다. 같은 선수의 팔 부하도 함께 검사한다. 관찰 연구의 계수를 동작 처방으로 복사하지 않는다.
- Nebel et al., 2025 인쇄본/2024 온라인, https://pmc.ncbi.nlm.nih.gov/articles/PMC12766286/ : 구간별 각속도 시계열의 선수 내 비교를 참고한다. 유의한 구간을 최적 개입 시점이나 인과효과로 간주하지 않는다.
- Joos et al., 2020, https://arxiv.org/html/2007.06669v1 : 위치/속도 상태에 조건화한 제어 구조를 참고한다. 어깨 외전 단일 축 연구이며 투구나 현실 효과의 증명이 아니다. 이번 구현은 그 논문의 DRL이나 근육 모델을 재현하지 않는다.
- Attias et al. 저자 공개 원고, https://uwaterloo.ca/motion-research-group/sites/default/files/2026-01/mbsd_pub_baseball_fd_cattias_final.pdf : 동역학 안의 제약·최적제어를 참고한다. 손 최대 전방속도 이탈과 reserve actuator 및 직접 실험 검증의 제한도 함께 반영한다. 원고의 목표 구속을 달성하도록 모델을 맞추는 방식은 채택하지 않는다.
- Scarborough et al., 2020/2018 온라인, https://doi.org/10.1080/14763141.2018.1503321 : 출판사 초록에서 시퀀스 다양성과 이상적 순서 미정임을 확인했다. 유료 본문 전체는 확인하지 못했다. 특정 순서를 하드 정답으로 넣지 않는다.

위 논문들은 아래 12계수 공식, 2%/60ms 범위, 학습 분할, 수치 판정을 입증하지 않는다. 이들은 기존 코드와 계산 예산을 고려한 이번 연구의 명시적 공학 가정이다. 근육/해부학적 축/지면 접촉/손가락 관측은 새로 검증하지 않는다.

## 작은 구현의 정확한 범위

선수 user2의 기존 5구 입력을 쓴다. 3034_1/2/3만 계수 적합에 사용하고, 3034_4/5는 새 적합에서 제외한다. 이미 이전 실험에서 본 개발 자료이므로 진정한 미사용/독립 자료라고 부르지 않는다. 새 계수를 4/5 결과를 보고 고르거나 다시 적합하지 않는다.

기존 PR136의 고정 분절 길이, 일반 관성, 15cm 그립, 20Hz 처리, 공칭 BR과 FP10~BR 구간을 유지한다. 원본 NPZ/기준 적분/보고서는 해시로 확인해 재사용한다. 레이더 구속을 특징, 손실, 선택, 스케일링에 쓰지 않는다.

개입 직전 BR-60ms 이하 마지막 기준 적분 상태에서 특징 3개를 읽는다: 모델 팔꿈치 힌지 각도(rad), 그 속도(rad/s), 손목 마커 회전의 속도 노름(rad/s). 정확한 해부학적 각도나 코치 처방량은 아니다. 기준 구간이 BR로 정렬되어 있으므로 미래 BR을 아는 오프라인 계획이며 실시간 제어가 아니다.

학습 3구만으로 평균과 표준편차(최소 1e-6)를 정한다. 표준화 특징을 +/-2로 제한한다. 관측 특징이 학습 최소~최대 범위 밖이면 적용 출력은 0인 보류로 한다. 바깥 범위는 안전이나 정확성을 보장하는 경계가 아니라 작은 개발 자료 밖의 외삽을 피하는 보수적 규칙이다. 적합 후에 범위를 넓히지 않는다.

공통 정책은 a=tanh(W[1,z])이며 W는 3x4, 각 원소 -1~1이다. a의 세 성분이 각각 팔꿈치/전완 marker-roll/손목의 기존 후보 시간 패턴을 배율 조정한다. 방향 패턴은 PR135의 고정 33계수에서 해당 성분만 가져온다. root 외부 힘과 회전 토크의 입력 수정은 0으로 고정한다. 실제 힘/일은 상태가 바뀌면 달라질 수 있어 다시 계산한다. 이는 제한된 탐색 기저이며 보편적 인체 공식이 아니다.

시간 기저와 입력 생성은 이전과 같이 마지막 60ms의 세 Hann 구간, 각 성분 peak 2%, 원래 peak 투영이다. 같은 W를 모든 학습/평가 투구에 적용하며 투구별 재최적화는 하지 않는다. 0 정책을 반드시 기준 대안으로 둔다.

## 강화된 C 검사와 최적화

C는 기존 A 전체 + B 전체 + root 병진힘 벡터 peak 비증가의 교집합이다. 생리학적 능력 검증으로 부르지 않는다. A/B도 별도로 보고한다. C와 자세는 각 투구 자신의 기준과 비교한다. 실제 RK4 힘 적분에서 비용을 계산하고 상태를 재생 궤적으로 되돌리지 않는다.

세 학습 투구의 가장 작은 구속 변화량을 최대화한다. SLSQP 변수는 W의 12개와 epigraph t이다. 각 학습 투구에서 coarse/fine의 gain>=t, C의 실제 일 상한, 자세 3도/20mm/1도를 동시에 부등식으로 넣는다. 목적은 -t+1e-6*sum(W^2)다. 입력 생성기가 이미 강제하는 peak 부등식은 중복 수치 제약을 피하기 위해 optimizer에서만 빼고 최종 C 검사에는 남긴다. 비교 epsilon은 최종 기존 gate와 같은 1e-9이며 optimizer의 일 상한에는 epsilon을 더하지 않는다.

시작점 두 개: W=0,t=0; W의 절편열만 [0.05,-0.05,0.05], 나머지 0,t=-1. 각 시작점 최대 80개 고유 W 평가(각 평가에서 3구 x 2해상도), maxiter=12, eps=1e-5, ftol=1e-10. 총 최대 160개 정책, 480쌍=960회 후보 적분이다. 기록과 실패/예산 종료를 보존한다. 이 제한된 기저·계산 예산의 실패를 보편적 불가능 증명으로 바꾸지 않는다.

## 선택과 고정 평가

학습 3구 모두 두 해상도에서 C+자세+동일 초기 상태를 통과해야 한다. 각 구의 양의 gain은 두 해상도의 기준/수정 속력 차이 합보다 커야 하며 coarse/fine gain 차이는 <=0.001km/h다. 후보 선택은 학습의 최소 fine gain을 최대화한다. 없으면 W=0을 선택한다.

선택된 W와 scaler 및 적용 보류 범위를 고정하고 3034_4/5에 한 번 적용한다. 결과를 보고 후보나 판정을 바꾸지 않는다. 적용 보류, 0변화, C/자세 실패를 각각 보고하며 성공으로 세지 않는다. 두 평가 투구 모두 양의 변화와 동일한 전체 검사를 통과할 때만 이 작은 개발 분할에서의 재현이라고 보고한다. 별도 선수 일반화나 실제 효과는 검증하지 않는다.

선택 결과는 저장 힘과 초기 상태로 독립 적분/accounting을 검사한다. 합격한 새 양의 후보가 있으면 원래/수정 투구 신체를 같은 좌표·시각·축척으로 겹친 영상을 만들고 전체 디코드를 확인한다. 없으면 새 향상 영상은 만들지 않는다. 실제 효과 95% 구간, 선수 훈련 효과, 구위/제구, 근육 안전은 미검증으로 남긴다. 전역 research gate를 진전시키지 않는다. 원본 C3D/CSV/영상을 업로드하지 않고 CC BY-NC-SA 4.0을 따른다.
