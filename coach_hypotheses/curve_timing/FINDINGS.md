# 곡선 중심시각: 안정성 개선과 예측 실패를 구분한 결과

2026-10-30. 사전 기준b784cac 뒤 동결된399투구·98명, 선수 내 모든666쌍을 같은 방법으로 비교했다. 기존 피크/전체곡선/Ridge/RFF 실패, 구속 예측 gate와 합격 기준을 바꾸지 않았다. 새로운 선수 개입 효과나 훈련·의료 조언이 아니다.

## 결과

**처리 가정에 대한 지표 안정성은 좋아졌지만, 구속 변화 분별의 사전 조건은 미통과**다. 검출 안정성을 실제 구속 정확도 향상이나 선수의 능력 증가로 바꾸지 않는다.

세 추가 필터와 PKH/BR 각각±1프레임의9조건에서 투구별 시차 범위를 비교했다.

- 기존 최대점 시차: 범위 중앙값8.200ms, p95 22.300ms, 최대111.000ms.
- 곡선 중심시각 차이: 범위 중앙값1.389ms, p95 2.580ms, 최대12.498ms.

사전의 중앙값 감소/p95 비악화 조건을 만족해 engineering_stability_improved=true로 표시했다. 이것은 같은 신호의 처리 민감도이며 실제 시각 오차/신뢰구간 또는 subframe 정확도를 추정한 결과가 아니다. 제공 full_sig는 이미20Hz 처리됐고 이번도 원시 마커 재처리가 아니다.

## 공통 구속 변화 예측 대조

각각 단일특징 하나만 고정 ridge alpha10/절편0에 넣고 선수전체제외98분할로 평가했다. 표준화는 학습 선수의 쌍 차이 RMS만 사용했다. 같은 선수의 모든 쌍을 먼저 평균해 선수균등 MAE를 계산했다. 쌍 방향은 투구ID순이며 시간순/빠른순이 아니다.

- 추가10Hz: peak 1.016155, centroid 1.019643, 무변화 1.015200km/h.
- 추가20Hz: peak **1.024556**, centroid **1.018900**, 무변화 **1.015200km/h**.
- 추가30Hz: peak 1.025493, centroid 1.018737, 무변화 1.015200km/h.

20Hz에서 같은 단일피크 비교군보다 MAE가0.005656km/h 작아졌지만 무변화보다0.003700km/h 컸다. 모형−무변화 선수 재표집95%구간은[-0.003603,+0.011171]km/h로 상한<0 조건도 충족하지 못했다.10/30Hz에서도 무변화를 이기지 못했다. centroid와peak 모두 개발예측조건 false로 보존한다. 이 구간은 개입 효과나 측정 오차 구간이 아니다.

이것은 **관측 투구 간 기록 구속 차이**의 개발 평가다. 원래3034 동역학의 절대 구속 차이와 다른 문제이며, 과거 다변량 모형의1.032 등의 값과 같은 모형의 전후오차처럼 비교하지 않았다. 새 세션/외부 자료나 미래 투구 검증도 아니다.

## 해석과 코드 상태

기존 최대점 선택의 흔들림을 줄이는 부분은 수치적으로 가능했다. 그러나 이 단일 시각 특징이 같은 선수의 구속 차이를 설명하는 정보가 충분하다는 근거는 얻지 못했다. 이것이 모든 전신 동작이 무관하다는 뜻도 아니고, 보이지 않는 손–공 접촉이 유일한 원인이라는 뜻도 아니다.

새 특징은 양의 제공 각속도 z성분 w(t)의 ∫t*w/∫w다. 선형 보간의 양/음 교차를 분리하고 해석적으로 적분해, 평탄부의 한 표본을 골랐는지에 대한 의존을 줄였다. 실제3D각속도·에너지 전달/근육 일과 같은 값으로 해석하지 않는다. 후보마다 근력/관성/그립/이탈을 맞추지 않았다.

따라서 새 특징을 검증된 구속 예측기/자세 추천으로 채택하지 않는다. 기존 scientific gate와 same_capacity/athlete_effect/coaching_ready는 미검증이다. 안정성만으로 근거를 승격하거나 불리한 필터를 숨기지 않았다. 신체 수정/구속 향상을 검증한 것이 아니어서 새 향상 영상을 만들지 않았다.

## 검산

새 단위 테스트9개를 통과했다. 양음 교차·삼각파·상수파의 해석 중심, 경계 보간, 진폭/시간 이동, 불변 분할·heldout 정답 변경, 쌍 방향 반전, 선수 균등 가중,0기준과 기존 조건을 검사했다.

별도 Simpson 구간 적분으로10,773개 이벤트/필터 중심시각 차이를 검산해 최대차1.34e-12ms였다. 독립 폐형식 ridge 계산으로3,996개 예측을 대조해 최대차4.44e-16km/h였다. 이는 계산 검산이며 실제 투구 정확도 검증은 아니다. 자세한 기록은results/verification.json에 있다. MLB parser를 통합한 전체 테스트는355실행/343통과/기존오류10/skip2이며 새 오류ID는 없다. 새 테스트는 곡선9개/MLB18개로27개다.

## 병렬 구위 자료 작업

이전 CSV403 실패를 유지하면서 MLB 공식 schedule이 제공한 완료 경기 링크에서 실제 투구JSON 접근에 성공했다. 별도 DATA_PROTOCOL을 먼저 고정하고 파서/스키마/단위·카운트·신원 연결을 감사한다. 이를 OBP의 같은 투구 신체 동작과 연결하거나3D회전/구위 향상을 계산한 것으로 취급하지 않는다.
