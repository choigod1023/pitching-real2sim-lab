# 기준 자세를 유지하는 어깨–전완–손목 협응 제어 검증

2026-10-30. 결과 실행 전에 고정한다. PR133의 51조건은 미통과이며 그대로 보존한다. 원래3034_1, 일반 관성·15cm 그립·공칭이탈시각, 기존 기계적 예산을 바꾸지 않는다. 마커 축과 자유 어깨 외력을 실제 해부학/근력으로 해석하지 않는다. 실제 효과 구간은 아직 UNKNOWN이다.

## 문제와 새 방법

기존 손목 입력만 바꾼 실험에서는 전완과 손목이 보상 회전했고, 전체 입력을 끊은 보호기는 기준 동작을 잃었다. 이번에는 실제 기준 RK4 상태를 시간별 목표로 삼고, 어깨·팔꿈치·전완·손목의 일반화 입력을 함께 조정한다. 상태 재설정 없이 실행한다.

기준의 실제 전방 궤적 `(q0,v0)`에 마지막30ms의 손목 마커Z축 수정각0.5/1/2°를 cubic-in 또는 smootherstep으로 가한6목표를 고정한다. 원하는 속도는 기준 실제속도에 수정/무수정 궤적의 동일 미분법 속도 차이를 더한다. 초기 두 상태가 바뀌면 제외한다. 동작의 연속식 끝점 추가 각속도는 cubic-in에서50/100/200°/s, smootherstep에서0이다.

입력은 기준 실제 입력에 `inverse(q목표,v목표,a목표)−inverse(q0,v0,a0)`를 더한 feedforward와 `M(q실제)[ω²·위치오차+2ω·속도오차]` feedback으로 만든다. 위치오차는 quaternion-aware tangent로 계산한다. 주파수0/5/10/20Hz를 고정하며0은feedforward-only 대조군이다. 총24조건을 두 해상도에서 실행한다(48개 후보실행). gain과 목표를 속도 기록에 맞춰 고르지 않는다.

기준 상태/입력은 각 적분 해상도의 원래 rollout에서 얻고, 같은 방법으로 목표를 만든다. 실제 참조/목표의 희소 저장 시각과 세밀한substep시각은 quaternion-aware 보간한다. 각 source interval 시작에 제어를 계산하고 substep 안에서 고정하므로 두 해상도에서 제어 갱신 빈도는 같다. feedback 때문에 채택된 입력은 해상도별 상태에 따라 달라질 수 있으며이를기록한다. 제어주파수는 공학적 gain이며 사람의 신경근제어 대역으로 해석하지 않는다.

모든 성분 입력을 기존 적용 구간의 성분별 최대절댓값과 관절3축 최대노름으로 제한한다. terminal미사용힘은제외한다. 이 제한은 실제일을보장하지않으므로 실제 qvel로 성분별 양/음의 일, 어깨병진·회전순일을 계산해 기존gate로 별도 판정한다. root외력·일을비교에서빼지않는다.

## 대조군·판정

- 목표수정0 대조군은 각 gain/해상도에서 원래 상태·구속·일을 재현해야 한다. 위치·속도오차가0이면feedback0이고 역동역학차이도0이어야 한다. 초기상태/에너지가같아야한다.
- 기존 1e−9 비교epsilon, 각DOF 양/음의 일·성분peak·관절peak노름·어깨병진/회전순일제약을 그대로유지한다. 힘 제한 통과가 일 제한 통과라는 뜻이아니다.
- 기존 최대회전3°/공중심이동20mm/방출방향차1°를 모두 지켜야한다. 목표추적RMSE와 실제끝각도·각속도, 전완/손목 보상회전을 별도로 보고한다.
- 두 해상도 모두전체제약통과+양의구속차이, 증가량 차이0.001km/h이하, 증가량이 기준/수정 절대구속 해상도차이합보다클때에만 계산상조건부후보로둔다. 1km/h초과여부를별도보고한다.
- 일부에서통과해도다른조건을숨기거나실제선수효과/95%구간/RPM·제구향상을주장하지않는다. 실패하면실패목록과추적/부하원인을분리한다. 새 gain/각도/창을추가탐색해성공을만들지않는다.
