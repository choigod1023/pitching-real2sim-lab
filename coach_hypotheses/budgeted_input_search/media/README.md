# 조건부 팔·손·공 입력 재분배 영상

`budgeted_pitch_overlay.mp4`는3034_1에서실제RK4적분한기준/수정팔·손·공을겹친14초영상이다. 몸통·다리는동일투구관찰좌표재생이며새전신예측이아니다. 같은시간·좌표·축척을사용하고실제변경량을과장하지않는다.

기존A비교기준에서+0.647km/h이지만전체순일+1.125J와어깨병진힘벡터peak+0.01051N을함께표시한다. 전체힘·일불증가나실제선수성능향상영상이아니다. 기준모델과실측차이약16.729km/h,실제효과구간미확인도명시한다.
