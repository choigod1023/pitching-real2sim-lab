# 앞무릎–릴리스–회전 연결의 사전 절차

PR162/163의 이미 본 스킨스 포심14쌍을 재분석한다. 새 결과를 계산하기 전에 이 문서를 커밋한다. 원자료·검수 사이트·기존 결과를 변경하지 않는다. 관찰 관계, 기록 초기화 비행, 신체 수정 전방 동역학을 구분한다.

## 자료와 관측 정의

- PR163의 같은 투구 CSV 연결·쌍 내부 배경·상황 판정을 재사용한다. 주 관찰 집단은 같은 타자·이닝·아웃·주자 점유·타자 좌우, 쌍 내부 시야 통과 9쌍(속도 선별7쌍5경기, 회전 선별2쌍2경기)이다. 두 선별 집단을 합치지 않는다. 모든14쌍의 기술통계·누락도 보존한다.
- 기존 무릎 특징은 초반 -150~-100ms에서 후반 -83~-33ms로의 2D 포함각 변화량이다. 첫 자유 공은 실제 손가락 접촉 종료 시각과 다르다. 원래 ±1프레임의 양 영상9공통조합을 재사용한다.
- CSV의 릴리스 x/z/익스텐션(ft→cm), 공식 `arm_angle`(어깨→공 슬롯), `spin_axis`(X-Z 평면 각도)를 같은 투구에서 읽는다. y위치도 보존하지만 익스텐션과 중복되는 검정은 하지 않는다. `spin_axis`를 완전한3D축·유효 회전율로 바꾸지 않는다. 각도 차이는 ±180° shortest difference다. 속도/가속도50ft 값을 릴리스 초기값으로 그대로 쓰지 않는다.
- 원본 관절 캐시는 MediaPipe33 추론이 아니라 RTMPose COCO17의 신체12점을33칸에 매핑한 것이다. 손가락18/20/22는 구조적으로 미출력이다. 손 방향·접촉을 보간하거나 손목→팔꿈치로 대체하지 않는다. 실제 좌표/score 전수검사를 남긴다.
- 새 영상 특징은 상완(어깨12→팔꿈치14), 전완(팔꿈치14→손목16)의 화면 방향이다. 첫 자유 공 -70~-15ms 창(60fps에서4프레임), 최소4표본 중3이상 유효하고3연속 유효, 창 전체 캐시 지원을 요구한다. score≥0.5, 화면 내부, 분절≥8px 및 유효 중앙길이의0.35~2배, 기존 수동arm제외를 유지한다. 원형각 중앙값은 첫 유효값 기준unwrap, 폭180°이상이면 미계산이다. 9시점조건에서8이상 지원 여부도 표시한다. 길이/점수 검사는 실제 관절 정체나 위치 정확도 검증이 아니다.

## 고정할 연결과 모델

11개 연결을 모두 보고한다. 무릎 변화→릴리스x, 높이z, 익스텐션, 공식팔슬롯, 2D회전축, 상완방향, 전완방향(7); 공식팔슬롯→2D회전축(1); 전완방향→2D회전축(1); 2D회전축→좌우/수직무브먼트(2). 손방향은 구조적 미관측으로 별도 표시하며 검정 수에 넣지 않는다. 뒤 연결만 통과해도 전체 신체 경로가 입증됐다고 하지 않는다.

M0는 구속차이/1kmh, 총RPM차이/100RPM, balls/strikes차이다. M1은 해당 연결의 입력 하나를 더한다. 고정 단위는 각도5°, 위치5cm, 고정ridge λ=1이다. 경기별 총가중치를 같게 정규화하고 학습 평균으로 중심화한 절편은 벌점 없이 둔다. 작은 표본의 공변량 수 문제를 확인하기 위해 구속/RPM 두 변수만의 진단도 처음부터 함께 계산하며 주 결과를 대체하지 않는다.

한 경기를 통째로 제외해 학습·평가한다. 최소2학습경기·3학습쌍, 최소3평가경기를 요구한다. 두 모델의 학습/평가 행은 동일한 입력·목표 관측 지원으로 고정한다. 결측은0이나임의값으로채우지않고 coverage를보고한다. 비교는 M0, 학습경기평균차이,0차이예측이다. 각도 목표는 차이의 원형평균과 원형 MAE를 사용하고 예측도±180°로 감싼다. 학습에서 목표 각도차이는 원형평균을 중심으로 unwrap한다. 기록끼리의 관계에는 영상 시점이 영향을 주지 않으므로9조건은 동일하며 이를독립복제로세지않는다.

각 fold의 설계rank/관측수/공변량으로 입력을 설명한 잔여RMS를 보존한다. MAE는 경기별평균을동일가중치로평균한다. 모든검정과9시점조건을보존하고 좋은경기/시점/목표를골라성공시키지않는다.

## 판정과 Real2Sim 연결

통계적반복후보는3경기이상, 전체선택쌍평가가능, 모든경기에서M1이M0/평균/무변화보다낮은MAE, 입력기울기방향모든fold일치,9조건에서유지할때만표시한다. 대조오차0일때동률을승리로세지않는다. 같은경기내관측상관은인과나처방이아니다. 반복후보라도선별개발자료·다중검정·카메라간시야미확인한계가남는다.

신체개입 Real2Sim은 통계적앞단연결후보, 같은투구의확인된3D/신체힘·일상태, 손–공연결/회전생성, 기준구속/RPM/궤적검증이 함께 있어야 실행한다. 현재소스감사에서Skenes는2D뿐이며 기존Skenes비행모델은실측구속으로속도크기를정규화하고RPM을입력받는다. 이 경로를신체조정예측으로호출하지않는다. OBP3034·Prime의힘/근력/관성을옮겨성공시키지않는다. 조건미충족이면시뮬레이션변화값은null/미실행으로남기고0향상이라고쓰지않는다. 실제훈련효과·안전·편안함은시뮬레이션만으로입증하지않는다.

## 산출물

기존원영상해시/캐시/CSV·프로토콜해시, 전체투구별결과는ignored artifacts에보존한다. 코드·비식별집계·한국어보고서만커밋한다. 관계가반복되지않아도 실제원영상의무릎·유효팔방향, 같은투구릴리스/팔슬롯/2D회전축/구속/RPM/무브먼트를표시해무엇을비교했는지보인다. 타경기예측값과실제기록은분리하며 임의3D공회전·개선동작을그리지않는다. 시간순첫적격쌍을경기별선택하고얼굴영상은Git에넣지않는다. 대표프레임·전체디코드, 합성함수테스트와독립워커수치검산후커밋/push/초안PR을만든다.
