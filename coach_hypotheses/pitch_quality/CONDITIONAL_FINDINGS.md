# 반복 경기에서 회전·움직임 정보가 미스 예측에 더 도움이 되는가

2026-10-30. **이번 포심 주분석은 사전 기준을 통과하지 못했다.** 속도·위치·카운트 등을 통제한 모델은 투수 평균 기준보다 검사 Brier가 낮았지만, 여기에 회전·움직임 필드를 추가하면 오히려 조금 나빠졌다. 관측 자료 분석을 실제로 실행한 결과이며 신체 동작 개입이나 실제 선수 효과의 검증은 아니다.

## 먼저 고정한 것

`CONDITIONAL_PROTOCOL.md`를 커밋 `9198cf13067e031ef109288b57745299f56aa9e1`로 고정한 뒤 반복 경기 수집과 모델 계산을 진행했다. 다항항 생성 순서·투수 동일 가중·T/Q 처리 보충은 결과 계산 전 `39ec5a8`로 남겼다. 결과를 보고 경기·변수·페널티·합격 기준을 바꾸지 않았다. 기존 PR127의 단일 개발 경기도 포함되므로 완전 미사용 외부 코호트라고 부르지 않는다.

2025년 6월 1~14일의 모든 완료 정규시즌 경기를 공식 날짜로 선택했다. [MLB 공식 schedule](https://statsapi.mlb.com/api/v1/schedule?sportId=1&date=2025-06-01)의 실제 feed link를 사용했고, 14일·186경기·53,950투구를 확보했다. 실패는 0건이며 모든 경기에서 boxscore 투구수와 일치했다. 공식 일별 목록의 중복 2개는 gamePk로 제거했다. 원본과 투구별 데이터는 Git 제외 artifacts에만 있다. 공개 접근을 원자료 재배포 허가로 해석하지 않았다.

36투구는 타석 중 선수 교체 때문에 신원을 격리했다. 분석에서 비번트 스윙이 아닌 28,004개, 신원 불확실 36개, 필요한 수치가 없는 13개를 제외해 **25,897스윙**을 남겼다. 이 제외 분류는 순차 판정이다. 원본 전체의 회전수 결측 22개와 분석 수치 제외 13개가 같아야 하는 것은 아니다.

[공식 pitchCodes](https://statsapi.mlb.com/api/v1/pitchCodes)의 비번트 swingStatus를 분모로 사용했다. 주 타깃은 연구자 정의 엄격 S/W 미스다. T(파울팁)와 Q(피치아웃 헛스윙)는 같은 분모에 남는 0이다. 민감도 타깃은 공식 비번트 swingMissStatus로 S/W/T/Q를 포함한다. [MLB 설명](https://www.mlb.com/news/steven-kwan-s-streak-without-swing-and-miss-ends)과 공개 gamefeed 코드에서도 파울팁의 whiff 포함을 확인했다. 두 타깃을 같은 지표로 이름 바꾸지 않았다.

## 물리 단위와 통계 분석을 구분했다

MLB 공개 gamefeed JS에서 startSpeed의 mph 표시를 확인했다. 그러나 평가 위치/시점은 미확인이다. spinRate, breakVerticalInduced, breakHorizontal, pX/pZ는 **해당 StatsAPI 경로의 단위·방향·시점이 여전히 미확인**이다. [Savant CSV 공식 문서](https://baseballsavant.mlb.com/csv-docs)의 설명을 다른 경로에 임의 적용하지 않았다. 상세 근거와 source 해시는 `FIELD_DEFINITIONS.md`에 있다.

이번에는 원필드를 훈련 자료에서만 중심화·표준화한 무차원 관측 분석을 했다. 단위가 검증됐다고 주장하거나 실제 인치의 변화량, 회전 효율, 관절 변경량으로 번역하지 않았다. 기존 conditional_study_ready 및 Real2Sim data gate도 그대로 두었다. 새 `standardized_observational_analysis_ready=true`는 이 좁은 분석의 다섯 검사 분할 계산을 마쳤다는 뜻이다.

## 모델과 검사 모집단

포심 FF가 주분석이다. 투수×구종 절편을 정규화한 로지스틱 모델에서 연속 설계열을 훈련 투수 안에서 중심화했다. 원 위치의 제곱·교차항을 먼저 만들었다. 통제는 속도, 위치, 위치의 제곱·교차항과 타자 좌우 상호작용, 타자 좌우, 투구 전 카운트다. control, +spin, +movement, +both를 동일 행에서 비교했다. 페널티는 사전 고정했고 결과 기반 튜닝을 하지 않았다.

gamePk % 5로 경기를 나눴다. 같은 경기를 학습과 검사에 섞지 않았고, 각 fold의 학습 스윙 20개 이상·학습 경기 2개 이상인 투수만 주 검사에 포함했다. **이미 관측한 투수의 다른 경기 검사**이며 새 투수/미래 시점/다음 시즌 검증이 아니다. 전체 검사 예측을 모아 투수별 손실을 먼저 계산한 뒤 투수에 동일 가중했다.

포심 complete-case는 8,425스윙이지만 이 적격 조건을 적용한 검사 자료는 **78명·1,689스윙**이다. 6,736개는 해당 fold 학습의 출전·스윙 수 조건을 충족하지 못했다. 2주 동안 같은 투수의 반복 경기가 적으면 한 경기를 빼는 순간 학습 2경기를 확보하지 못하기 때문이다. 이를 신규 관측이나 8,425개의 적격 예측으로 바꾸어 세지 않았다.

## 포심 수치

Brier와 log loss는 낮을수록 좋다. 아래는 엄격 S/W 타깃의 검사 결과다.

| 모델 | 투수 동일 가중 Brier | log loss |
|---|---:|---:|
| 학습 전체 평균 | 0.1500445 | 0.4771486 |
| 학습 투수 평균, Laplace 보정 | 0.1544125 | 0.4905544 |
| control: 속도·위치·카운트 등 | **0.1414774** | **0.4538414** |
| control + spinRate | 0.1412806 | 0.4538661 |
| control + movement | 0.1423780 | 0.4568696 |
| control + both | 0.1422396 | 0.4568349 |

control의 Brier는 투수 평균 기준보다 8.38% 낮았다. 그러나 both는 control보다 0.54% 높았다. 주 비교의 control−both Brier 차이는 **−0.0007622**, 투수 cluster bootstrap 2,000회 95% 백분위 구간은 **−0.0030951~+0.0015013**이었다. 이는 예측 손실 차이의 통계적 재표집 구간이며 km/h 측정 오차, 물리 모델 오차 또는 실제 개입 효과의 구간이 아니다.

사전 여섯 조건 중 세 개를 만족했다. 투수 수 50명 이상, 5 fold×4 모델의 수렴, 투수 평균보다 낮은 both Brier는 충족했다. 검사 2,000스윙 이상, Brier 개선 구간 하한 양수, control보다 낮은 both log loss는 충족하지 못했다. **미통과 판정을 유지한다.**

공식 미스 플래그 민감도에서도 같은 1,689스윙을 사용했다. 엄격 S/W 미스는 305개, 공식 비번트 미스는 365개였다. 공식 타깃의 Brier는 control 0.1554539, both 0.1564917로 추가 정보의 유리함을 확인하지 못했다. T/Q를 결과에 유리한 쪽으로 선택하지 않았다.

## 선수 사이와 선수 안의 관계

다음은 전체 포심에서 20스윙·2경기 이상인 164명의 **통제하지 않은 기술적 상관**이다. 예측 검사 78명과는 모집단이 다르다. 아래 계수만으로 처방하지 않는다.

| 원필드 | 투수별 평균끼리의 r | 같은 투수 평균을 뺀 r |
|---|---:|---:|
| spinRate | +0.1098 | +0.0442 |
| breakVerticalInduced | −0.1425 | +0.0772 |
| breakHorizontal | +0.1542 | −0.0175 |

선수 사이와 선수 안의 방향이 다른 필드가 있다. 한 투수의 단순 회전수 증가를 모든 투수에게 유리한 변화로 일반화할 근거가 아니다. 전체 both 재적합 계수와 fold별 계수는 결과 JSON에 보존했지만 인과 계수·물리 단위별 효과·다중 비교 유의성으로 해석하지 않았다.

## 보조 구종도 따로 남겼다

사전 전체 표본 조건을 만족한 CH/CU/FC/SI/SL/ST를 같은 절차로 계산했다. 아래는 엄격 타깃이다. 주분석을 다른 구종으로 바꾸지 않았다.

| 구종 | 적격 검사 스윙/투수 | control Brier | both Brier |
|---|---:|---:|---:|
| CH | 144 / 11 | 0.2341456 | 0.2334494 |
| CU | 6 / 2 | 0.1205960 | 0.1141038 |
| FC | 212 / 14 | 0.1369601 | 0.1418010 |
| SI | 531 / 33 | 0.0828308 | 0.0838129 |
| SL | 525 / 26 | 0.1606819 | 0.1592959 |
| ST | 180 / 8 | 0.1638772 | 0.1650790 |

특히 CU는 다섯 분할 중 세 분할에 적격 검사 스윙이 없어 8개 모델 적합만 실행했다. 6스윙의 수치를 일반 정확도라고 부를 수 없다. 다른 보조 구종도 반복 경기 검사 표본이 작다. spin 단독의 작은 Brier 개선, SL의 유리한 점추정 등을 골라 주 가설 통과로 바꾸지 않았다.

## 검산과 테스트

- 원본 186경기의 bytes·SHA256과 파싱 53,950투구를 별도 경로로 대조했다. 필수 원수치 323,700칸, 투구 전후 카운트 53,950개, 공식 판정 플래그 53,950개를 확인했다.
- 포심 검사 1,689개가 학습 경기·스윙 수 조건과 정확히 일치함을 독립 계산했다. 예측에서 Brier와 log loss를 다시 합산한 최대 차이는 1.11e−16이었다. 이 수치는 계산 일치도이며 실제 성능 오차가 아니다.
- 수치 gradient와 독립 dense Newton 해 비교, 훈련 전처리 불변, T/Q, pre_count, 게임 분리, 단일 클래스 거부, 공식 코드 불일치 제외, 투수 동일 가중, 합격 조건을 테스트했다.
- 새 테스트 27개: 수집기 10개·조건부 모델 17개 모두 통과했다. 기존 파서 18개도 통과했다.
- 전체 382개 중 **370개 통과, 기존 오류 10개, skip 2개**다. 새 실패·새 오류는 없다. 9개는 OpenSim 미설치, 1개는 기존 로컬 formula_checks.json 부재다. 테스트가 자기 worktree의 기존 model.xml에 만든 변경만 복원했다.

전체 14개 구종×타깃 분석에서 실행한 256개 fold 모델은 모두 수렴했다. CU의 적격 검사 부재와 실제 최적화 실패를 구분했다. 전체자료 재적합은 모두 수렴했다. 테스트 fixture와 실제 연구 표본을 섞지 않았다.

## 현재 활용 범위와 다음 순서

이제 공개 MLB 실제 경기의 공 지표와 미스 결과를 투구별로 연결하고, 같은 투수 안의 관계를 속도·위치 등과 구분해 검사하는 코드가 있다. 이번 표본에서는 **속도·위치 등을 포함한 control을 연구용 기준 모델로 유지하고, 회전·움직임 추가 모델은 채택하지 않는다.** 이는 포심 검사 표본의 예측 비교이며 실전 배합·훈련 권고가 아니다.

다음에는 결과와 무관하게 정한 더 긴 별도 기간을 먼저 등록해 같은 모델의 재현성을 확인해야 한다. 이번 2주에서 변수·구종·분할을 계속 바꾸며 개선 수치를 찾지 않는다. 장기 표본에서는 시간 순 검사, 타자/경기 의존, 위치 함수의 부족, 움직임의 타자 좌우 상호작용을 **별도 후속 가설**로 검토할 수 있다. 이번 실패 원인을 그중 하나로 확정하지 않았다.

신체 조정 목표로 이어가려면, 같은 투구의 전신/팔/손 움직임과 직접 관측한 회전·3D축·공 궤적이 연결된 자료가 별도로 필요하다. MLB 결과 모델은 어떤 관절을 몇 도 바꿀지 알려주지 않는다. 근육·힘·일 모델의 잔차도 이번 분석으로 해결되지 않았다. 실제 신체 개입이 없으므로 새 향상 영상은 만들지 않았다. **훈련·의료 조언이 아니며 실제 선수의 능력 향상·안전·편안함을 입증한 결과가 아니다.**
