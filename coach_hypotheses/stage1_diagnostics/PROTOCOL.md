# 단계1 실패 원인 진단 및 개선 실험 사전 기록

기존 단계1 결과와 무릎 부호 정정은 이미 확인했습니다. 이 후속 분석은 같은 개발
자료의 재사용이며 독립 확인 연구가 아닙니다. 기존 PROTOCOL.md/결과/합격 기준을
바꾸지 않습니다. 이 문서는 새 계산/구현 전에 커밋합니다. 단계2는 사용자 추가
승인에 따라 다른 작업공간에서 병렬 실행하며 이 분석의 통과로 간주하지 않습니다.

## 구분할 질문

1. 자료: 기존 해시/키 일치, 선수별 반복수·구속 범위·값 간격, 개인 내 분산 대비
   선수 사이 분산, 필터 변화 대비 개인 내 신호 크기를 기술합니다. 레이더의 실제
   측정 정확도·반복 신뢰도는 자료만으로 추정하지 않습니다. 값의 간격을 장비 오차로
   바꾸지 않습니다. 20Hz 처리 자료에서 사라진 고주파는 복구하지 않습니다.
2. 지표: 원래12개, 더 안정적인7개, 최고 각속도 크기를 추가한14개, FP10~BR의
   파형20개를 비교합니다. 단일 최대/시점 요약이 잃는 정보를 시험합니다.
3. 모형: 공통 선형계수와 강제 비영 예측, MSE 학습/MAE 평가 차이를 분리합니다.
   평균 기준과 같은 0변화 후보를 inner 선택에 포함하고, MAE 근사 손실도 시험합니다.

## 고정 코호트와 표현

단계1의 공통399구98명을 그대로 사용합니다. 성능을 보고 선수/투구를 제외하지
않습니다. 10/20/30Hz 세 조건을 모두 유지합니다. 원자료 대응/전처리 원칙은
원래 프로토콜과 AMENDMENT_01_KNEE_SIGN.md를 따릅니다. 토크·힘·레이더·ID는
예측 입력에서 제외합니다. 다음 family를 이번 실행 전에 고정합니다.

- original12: 기존12개와 기존 ridge alpha(.01,.1,1,10,100). 원래 결과 재현 대조.
- stable7: 신전량, 보폭/보폭제곱, FP10/최대 분리각, 손목 높이, 팔 슬롯.
- extended14: original12 + 제공 pelvis_peak_dps/torso_peak_dps.
- waveform20: pelvis_velo_z,torso_velo_z,lead_knee_velo_x,torso_pelvis_angle_z의
  FP10~BR 상대0/25/50/75/100% 값. 피치별 시간 정규화이며 실제 시간 차이는 별개입니다.
- mae14: extended14와 같은 입력, pseudo-absolute 손실sqrt(r²+0.05²)-0.05,
  L2 penalty alpha/2. 최적화 오차는 기록하며 실패하면 조용히 ridge로 바꾸지 않습니다.
- null: 중심화한 예측=0. 비교군을 자동으로 이긴다고 해석하지 않습니다.

original12 외 ridge/mae 후보 alpha는(.01,.1,1,10,100,1000)입니다. 모든 스케일,
상수열 처리, 계수/절편은 훈련 자료에서만 정합니다. 원래와 같은 선수균등 손실을
사용합니다. mae 최적화는 tol1e-8,maxiter200으로 고정합니다.

## 평가와 원인 진단

모든 family/alpha 선택은 outer LOAO에서 제외한 훈련 선수만의 deterministic5그룹
inner CV로 합니다. 검증 입력은 해당 선수의 세션 평균으로 중심화하고 예측도
선수별 평균을 뺍니다. 정답 평균은 회고적 점수 계산에만 씁니다. 실전 절대 구속
예측이라고 주장하지 않습니다. 동률에서는 null, 나머지는 단순한 family/큰alpha를
우선합니다. 새 **주 개선 모델은 inner가 family와alpha를 함께 선택한 selector**입니다.
각 family도 자체 inner alpha로 전부 보고하되 outer 성능으로 좋은 family를 골라
주 모델이라고 바꾸지 않습니다. 원래 historical/stage1 결과는 보존합니다.

추가 진단:

- 각 feature의 선수 내/간 분산, 필터 변화량/선수 내 SD 비, 상관·행렬 rank/조건수,
  훈련/검증 MAE와 계수 방향/크기 안정성을 보고합니다. 이것만으로 단일 원인을 확정하지 않습니다.
- null 입력에 대한 유한 예측, held-out 정답 변경 불변, 선수 비중복을 테스트합니다.
- known synthetic within signal에서 같은 파이프라인이 신호를 찾는지 확인합니다.
  합성 성공은 실제 자료 합격 근거가 아닙니다.
- 추가20Hz extended14에서 고정alpha10의 20개 within-player 훈련 정답 순열을
  negative control로 평가합니다(seed20261029..20261048). outer 검사 정답은
  고정하고 훈련 정답만 순열합니다. 이는 정식 유의성 검정/오차 신뢰구간이 아닙니다.
- 이미 본 자료의 반복 재분석, 다중 비교, 모형 선택 불확실성을 명시합니다.

## 합격 기준: 원래와 동일

selector에 원래 scientific_gate를 그대로 적용합니다. 선수>=50/투구>=150,
선수 비중복·target 없는 전처리 검증, 추가20Hz 선수균등 MAE가 같은 코호트 평균
기준보다 작음, 선수별 오차차이2000회 cluster bootstrap95% 상한<0,
추가10/30Hz에서도 평균 기준보다 나쁘지 않아야 합니다. 하나라도 미충족이면FAIL.
null 선택/상관/하위집단/합성자료/다른 family 성공으로 이 판정을 바꾸지 않습니다.
사후 개발자료에서 통과하더라도 새 선수/새 세션으로 확인하기 전 처방 근거가 아닙니다.

원본/기존 코드를 수정하지 않고 coach_hypotheses/stage1_diagnostics/ 안에 구현·
출력·테스트·한국어 보고서를 만듭니다. 모든 새 함수에 테스트를 붙이고 기존 테스트의
추가 오류를 확인합니다. 원자료/영상/논문 전문은 커밋하지 않습니다. 파생 자료는
OBP CC BY-NC-SA4.0와 NOTICE.md를 따릅니다. 실제 선수 효과·안전·편안함·인과와
관찰 예측을 구분합니다. 단계3 개입 설계/구현은 진행하지 않습니다.
