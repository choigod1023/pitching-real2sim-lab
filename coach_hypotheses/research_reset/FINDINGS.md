사용 가능한 자료의 범위는 확인했지만, 이번에 고정한 7개 신체 지표 모델도 관측 투구쌍 구속 차이의 0예측을 넘지 못했습니다. **채택할 대체 예측 모델, 신체 수정 후보 또는 실제 성능 향상은 없습니다.** 이 결과를 숨기려고 조건/필터/코호트를 바꾸거나 더 좋은 모델만 골라 다시 주 결과로 삼지 않았습니다.

## 1. 실제 자료의 연결과 신호 가용성

부모 코드가 원자료 manifest 7개 해시와 파생 지표 해시를 검증했습니다. 추가 GRF 파일 해시도 기록했습니다. metadata의 고유 411투구는 각각 하나의 C3D에 연결되며 누락/다중 연결이 없습니다. 전체 C3D는 정적 파일을 포함해 511개입니다. 신체 지표에는 세 필터 공통 98선수/98세션/399투구가 있고, 키·선수·세션·mph→km/h가 metadata와 일치했습니다.

GRF는 파일 가용성 기준으로 403투구이며 metadata 전체 411개와 다릅니다. 전체 시간에서 6축 모두 finite인 투구는 401개, PKH~BR 구간에서는 403개입니다. 2투구 `2981_3`, `3233_1`의 결측 합계 12행은 이 구간 밖에 있었습니다. 따라서 다음 두 코호트를 구별해야 합니다.

- 신체 지표 399투구 ∩ 전체 시간 finite GRF: 397투구/98선수.
- 신체 지표 399투구 ∩ PKH~BR finite GRF: 399투구/98선수.

이번 예측 실험은 사전 고정한 399투구를 그대로 사용했습니다. GRF가 finite라는 사실은 발 접촉·COP·축/단위·외부 일·근육 능력 검증을 뜻하지 않습니다. 동작과 GRF의 시간 격자가 다르므로 행번호로 결합하면 안 됩니다.

읽기 전용 자료 에이전트는 원본 CSV도 직접 열었습니다. energy_flow/forces_moments/joint_angles/joint_velos/landmarks 각각 411투구/247,709행이며 ID/시간 중복이 없었습니다. Prime 별도 trial OBP_movement_BaseballThrow_001의 8카메라 원본은 각각 1406프레임/360fps/1280×720입니다. C3D는 POINT 0개, 회전 19분절×1406프레임이며 양손 추정 분절이 있습니다. 기존 공 track은 48프레임(956~1003), 프레임당 4~8시야, XYZ finite입니다. 이것은 공 관측의 존재를 확인하지만 하드웨어 동기화·공 중심/관절원점·보정의 검증 완료가 아닙니다. Prime과 OBP 3034의 선수/세션을 연결하는 키는 확인하지 못했습니다.

에이전트가 확인한 Prime 원본은 `../downloads/obp-cv-full/OBP CV Files/compressed_optitrack/`와 `theia3d_output/c3d/`이며, track은 기존 `video_track/results/track.json`입니다. 기존 카메라 리그는 provisional_not_bundle_adjusted이고 새 기하를 승인하지 않았습니다. Prime 단일 trial은 399구의 구속 정답이나 독립 선수 코호트로 섞지 않습니다.

## 2. 평가 목표를 명확히 한 작은 실험

기존 약 0.63km/h는 선수의 전체 세션 평균을 제거한 회고적 잔차 오차입니다. 평가 정답을 fitting에 썼다는 증거는 없지만, 미래 한 투구를 예측하는 오차로 소개하면 안 됩니다. 설계 에이전트의 직접 검산에서 전체 세션 평균 기준은 0.6297416km/h, 해당 투구를 뺀 다른 투구 평균 기준은 0.8669657km/h였습니다. 이 차이는 평균 정의의 수학적 영향이며 오차 감소 성과가 아닙니다. 뒤의 기준도 미래 투구를 포함할 수 있어 실전 성능을 뜻하지 않습니다.

이번 정답은 같은 선수의 두 관측 투구 간 속도 차이입니다. 399투구에서 666쌍이 생기지만 독립 선수는 98명입니다. stable7/alpha10/절편0/훈련 RMS/선수균등 가중/선수 LOAO 한 조건만 사용했습니다. 기존 선형 중심화와 밀접한 방법이며 새 신체 정보를 추가한 모델이 아닙니다. 7개 입력 선택도 이미 본 결과를 토대로 한 개발 선택이라는 한계가 있습니다.

선수균등 MAE(km/h):

- 10Hz: 모델 **1.029984**, 차이 0기준 **1.015200**.
- 20Hz: 모델 **1.032053**, 차이 0기준 **1.015200**.
- 30Hz: 모델 **1.031696**, 차이 0기준 **1.015200**.

20Hz의 모델−기준 MAE 차이는 +0.016853km/h이고, 2000회 선수 bootstrap의 95% 차이 구간은 **−0.004531~+0.040400km/h**입니다. 우월성을 확인하지 못했습니다. 절대오차 p95는 **2.633098km/h**입니다. 이것은 이 개발 표본의 관측 투구쌍 오차 분위수이며 ±2.63km/h 센서 오차나 보정된 95% 예측구간이 아닙니다.

새 결과는 기존 0.63km/h 또는 3034 물리 모델의 약 16.7km/h와 목표/자료/모델이 다릅니다. 이를 전후 오차 감소 또는 악화처럼 빼지 않습니다. 1km/h 효과를 판단할 개발 점검(MAE<0.5 및 절대오차 p95<1)도 미충족입니다. 개입 반응의 검증은 별도로 필요합니다.

## 3. 판정과 검사

`development_pairwise_criteria_pass=false`: 표본 수/자료 연결/선수 비중복/정답 교체 불변/방향 반대칭은 통과했지만, 주 MAE 우위·bootstrap 상한<0·10/30Hz 비열등은 미충족입니다. 기존 scientific_gate FAIL은 그대로 보존했습니다. 힘/일·근육·실제 향상·추천 가능 여부는 모두 미검증/false입니다.

실행 명령은 README.md에 있습니다. 새 함수 회귀 검사 14/14 통과. 전체 unittest는 303개 실행, 291개 통과, assertion 실패 0개, 기존 오류 10개, skip 2개입니다. 오류 ID 집합이 이전 단계0 기록과 같음을 Python으로 검증했습니다. 9개는 OpenSim 부재, 1개는 로컬 formula_checks.json 부재입니다. 전체 통과로 주장하지 않습니다.

실제 신체 수정이나 검증된 향상이 없어 개선 투구 영상을 새로 만들지 않았습니다. 추가 탐색으로 통과 수치를 만들지 않고 다음 계획의 입력을 바꾸도록 판단했습니다. 훈련 또는 의료 조언이 아닙니다.
