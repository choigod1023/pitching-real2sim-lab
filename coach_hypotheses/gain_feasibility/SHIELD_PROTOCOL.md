# 후속 실험: 실제 누적 일 예산을 검사하는 입력 보호기

2026-10-30. 첫96실행을 마친 뒤 별도로 고정한다. 첫48조건 모두 예산 미통과였고 손목 입력 peak 제한만으로 DOF별 양/음의 일을 제한할 수 없었다. 이 실패는 보존한다. 기존 판정 기준과 원결과는 바꾸지 않는다.

원래30ms 창의 cubic-in/smoothstep/smootherstep 3개를 alpha1 손목 peak 제한 입력으로 만들고, 두 해상도에서 실행한다(6실행). 최대 구속에 따라 조건을 고르지 않는다. 기준도 같은 적분기로 다시 실행한다.

이번에는 필요한 경우 **전체 일반화 입력을 0~1의 같은 계수로 줄일 수 있다**. 따라서 어깨 입력을 매 순간 고정한 첫 경로와 구분한다. 입력의 방향을 뒤집거나 성분의 절댓값을 늘리지 않는다. 이 경로는 손목 요청+2°를 강제하지 않고 실제 동작을 예측한다. 근육 신경제어 학습이나 실제 선수 제어를 검증한 모델이 아니다.

각 RK4 substep을 가상 적분하여 실제 속도로 성분별 양/음의 일 증가분을 계산한다. 누적 일이 각 해상도의 기준 총예산을 넘으면 상태를 복원하고 전체 입력에1/2를 반복 적용한다(최대40회). 그래도 불가능하면 그 substep의 입력을0으로 한다. 입력0은 외부 중력까지 제거하는 것이 아니다. 이 검사는 성분별 양/음의 일만 보호하며 어깨 병진/회전 순일·자세·방향 제한은 최종 기존gate에서 별도로 검사한다. 순일도 자동 보장한다고 주장하지 않는다.

실제 채택한 입력과 모든 실제 상태를 저장한다. 초기 상태가 같고 상태 재설정은 가상 시도에만 적용되며, 실제 채택 궤적은 연속이다. 가상 시도 횟수와 억제 시각을 기록한다. 최종 구속/일/힘은 저장된 실제 상태와 입력으로 별도 재계산한다. 입력0 및 제한이 비활성인 경우 원RK4와 일치하는지 시험한다. 원 기준이 보호기에 의해 달라지는지도 대조한다.

통과 기준은 첫 PROTOCOL.md의 기존 전체기계적gate+최대회전3°+공중심20mm+방향1°+두해상도의양의증가/수치수렴을 그대로 사용한다. 실패를 숨기거나 입출력 힘·일 허용량을 확대하지 않는다. 실제선수효과/실제오차95%구간/회전·제구향상은미검증이다.
