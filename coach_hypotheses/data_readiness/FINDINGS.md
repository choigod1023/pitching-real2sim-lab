2026-10-29. 모델을 더 돌리는 대신 자료 확보·파일 연결·측정 준비를 실행했습니다. 사전 계획 cbffe4b 이후 원본 압축파일/기록표/추가C3D/다른 코호트MAT를 직접 계산했습니다. 기존 실패·합격 기준·gate는 바꾸지 않았습니다.

## 1. Ozkaya: 3파일 검사에서 전체 목록·반복 기록 연결로 확대

기존에 다운로드한 S1.rar(372,116,458bytes)와 Trialinfo.xlsx의 SHA256이 기존 영수증과 같았습니다. 압축파일 전체에는 **한 사람15세션의 동적450개·정적30개 C3D**가 있습니다. 이전 작업 폴더에 추출돼 있던 C3D는6개였습니다. 이번에는 전체 목록과 기록표의 S1 sheet를 대조하고 사전 선택한 동적3개를 추가로 추출했습니다. 전체450개를 모두 열어 품질 검증했다고 주장하지 않습니다.

투구키는 subject/day/DP또는NDP/반복번호이며 원래 문자열과 셀 주소를 함께 보존합니다. 결과는 다음과 같습니다.

- 압축파일 동적 투구키450개, 기록표 투구행450개.
- **448개 고유 연결**, 누락2개, 비고유 연결0개.
- 고유 연결 중 속도 원값이 비어 있지 않은 기록 **358개**. 단위는 UNKNOWN입니다.
- 누락: 3w1d 및3w2d의 S1_NDP_08_O.c3d. 파일명/기록표를 임의 교정하거나 다른 반복에 연결하지 않았습니다.
- 상태 원문은48개가 달랐지만44개는 파일명의 거친 코드와 기록표의 자세한 결측 부위 설명 차이입니다. 상태 코드 자체가 다른4개는 모두1w1d NDP07/11/13/14이며 파일은O,표는M-XIPH입니다. 처음 기록의48개도 보존했습니다. 원문/접두코드 비교는 의미를 자동 교정한 것이 아닙니다.

새 파일은 가장 이른 유효 날짜의 우세손 정상 이름 중 아직 추출하지 않은 사전식3개인 **1w2d DP07/08/09**입니다. 선택은 파일명으로 고정해 열기 전에 저장했습니다. 첫날1w1d의 우세손에는O 파일이 없었습니다. 세 파일은200Hz, 각각1001/927/1011프레임이고 Ball 유효 표본은28/35/39개입니다. 후보event 이전−90~−5ms18표본에서 손/전완/골반/몸통/Ball이 두 인덱스 규약 모두 유효했습니다. FORCE_PLATFORM 수는 각각2이지만 신호의 물리 정합성을 새로 입증한 것은 아닙니다.

처음 체크리스트는 일반적인T10 라벨을 잘못 기대해 몸통을 불완전하게 표시했습니다. 실제 이 자료의 라벨은 **C7/T8/STRN/XIPH**입니다. 원래 결과를 별도 보존하고 T8 라벨로 목록 검사를 정정했으며, 세 파일의 해당 창이 모두 유효함을 확인했습니다. T10을T8의 같은 해부학적 점으로 치환하거나 원본을 재라벨링한 것이 아닙니다. 점 위치 정확도/골 중심을 검증했다는 뜻도 아닙니다.

부족한 것은 분명합니다. 기록표의 Ball Speed 원값은 단위가 없고, 이번에 확보한 저자2018 전문과 기록표 Key에서도 단위를 확인하지 못했습니다. 공 표식에서 공 중심으로의 변환/공 회전, 물리 이탈 시각과 독립 보정·시각 오차도 미확인입니다. 따라서358개를 km/h 정답으로 바꾸거나 그립 모델을 구속에 맞추지 않았습니다. 초보자의 야구공 던지기이며 숙련 투수의 마운드 피칭 표본으로 소개하지 않습니다.

1차 출처: [저자2018 논문](https://doi.org/10.1038/sdata.2018.272), [Europe PMC 공식 전문XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6278687/fullTextXML), [S1 원본 배포API](https://api.figshare.com/v2/articles/5943103). 논문은 반복 투구와 표식 데이터를 설명하지만 새로운1km/h 개입 예측의 성능을 보증하지 않습니다.

## 2. Takamido: 50명250구는 실제 있으나 손–공 원자료와 다름

이미 확보한 Sub001~050의250개 MAT를 모두 읽고 해시를 기록했습니다. 모두 X(101,15,3)와 scalarY만 있고 값은 finite였습니다. 선수마다5구입니다. 별도 공 궤적이나 실제 캡처 시각 필드는 없습니다. 좌표101개를 원래 표본율의 원시 시계열로 취급하지 않습니다. 이 구조만으로 손 프레임/손가락/공 중심/물리 이탈을 독립 확인할 수 없습니다.

원문은 TrackMan 구속을 설명하므로 신체–기록 구속 관찰 연구의 후보로는 남습니다. 다만 고정 README에 명시적인 데이터 재사용 라이선스를 확인하지 못해 이번에는 구조/무결성만 검사하고 학습/재배포하지 않았습니다. 모델을 새로 적합하거나 기존 OBP와 합치지 않았습니다.

## 3. 공식 접근 복구와 새 후보

Gomaz2021의 공식 Figshare 메타데이터/파일ID/라이선스는 재사용했습니다. 이번 개별파일 공식 주소는504, 전체 version1 archive 공식 주소는502였습니다. checksum을 확인한 새 원본은0개이고 모델 적합을 하지 않았습니다. 목록만 있는25선수/224투구를 이번 실측 감사 코호트로 쓰지 않습니다.

새로 찾은 mycpuorg/baseball은 공식README와 data폴더를 읽었습니다. 공개된 것은 메타데이터/results CSV와 코드이며 영상은 개인 로컬 디렉터리의 심볼릭 링크로 설명합니다.20/30/40fps 측면 영상과 음성 레이더 라벨이라는 설명도 동기화된3D 손/공 정답과 다릅니다. 공개 코드만 보고76개 원본영상을 확보했다고 하지 않았습니다. PitchPerfect2023,PitcherNet,TrackMan-only 자료도 손·공 직접 관측 조건을 충족한 새 코호트로 승격하지 않았습니다.

## 4. 결론과 다음 실제 단계

SOURCE_EVIDENCE.json의6개 후보군 중 모든 조건을TRUE로 확인한 손–공 모델 검증 준비 자료는 **0개**입니다. 관측자료가 없다는 결론이 아닙니다. 반복 투구와 신체/손/공 표식/속도 원값의 연결 범위는 넓혔지만, 공 중심·단위·정의·시계·독립 보정·실제 접촉 종료가 남아 있습니다. UNKNOWN을 통과시키지 않았습니다.

따라서 새 예측 모델이나 신체 교정 추천을 만들지 않았습니다. 공개자료의 이 미확인 항목을 추가 근거로 확인하지 못하는 경우, **COLLECTION_SPEC.md의 같은 투구 동시 측정**이 필요합니다. 그 문서와 헤더 전용 CSV를 준비했으며 실제 연락·모집·측정을 진행한 것은 아닙니다.

측정 정밀도 예산은 조건부 수식으로 검산했습니다. 독립 위치잡음SD0.5mm/1000fps/11표본의 일정속도 축방향 적합은 속도SD0.171623km/h,150km/h에서 스케일1%는1.5km/h 편향입니다. 이 계산은 실제 센서 또는 공 중심 정확도의 보장이 아닙니다. Monte Carlo20000회는 수식 검사에만 썼습니다.

새 소프트웨어 검사13/13 통과. 이 독립 브랜치는 main+사용중단 선행만 포함하며 전체302개 중290개 통과/기존오류10개/skip2개입니다. 새 오류가 없고 이전 단계0 오류ID집합과 같음을 검산했습니다. 기존 테스트가 만든 격리 폴더의 model.xml만 검사 전 SHA256과 같은 상태로 복구했습니다. 원본 자료·다른 작업 파일·기존 결과는 바꾸지 않았습니다. 훈련/의료 조언이나 실제 성능·안전·편안함 검증이 아닙니다.
